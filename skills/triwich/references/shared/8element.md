# 8要素评估模板 + 自爆机制（Poka-Yoke固定数量防错）

> **使用层级**：L1批判验证 / L2 / L3
> **设计来源**：丰田Poka-Yoke固定数量防错法 + 深度模式Skill v1.6自爆机制
> **模板锁规则**：8行必须全评，全员绿灯触发强制复检

---

## 模板

| 要素 | 评估结论（不少于一句话论据） | 置信度（🟢高/🟡中/🔴低） |
|------|---------------------------|---------------------------|
| ①核心问题 | | |
| ②实现复杂度 | | |
| ③可靠性 | | |
| ④动态性 | | |
| ⑤准确性 | | |
| ⑥可扩展性 | | |
| ⑦交叉关联 | | |
| ⑧维护成本 | | |

> **置信度标准**：🟢高=≥2个独立来源且交叉验证一致 | 🟡中=1个来源或多源有分歧 | 🔴低=无外部来源仅AI推理

---

## 🛡️ 自爆机制

```
8行评估结论全部为正面时，触发强制复检：
⚠️ 8要素全员绿灯 = 评估不充分。必须找出≥2个评估结论不是纯正面的要素，重新扫描。
```

**复检后仍全员绿灯** → 在评估结论末尾追加 `（⚠️ 复检后仍无实质性发现，可能超出当前知识范围）`，但签名必须标❌。

---

## 质量判定

| ❌ 糊弄写法 | ✅ 合格写法 |
|------------|-----------|
| 8行全写"✅通过""正常""没问题" | ≥2行有具体风险/不一致/未知/待验证 |
| 每行只有置信度符号无论据 | 每行有一句话论据（"因为XXX所以评估为YYY"） |
| 全员🟢高置信度 | 至少有🟡或🔴标注 |
| 结论照搬Step2未引入新视角 | 有独立于Step2的发现 |
