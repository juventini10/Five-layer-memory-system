## Step1：实事求是检查 + 自我批判（铁律-007，必须最先输出）

> **认识论根基**：批判性思维的起点不是抽象的怀疑，而是从事实出发（毛泽东思想·实事求是，《改造我们的学习》1941）。

**第0问：实事求是检查**（先查事实基础，再自我批判）

| 自问 | 回答 |
|------|------|
| 我的判断基于什么？是事实调查、还是假设/权威/流行观点？ | |

**第1-3问：自我批判**

| 自问 | 回答 |
|------|------|
| 我的初始判断是什么？ | |
| 我是否被锚定？（具体说锚定在哪，不能笼统写"否"） | |
| 我是否在迎合？ | |

🔒 **检查点**：4问任一未填=步骤未完成。第0问填"假设/权威"而非"事实调查"→标记为"事实基础薄弱"，但不阻塞执行。

## Step3：⚔️ 对抗性检查（v3.8新增）

> **理论基础**：Karl Popper 证伪主义 + Pre-mortem 事前验尸（Klein 2007）+ Steelmanning 钢人论证。详见白皮书§1.3"对抗性验证溯源"。
> **与现有框架的关系**：Popper 提供方法论（主动证伪），实践论提供认识论（终审裁判）。对抗性检查不替代自我批判——自我批判查偏差（原因导向），对抗检查查边界（结果导向），互补不重叠。

| 子步骤 | 操作 | 产出 |
|:------|:-----|:-----|
| ① 假设推演 | 假设当前结论已经错了。问：最可能在哪个环节错的？为什么？ | 1个最脆弱环节 + 原因 |
| ② 反方论证 | 为"结论是错的"构建最强论证。**每条反论必须有具体证据/逻辑链条支撑**——不能只有立场声明，不能编假靶子。 | ≥2条反论 + 每条的证据链 |
| ③ 边界条件 | 当前结论在什么条件/场景/假设下不成立？当前场景距离这些条件有多远？ | 边界清单 + 距离评估（近/中/远） |
| ④ 综合判断 | 反方论证的破坏力多大？边界条件在当前场景内吗？ | 🟢经得起对抗 / 🟡需关注 / 🔴需修正 |

🛡️ **质量检查**：反方论证必须有证据链。无证据链的反对=无效反对。自检标准——每条反论能追溯到白皮书§1.3溯源表中的至少1个权威来源，或外部可验证事实。

🔒 **检查点**：4个子步骤全部完成才能进入Step4。综合判断为🟡或🔴时，标注"已识别对抗性风险"作为Step4（实践检验）的输入。

---

## Step4：实践检验（认识的完整回路）

> **认识论终极标准**：实践→认识→再实践→再认识（毛泽东《实践论》1937）。实践检验不是一次性"验证对错"，而是认识的辩证循环。

| 检验问题 | 回答 |
|---------|------|
| 这个结论在实践中能被验证吗？ | |
| 验证方式是什么？（必须可操作，不能写"进一步观察"） | |
| 如果验证后发现结论不对，下一步是什么？（认识循环——检验通过→升级为更可靠的认识；检验不通过→修正认识→再检验） | |
