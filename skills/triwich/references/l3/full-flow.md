> **架构**：Agent A（执行者·球员）→ Agent B（验证者·裁判·两阶段交叉验证）→ 最终签名
> **步骤**：Step0→Step0.5→Step1→Step2→G1→[Agent A写入文件]→[Agent B]Step3→G2→Step4(含G4+G5)→结论块+门禁锁→签名 = 11步+1子目标+2独立检查点(G1/G2)

## 🔴 对话内联呈现（硬约束·不可跳过）

> **级别**：🔴 系统级（⛔DO NOT / ✅DO 常驻注入）
> **依据**：指令编写规范 §一(双轨制) / §二(因果链) / Skill架构规范 §九(Alternatives Considered)

**✅DO 将 L3 全流程思考直接内联显示在对话任务框**——Step0判定 / 锚点两列对立面 / 苏格拉底五问 / 8要素表 / Agent B盲审8要素表+全量锚点推导验证+交叉终判 / 结论块，须逐步滚出，**呈现完整度必须 ≥ L1/L2**。

**⛔DO NOT 仅输出"结论块+思考检查点+签名"的寡淡骨架**——原因是用户需在对话中实时看到推理与审查过程，才能判断结论是否认可；纯文件外置（v3.0默认）剥夺用户可见性，违反"先理解再判断"协作原则。

**Step 段头写死（设计端防误·接触法）**：L3 内联复用的模板段头为固定骨架——`【抽象建模】`(Step1) / `【第一性原理】`(Step2) / `【苏格拉底诘问】`(G1) / `【批判验证】`(Step3) / `【具象落地】`(Step4)。⛔DO NOT 改写段头或自造 Step 编号——段头与思维模块物理绑定，反贴即错（2026-07-08 实测：主agent将Step1=第一性原理、Step2=抽象建模写反，编号逃逸出Poka-Yoke边界）。✅DO 复用白皮书§3.6骨架，只填内容。

**正面建模**：对话内联 = 用户边看边拍板，是**必须项**；文件通道**仅因 Agent B 是独立子Agent（看不到主聊）而作为盲审输入源存在**——绝不意味着推导可只存文件不内联。主agent 必须把 Agent A 推导文本复制进对话，文件不替代对话呈现。

**因果链**：内联显示不破坏盲审——Agent B 是独立子 Agent、拥有独立上下文，天然看不到主聊天；盲审隔离靠子 Agent 上下文边界，与用户是否可见推导无关。故文件外置非盲审必要条件，可省。

### Alternatives Considered

| 设计决策 | 选择 | 替代方案 | 为什么不选替代 |
|:---------|:-----|:---------|:--------------|
| L3思考呈现位置 | 对话内联优先 + 文件可选 | 纯文件外置（v3.0默认） | 用户不可见推导，无法实时判断结论；盲审不依赖文件，外置无必要 |
| | | 仅结论块（寡淡骨架） | 透明度趋零，用户不知AI如何思考，违背协作验证原则 |

**交叉验证**：
```
盲审初判(阶段1) vs 全量审查(阶段2) 是否一致？
  ├─ 盲审✅ + 全量✅ → 终判✅（两次独立审查一致）
  ├─ 盲审❌ + 全量✅ → 终判✅（标注"盲审疑虑：xxx"）
  ├─ 盲审✅ + 全量❌ → 终判❌（最危险——结论好看但锚点错）
  └─ 盲审❌ + 全量❌ → 终判❌（两次都不过）
```

## 签名

### 签名反造假规则（v3.0更新）

签名出现 ✅ 时，摘要必须引用以下三者至少各一处：

| 来源 | 必须引用的证据 |
|------|--------------|
| G1 苏格拉底诘问 | 五问中至少一问的**具体答案**（不能写"已诘问"） |
| Agent B 审查报告 | 至少一个**Agent B独立发现**（不能写"审查通过"——必须引用审查表的具体行） |
| G5 思考质量自检 | 三问中至少一问的**具体回答**（不能写"已自检"） |

签名造假 = 签了✅但摘要无证据引用 = 输出无效。
