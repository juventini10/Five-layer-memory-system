# 📋 Alternatives Considered（设计决策对照）

| 设计决策 | 选择 | 替代方案 | 为什么不选替代 |
|:---------|:-----|:---------|:--------------|
| 防错端 | 设计端（问题生成声明） | 检查端（标注门禁） | 检查端可倒填标签，设计端让声明决定问题方向 |
| 深度标注 | 四层显性标注[深度X/4] | 隐性深度（不标注） | 隐性深度用户看不到，无法验证递进 |
| 原话锚点 | 接触式防错（引用用户原话） | 凭空生成匹配特征 | 原话=物理锚点，AI编不了 |
| 对话控制台 | 第8问+换主题时出示 | 每问都出示 | 每问出示打断沉浸感，消耗Token |
| Agent B介入 | 3次硬限制 | 无限制 | 无限制会过度干预，消耗资源 |
| 沉淀锁数 | 六道锁 | 三道锁（精简） | 三道锁无法覆盖产出检查+触发+反馈+执行+验证+签名+反哺全链路 |
| 题号呈现 | 前缀式「🎤 第X问」(仅序数) | 带分母「/共8问」/ 后缀式/ 无题号 | ①前缀式不挤占维度标注行、与标题🎤呼应 ②仅序数避 Koo&Fishbach 2008「进度悖论」(早期显进度反降坚持动机)+ Kivetz,Urminsky&Zheng 2006「目标梯度」(早期显分母=凸显剩余差距) ③SWT 八问为下限非定数(继续模式超8)，带分母在继续模式事实错误 ④后缀式易被误读为标注一部分 |
