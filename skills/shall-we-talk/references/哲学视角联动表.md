# 哲学视角联动表 — Shall We Talk 专用版

> 迁理之外（5 大哲学视角）与认知信号的联动映射。
> 当 Step 3 对话触及以下信号时，**必须**加载对应的哲学视角推进追问。

---

## 联动触发规则

| 用户表达了什么 | 触及的哲学问题 | 加载的哲学视角 | 追问方向 |
|:--------------|:-------------|:--------------|:---------|
| "这个对还是不对？""这样做好不好？" | 什么是"好"的标准 | **实用主义** | "你说"好"——用什么标准判断？效果优先还是原则优先？" |
| "我不知道怎么办""我不确定" | 知识边界在哪里 | **斯多葛** | "这件事哪些部分是你能控制的？哪些不是？你有办法区分吗？" |
| "本来就是这样""事情的本质是X" | 本质还是构建？ | **分析哲学** | "你说"本质"——你确定这不是你建构出来的解释吗？" |
| "这有什么意义？""我做这些是为了什么" | 意义由谁定义 | **存在主义** | "这个意义是你选的，还是别人给你的？如果没人告诉你，你还会这么想吗？" |
| "两个观点我都没办法放弃""都有道理" | 矛盾如何统一 | **唯物辩证法** | "这两个观点矛盾的点在哪？有没有一个更高的层面可以把它们统一起来？" |
| "我就是这样的人" | 自由意志 vs 决定论 | **存在主义** | "你一直是这样，还是你选择这样？这两者不一样。" |

---

## 加载方式

```
当信号命中 →
  Read references/哲学视角联动表.md 匹配对应视角
  在下一追问中引入该哲学视角的问题
  标注 [哲学-视角名]
```

**不需要把迁理之外完整的 5 个哲学理论全文搬进来。** 只需要使用上表中的追问方向，以哲学视角为追问框架。

---

## 产出要求

使用哲学视角后，追问需标注 [哲学-视角名]：

```
✅ "你说'本质就是这样'——但这个本质会不会是你建构出来的？[哲学-分析哲学]"
❌ "你说'本质就是这样'——你确定吗？"（无哲学标注，且没有哲学追问深度）
```

---

## 与三大思维的关系

```
认知边界扫描 → 发现信号 →
  ├── 信号涉及"事实/归因/模式" → 三大思维追问
  └── 信号涉及"价值/意义/边界/矛盾" → 哲学视角联动
         └── 两者可叠加：先用三大思维拆解事实，再用哲学视角追问意义
```

例子：
> 你说"本质就是这样"→ 先用 L1 第一性原理拆"本质指什么"→ 再用分析哲学追问"这个本质是你发现的还是构建的"

**不互斥，可叠加。** 一个追问可以同时使用 [L1-第一性原理] + [哲学-分析哲学]。
