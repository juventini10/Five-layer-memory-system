## 🔒 防跳步机制

接触法（物理锚点）

**接触法** — 物理锚点。接触式防错：文件读不到标🔴，不依赖AI记忆。
加载即校验——读不到=不存在=中止，读到=已加载=继续。铁律声明明确4个核心文件任一个读不到则整体中止——锚点缺失=流程不可启动。
每个步骤有必填字段（产出物📦），格式不符直接暴露跳步。边界约束清晰：轻量模式禁止写文件，越界即阻断。

定值法（数量锁）

**定值法** — 数量锁。轻量正好1步、全量正好3步，步数固定不可增删。
结构自锁——每一步产出物不可替代，跳步=产出物缺失=露馅。结论块门禁锁三问固定数量，任一未过则禁止输出签名。
步数上限锁死，不可自行增加步骤，退回补全是唯一纠正路径。

步序法（动作步序）

**步序法** — 动作步序强依赖。Step0→Step1→Step2→Step3串行，上步未完成不可执行下步。
6个熔断器串联阻断——Step0熔断器触发=中止全程，不可跳过Step0直接进Step1。
步序强制：产出物锁缺失→退回上步重产→仍不可达→中止，不可自行补写文件或降级执行。全量模式的版本门禁是步序法核心实例——版本不一致时强制回滚到步骤1，不可跳过。

## 设计原则

**加载即校验。** 读取文件本身就是校验。读不到=不存在=标注🔴。读到=已加载=标注✅。

**轻量不写文件。** 轻量模式直接在对话输出情境概览。全量同样对话输出。
