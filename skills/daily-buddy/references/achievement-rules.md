# 含金量评级标准（完整版）

> **归属**：每日伙伴 Skill → references/
> **用途**：评定日记含金量等级时按需查阅
> **版本**：v3.4（2026-05-20 从 SKILL.md 提取）

---

## 一、评级等级定义

| 等级 | 名称 | 触发条件 |
|------|------|----------|
| **S级** | 顿悟跃迁日 | 满足以下任一条件即可触发（取消"至少2条"门槛），同时无严重言行违背：
①【核心顿悟】有明确的「顿悟时刻」，清晰描述了"之前不理解的关键问题"，且抽象出了可跨场景迁移的普遍规律/底层逻辑
②【系统搭建】完成了可落地、有明确执行步骤的新系统/新机制/新流程的完整框架搭建，且当日完成首次落地验证
③【方向定调】做出了明确可落地、当日已启动第一步的长期行为/人生方向调整，且有清晰的执行计划 |
| **A级** | 高质量执行日 | 同时满足以下全部条件，未达到S级标准：
① 当日P1核心任务完成率≥90%，计划番茄钟完成率≥90%
② 无任何违背自律原则的言行（无时间浪费、无消费冲动、无作息违背等）
③ 情绪能量稳定，无严重内耗，有明确的正向积累 |
| **B级** | 平稳推进日 | 同时满足以下全部条件：
① 当日P1核心任务完成率 60%-90%，基础进度正常推进
② 无重大拖延、无严重言行违背、无深度内耗
③ 无明显成长亮点，也无明显低效失误 |
| **C级** | 低效预警日 | 满足任一条件即可判定：
① P1核心任务完成率＜60%，且无合理客观原因，存在明显拖延/摆烂
② 有明确的违背核心自律原则的言行放纵
③ 整日陷入无意义的内耗、焦虑，无有效正向积累 |
| **N级** | 中性休整日 | 同时满足以下全部条件，不归入C级：
① 主动/因客观不可抗力（生病、突发事务等）暂停原定任务计划，无明确的核心任务要求
② 无摆烂、无内耗、无违背自律原则的行为，属于主动休整/被动合理停摆
③ 无有效正向积累，也无负面消耗 |

### +/- 修饰符（展示层，不影响存储）

> **YAML 存储**：仅存核心字母 `S/A/B/C/N`，不含 `+/-`。月报 `grep` 精确匹配无障碍。
> **日记展示**：可在 callout 中附加 `+/-` 以表达粒度细化，帮助月末回顾时感知边界值。

| 等级 | 修饰 | 触发条件 |
|:--:|:--:|------|
| A | + | P1≥95% + 三项全优 + 仅差一项未达S标准 |
| B | + | P1≥80% + 轻微瑕疵（如睡眠偏差<30min） |
| B | — | P1 60-89% + 正常推进，无亮点无低效 |
| B | - | P1 60-70% + 接近红线（有拖延苗头但未破底线） |
| C | - | P1 45-60% + 有客观原因（非纯粹摆烂），勉强算低效 |

> 规则：`+/-` 仅用于日记正文 callout，不影响 YAML 值。月报扫描评级分布时只统计 S/A/B/C/N。

## 二、配套规则（保障体系长期闭环）

**1. 核心任务锚定规则**：评级只以日记里的「P1 核心任务」为准，不统计琐碎杂事，彻底避免"完成一堆小事，却没做核心事"的虚假勤奋。

**2. 月度校准规则**：每月做一次月度复盘，对当月的 S 级评级做二次校准——比如当月的一次顿悟，确实带来了后续的行为改变，就保留 S 级；如果只是当时空想，后续没有任何落地，就降级为 A 级。

## 三、「可跨场景迁移」判定规则

> **两个独立阶段，要求完全不同**：
> - **当日评S级时**：完全不需要后续运用记录，只需要能清晰论证"这个规律具备跨场景复用的能力"
> - **月度校准时**：才需要看后续日记里的实际运用记录

**第一阶段：当日S级评级（无需运用记录）**

在日记感悟中同时完成3件事，就算达标：
1. 从具体事件里，提炼出**脱离原场景的底层规律**（不是只针对变现这件事的经验）
2. 明确写出**至少2个和原触发场景完全无关的新场景**（原场景是"变现"，新场景就不能是"做账号、带货"等同属变现的场景）
3. 说清**在新场景里的具体用法**，不是空泛的套话

**第二阶段：月度校准（需后续运用记录）**

校准目的：验证"这个顿悟有没有真的从认知变成行为"。

**有效运用记录判定标准**（必须同时满足）：
1. 有**具体的场景事件**，且和当日写的「可跨场景复用方向」对应上
2. 有**明确的动作+结果**，能证明真的用了这个规律

**月度校准结果判定**：
- **保留S级**：当月后续日记里，能找到至少1条有效运用记录
- **降级为A级**：当月后续日记里，完全没有任何相关的运用记录
- **特殊豁免**：如果提炼的规律是长期适用、短期内没有落地场景的，只要在月度复盘里写出了**明确的落地计划+已完成的准备动作**，也可保留S级

**2条铁律**：
1. **绝不倒推评级**：当日评级只看当日的认知提炼，哪怕后续月度校准降级，也不代表当日评S级是错的
2. **运用记录不贪多**：月度校准只看"有没有"，不看"有多少"，哪怕只有1次落地也足够

## 四、月度校准执行方案（方案一）

| 执行环节 | 执行主体 | 具体动作 |
|----------|----------|----------|
| 前置准备 | AI | 月度复盘时，自动拉取当月所有标记为S级的日记，逐条整理「S级触发依据」 |
| 落地验证 | AI | 自动检索后续日记内容，匹配该S级对应的规律/系统/决策，有没有明确的落地执行记录 |
| 校准建议 | AI | 给每条S级给出明确的校准建议：✅建议保留S级 或 ⚠️建议降级为A级 |
| 最终决策 | 用户（手动） | 基于AI的提醒和自身实际情况，手动确认最终评级结果 |

### 双向校准规则（月报执行，全面覆盖所有等级）

> **核心原则**：当日 YAML `rating` 字段永不动（"绝不倒推评级"铁律）。月报校准是独立注释，记录在月报质量评估模块的"校准记录"表中，不影响日记原文。

**触发条件**（月报生成时，AI 扫描当月所有非S级日记）：

| 方向 | 触发信号 | 校准动作 |
|:--:|------|------|
| A → S 晋升 | 该日洞察在后续30天内跨≥2个场景落地，且至少1次产生了可追溯的行为改变 | AI标注"建议晋升为S"，附证据链 |
| B → A 晋升 | P1完成率虽未达90%但核心产出对月度目标有关键推动，后续证明了该日的战略价值 | AI标注"建议晋升为A"，附证据 |
| C → B 晋升 | 当日被评C但事后发现存在合理客观原因（非主观摆烂），且当周内弥补了缺口 | AI标注"建议调为B"，附原因 |
| S → A 降级 | 无后续落地记录（已存在，不变） | ✅ 保留S或 ⚠️ 降级A |
| A → B 降级 | 当日看起来达标的A，但在月度视角下发现实际P1完成率虚高或自律违背被忽略 | AI标注"建议降级B"，附原因 |

**晋升铁律**：
1. **用户手动确认**：所有晋升/降级建议最终由用户手动确认，AI不做自动改判
2. **YAML不动**：校准结果不回溯改写当日日记的 `rating` 字段
3. **月报记录**：校准结果写入月报质量评估模块的"校准记录"表：`日期 | 原始评级 | 校准评级 | 原因 | 用户确认`

**扫描方法**（月报AI执行）：
```bash
# 1. 拉取当月所有非S级日记（A/B/C）
grep -l '^rating: "[ABC]"' YYYY-MM/*.md
# 2. 对每篇，搜索后续30天内日记中是否有该日洞察的落地痕迹
# 3. 满足条件 → 生成校准建议 → 等用户手动确认
```

## 五、S级顿悟6条执行校验铁律

1. 非重复核查：AI自动调取S级总记录，重合度≥30%直接驳回
2. 痛点溯源核查：AI检查是否有历史记录引用
3. 落地交付物核查：AI检查交付物是否可追溯（口头无效）
4. 伪规律筛查：AI执行3步测试（去场景化+废话+复用性）
5. 方向转折类专属校验：AI检查是否证明认知跃迁（仅方向转折类需要）
6. 单一落地动作唯一验证：同一落地动作已用于过往S级直接驳回

**配套文件**：S级顿悟总记录（`[记忆共享中心]/最伟大的我/S级顿悟总记录.md`），每次评完S级追加一行
