| Skill | 关系 |
|-------|------|
| **唤醒记忆系统** | 上游输入——每日伙伴写入快照后，唤醒记忆可读取最新情境数据 |

| **三明智** | 互补——每日伙伴的促进思维分析场景可引用三明智L1 |
| **迁理之外** | 互补——哲学视角深度分析 |
| **读书助手** | 互补——感悟→知识提取→知识库沉淀 |
