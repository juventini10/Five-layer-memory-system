# 熔断器降级规范

> version: v1.0 | 来源: SKILL.md v2.2.0 | 日期: 2026-07-04
>
> 本文件集中记录clock-loop所有熔断器的触发条件、降级方案和外显信号。
> SKILL.md中各阶段内联熔断器为本文件的速查摘要，完整规范以此文件为准。

## 熔断器总览

| # | 位置 | 熔断器名 | 触发条件 | 降级方案 |
|---|------|---------|---------|---------|
| 1 | 阶段0触发判定 | 触发判定 | 用户输入不以"循环/loop"开头 | 不触发，正常对话 |
| 2 | 阶段1标准收集 | 标准收集模糊 | 用户回答模糊，追问1次仍模糊 | 使用默认标准（平衡模式+3轮） |
| 3 | 阶段1.5知识网络 | 文件加载失败 | patterns或weights文件加载返回空 | patterns→general_evaluation / weights→等分权重 |
| 4 | 阶段2自查循环 | 自查未达标 | 3次内部循环仍未达到85% | 跳子Agent审查，如实记录当前分数 |
| 5 | 阶段2审查环节 | 轮次用尽 | 达到最大轮次仍有未通过项 | 超限终止，交付当前版本+未通过项清单 |
| 6 | 阶段2子Agent | spawn失败 | 子Agent spawn失败或超时 | 降级为自检+自查清单核对 |

## 外显信号格式

所有熔断器触发降级时，必须输出外显信号：

```
⚠️ 熔断器触发:{熔断器名}({具体原因}) → 降级方案:{降级内容}
```

### 各熔断器外显信号

| # | 熔断器名 | 外显信号 |
|---|---------|---------|
| 1 | 触发判定 | 不触发时无输出（正常对话不需要信号） |
| 2 | 标准收集模糊 | `⚠️ 熔断器触发:标准收集模糊({原因}) → 降级方案:使用默认标准(平衡模式+3轮)` |
| 3 | 文件加载失败 | `⚠️ 熔断器触发:{patterns/weights}加载失败 → 降级方案:{general_evaluation/等分权重}` |
| 4 | 自查未达标 | `⚠️ 熔断器触发:自查3次未达标({当前分数}%) → 降级方案:跳子Agent审查,如实记录` |
| 5 | 轮次用尽 | `⚠️ 熔断器触发:轮次用尽({已用N轮}) → 降级方案:超限终止,交付当前版本+未通过项` |
| 6 | spawn失败 | `⚠️ 熔断器触发:子Agent spawn失败/超时 → 降级方案:自检替代,如实记录` |

## 降级链路图

```
用户输入
  │
  ├─ 不含"循环/loop" → 熔断器1: 不触发,正常对话
  │
  └─ 含"循环/loop" → 阶段1标准收集
       │
       ├─ 用户回答模糊 → 熔断器2: 默认标准(平衡模式+3轮)
       │
       └─ 标准收集完成 → 阶段1.5知识网络
            │
            ├─ patterns/weights加载失败 → 熔断器3: general_evaluation + 等分权重
            │
            └─ 加载成功 → 阶段2循环执行
                 │
                 ├─ 自查3次未达标 → 熔断器4: 跳子Agent审查
                 │
                 ├─ 子Agent spawn失败 → 熔断器6: 自检替代
                 │
                 ├─ 子Agent审查不通过 → 修正 → 重试
                 │    │
                 │    └─ 轮次用尽 → 熔断器5: 超限终止
                 │
                 └─ 子Agent审查通过 → 阶段3交付
```

## 更新规则

- 新增熔断器时，必须同步更新本文件的总览表、外显信号表和降级链路图
- SKILL.md中各阶段的熔断器块为速查摘要，完整规范以此文件为准
- 版本号跟随SKILL.md主版本号
