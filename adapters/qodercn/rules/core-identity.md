## 注入自检（本端命脉·⛔不靠人记得）

本端整套常驻注入建立在官方**未文档化**的行为上（新版 CN=0.1.0 换代线，行为可能随版本变）。
每个会话的第一个实质任务前，跑一次留痕对账：

```
python3 [记忆共享中心]/开发工具/qodercn_inject_chain_guard.py --record --session <会话标识> \
  --seen .qoder-cn/AGENTS.md,.qoder-cn/rules/<文件名>.md,…,.qoder/rules/<文件名>.md
```

`--seen` 填**本会话上下文里实际出现的每个常驻注入文件的真实归属路径**（`global_context` 与 `project_context` 都算，逗号分隔）。
⛔ 凭印象填、照抄上次结果=自检作废——只报你真正看见的。
脚本自动对账并报告四类结果：`注入静默失效`（盘上有却没注进来=换代重置）｜`幻影注入项`（看见的盘上不存在）｜
`跨端串味`（他端根实体文件混入=泄漏复发，按 cross-end-guard 第二类泄漏处置）｜`痕迹缺失/超龄`（≥7 天没自检）。
报告结果原样进回复，⛔不静默吞。
