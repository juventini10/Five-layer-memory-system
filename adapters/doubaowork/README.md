# doubaowork adapter · 豆包办公端

> ⚠️ **本端与其他端不同——规则不是"放文件到目录"就生效，必须手动粘贴到 UI 设置。**

## 这一步是干嘛的？

豆包办公有个设置叫「工作任务偏好指令」——你可以把它理解成**"每次开工前先念一遍的规矩"**。你写一次进去，以后每新开一个工作任务，豆包都会自动先读到这些规矩，不用你每次重复说"你要严谨一点""表格别太宽""署名要怎么写"。

其他端（比如 WorkBuddy、Trae）是把规则文件放进指定目录就自动生效，但豆包办公没有这个机制——**唯一能让规则常驻的通道，就是这个设置框**。所以这一步必须你手动粘一次，粘完永久生效，不用每次重贴。

## 粘的是什么？

安装器会帮你生成 `~/.doubaowork-config/doubaowork-paste.md`。这份内容是**布洛陀版本的作者根据长期使用总结出来的一套适配规则**——包括做事前怎么想问题、底线是什么、回复怎么组织、童灵是谁、五系统文件怎么加载，等等。

你有两种用法：
- **全量粘贴**：直接全部粘进去，一步到位，作者验证过的完整配置
- **选择性吸收**：先通读一遍，觉得哪条适合自己就留哪条，不适合的删掉，末尾还可以追加你自己的习惯

## 为什么这端特殊

| 端 | 规则生效方式 |
|---|---|
| Trae Work / Qoder CN 等 | 把 `rules/*.md` 放到端指定目录，`alwaysApply: true` 自动每轮注入 |
| **豆包办公** | **没有规则目录、没有 alwaysApply 机制**。规则唯一常驻通道是「设置 → 工作模式任务设置 → 工作任务偏好指令」这个文本框——平台每次工作任务自动把框里的文字注入系统提示，不依赖 AI 自觉。 |

## 安装两步

1. **运行安装器**（推荐）：`bash adapters/doubaowork/setup.sh`
   它会生成两个文件到 `~/.doubaowork-config/`：
   - `doubaowork-paste.md` —— **待粘贴正文**（全选这个文件的全部内容）
   - `doubaowork-paste.md.readme` —— 给你的操作说明（⛔ 不用粘）

2. **手动粘贴**：
   - 打开豆包办公 → 左下角点头像 → **设置**
   - 找到 **工作模式任务设置** → 点开 → 找到 **工作任务偏好指令** 文本框
   - 打开 `~/.doubaowork-config/doubaowork-paste.md`，全选复制全部内容，粘贴进去 → 保存

> ⚠️ 同目录下的 `doubaowork-paste.md.readme` 是给你看的说明，**不用粘**。
>
> ⚠️ **关于字数上限**：豆包官方已公布该文本框上限为 **10000 字符**。安装器生成的 paste.md 约 4700 字，还剩约 5300 字空间，你可以放心追加自己的个性化偏好。如果以后 paste.md 内容增加导致接近上限，安装器会自动警告。
>
> 💡 粘贴后你可以在末尾追加自己的个性化偏好（回复格式、署名、表格具体列数/字数上限等）——通用版刻意不写死这些，留给你按自己习惯调。

## 怎么验证生效

新开一个会话，随便问一句："你的准则第一条是什么？"
- 答得出"退一步再动 / 先说假设" → ✅ 生效了
- 答不出或者说"我没有这样的准则" → ❌ 没粘上，回设置里看看文本框是不是真的保存了，以及内容有没有被截断

## 边界（诚实标注）

- 工作任务偏好指令是**平台 UI 设置**，本安装包的脚本无法替你写这个框——必须人工粘贴一次。粘贴后跨会话持久，不用每次重贴。
- **字数上限**：豆包官方已公布该文本框上限为 **10000 字符**。安装器生成的 paste.md 约 4700 字，剩余空间充足；安装器会自动统计字数并在接近上限时警告。
- 本 adapter 不含 Stop Hook / 每轮末守卫（豆包办公无此机制）；格式校验靠 AI 自觉 + 品格倾向兜底，不是物理闸口。
