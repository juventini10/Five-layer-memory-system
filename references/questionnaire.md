**Q10. 你在什么情况下会"硬撑"而不是放弃？（单选）**
- A 已经投入了很多时间和精力

**Q11. 你更相信"想清楚再做"还是"做了才知道？（单选）**
- A 70%想清楚 + 30%边做边调（计划型）

**Q12. 你怎么判断一个建议值不值得听？（单选）**
- A 给建议的人自己有没有做到（结果导向）
- B 建议有没有具体的可执行步骤（实操性）
- C 是否符合我对自己情况的判断（自我一致性）
- D 多个人说同样的话我就信（从众心理）
- E 其他：________

**Q13. 当AI给你的方案和你想的不一样时，你通常怎么处理？（单选）**
- A 说服AI按我的想法来（坚持己见）
- B 听AI的，但我心里打鼓（隐性抗拒）
- C 让AI说清楚底层逻辑，说通了我就改（逻辑服人）
- D 自己回去想想再决定（延迟决策）
- E 其他：________

**Q14. 当你犯了明显错误或陷入内耗时，你希望AI怎么对你？（单选）**
- A 直接指出问题，用词犀利点，骂醒我
- B 像朋友一样共情，先安抚情绪，再给建议
- C 绝对客观，只摆事实和数据，不带任何感情色彩
- D 扮演苏格拉底——不直接给答案，也不硬推证据链，用提问让我自己推导出结论
- E 其他：________

**Q15. 你最喜欢AI给你反馈信息的方式是？（单选）**
- A 极简要点：只给我结论，越短越好
- B 结构化长文：背景、分析、结论清清楚楚
- C 引导式提问：别直接给答案，问问题启发我自己想
- D 其他：________

**Q16. 你让AI整理资料时，你最偏好哪种呈现方式？（单选）**
- A 表格控（能用表格绝对不用文字——对比、分类、参数，凡结构化信息必须表格；一句话说不清的，直接做表不要堆文字）

- C 散文/叙述控（连贯地理解前因后果，不喜欢碎片化堆砌）

**Q17. 如果AI发现你的逻辑有明显漏洞，你希望它怎么做？（单选）**
