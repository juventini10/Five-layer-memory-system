# 步骤4：问卷填写

📦 **产出物**：33题问卷答案 → 写入 `{记忆共享中心}/.install/问卷答案汇总.md`

---

> **⚡ 步骤锁定协议**
> ① 导航锁：每次回复首行输出 `步骤4/7`
> ② 偏离锁：用户问无关问题 → 记到待办列表，不展开回答，继续问卷
> ③ 检查点前置依赖：Read `{记忆共享中心}/.install/step3-done.md` — 不存在则阻塞
>    从 step3-done.md 提取路径变量（MEMORY_CENTER / DIARY_REPO / KNOWLEDGE_BASE）
> ④ 检查点写入：两段验证全部通过后 Write `{记忆共享中心}/.install/step4-done.md`

## 执行指令

### 4a. 用户类型判断

读取步骤2产出的**安装类型标记**：

```
安装类型标记 = 步骤2用户回答的"全新安装" 或 "升级"

├─ 全新安装 → 走4c问卷填写 → 继续步骤5（文件合成）
└─ 升级 → 走4b旧版规则拆分 → 继续步骤5（升级合并）
```

> ⚠️ 步骤2的安装类型标记通过对话上下文传递。如无法确定类型→直接问用户"你是全新安装还是升级旧版？"

### 4b. 老用户升级（旧版规则拆分）

检测旧版规则文件（`[记忆共享中心]/记忆规则/` 下存在任一层规则文件）：

1. 读取旧版统一规则文件（可能为单文件或多文件）
2. 将内容拆分到三层：
   - 执行规则 → 铁律版
   - 问卷/偏好描述 → 摘要版（从旧版中提取或保留原摘要）
   - 完整行为准则 → 详解存档版
3. 三层文件写入后，版本标记为 v1.0
4. **摘要版不覆盖**——用户已有回答数据保留

> 老用户升级完毕 → 继续步骤5（升级合并）

### 4c. 全新用户问卷填写

**仅新用户执行。** 引导用户完成33题问卷，产生全部原始数据。

1. 读取 `references/questionnaire.md`（v4.0版）获取完整33题
2. 按顺序引导用户逐题回答（每次1-3题，不等全部回答完毕）
3. 记录每道题的题干+答案，暂存于AI上下文中

**答题要求**：
- 题目文本铁律：**必须逐题原样输出题干+选项，禁止改写、概括、精简或自行编造题目**
- 每道题都是单选，注意Q29可多选，Q23/Q24/Q25/Q27/Q31/Q32/Q33为开放填空题
- 用户答完一题，AI记录答案，展示下一题
- 所有33题完成后，确认答案完整

### 4d. 写入问卷答案汇总

33题全部完成后，执行以下操作：

1. **写入文件**：将Q1-Q33的题干（原文）+ 用户答案，写入 `{记忆共享中心}/.install/问卷答案汇总.md`
2. **第1关验证 — 题目一致性**：Read `references/questionnaire.md`（官方题库），逐题核对刚写入文件的Q1-Q33题干是否一致。任一体不一致 → 修正后重写 → 重验。全部一致 ✅
3. **第2关验证 — 答案一致性**：Read 刚写入的 `问卷答案汇总.md`，逐题核对答案与对话中用户的实际回答是否一致。任一个答案不对 → 修正后重写 → 重验。全部一致 ✅
4. 两关都通过 → Write `{记忆共享中心}/.install/step4-done.md`（检查点）

> 问卷完成 → 问卷答案已写入文件 → 继续步骤5

---

### ⚠️ 禁止行为

| 禁止 | 原因 |
|:----|:-----|
| ❌ NEVER跳过未答完的题目 | 33题是系统数据源，缺题=生成的文件有缺口 |
| ❌ NEVER用"用户意思差不多"替代完整提问 | Q8-Q33需要用户具体描述才能转化为有效规则 |
| ❌ NEVER在用户答完Q1-Q33之前走下一步 | 步骤锁定协议已写，但在禁止行为中再声明——双保险 |
| ❌ NEVER改写/概括/精简题目文本 | 题目文本铁律：必须逐题原样输出题干+选项+说明 |

### 🔌 熔断器

用户中断作答时的处理：
- 成功条件：33题全部答完 + 两段验证全部通过 + 写入 `问卷答案汇总.md`
- 中断处理：记录中断时进度（已答到第N题）→ 下次继续时从第N+1题开始
- 重试机制：两段验证任一项不通过 → 修正后重写 → 重新验证
- 降级处理：无降级——33题不完成不走下一步

- [ ] 第2关验证通过（答案一致性——与用户对话记录逐题核对）
