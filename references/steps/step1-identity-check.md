# 步骤1：系统身份校验

📦 **产出物**：平台确认 + 老用户探测 + 版本信息 + 架构概述

---

> **⚡ 步骤锁定协议**
> ① 导航锁：每次回复首行输出 `步骤1/7`
> ② 偏离锁：用户问无关问题 → 记到待办列表，不展开回答，继续安装
> ③ 领先步锁：本步无前置检查点（第一步）
> 🔒 门禁：平台确认完成 + 系统身份检测结果已输出

## 执行指令

### 1a. 平台确认

确认当前平台为 **WorkBuddy**

### 🔌 熔断器

身份校验过程中的异常处理：
- 成功条件：平台确认 + 老用户探测完成 + 校验结果表已输出
- 中断处理：目录检测失败 → 输出检测失败的路径 → 让用户手动提供
- 重试机制：用户提供路径后 → 重新执行验证
- 降级处理：全新用户没有记忆中心目录 → 跳过检查点写入，继续步骤2

### 1b. 老用户探测（⚠️ 必须实际执行文件查询，不可凭记忆猜测）

按以下顺序执行**真实的文件系统查询**：

#### 第一步：找记忆共享中心

依次尝试以下路径（用 Read 或 Bash `ls` 实际验证目录是否存在）：

| # | 候选路径 | 检查方式 |
|:-:|--------|---------|
| 1 | 用户在对话中提供的路径 | 直接验证 |
| 2 | `[记忆共享中心]/` | Bash `ls [记忆共享中心]/` |
| 3 | `~/AI记忆库/` | Bash `ls ~/AI记忆库/` |
| 4 | 常见变体：`~/记忆库/` `~/ai-memory/` `~/memory/` | 逐个试 |

→ 找到存在的目录后，**再用 Bash `ls` 列出其根目录全部文件**，确认里面包含布洛陀特征文件（如 `核心层/` `技能配置/` `记忆规则/` `.install/` 等）

→ 如果以上都找不到，问用户："你的记忆文件（布洛陀/个人AI档案）装在哪？给我完整路径"

#### 第二步：判断安装状态 & 找问卷答案

拿到记忆共享中心路径后，**必须逐个执行以下真实查询**（用 Glob 或 Bash `ls` / Read）：

| 检测项 | 查询命令 | 结果含义 |
|--------|---------|---------|
| 是否已安装 | Glob `{记忆共享中心}/.install/step*-done.md` 或 `ls {记忆共享中心}/.install/` | 有文件 = 老用户 |
| **当前版本** | **Read `{记忆共享中心}/.install/manifest.md`（首行version字段）** | **有 = 精确版本号；无 = 退化为全新安装基线** |
| 安装包版本 | Read `version.md`（安装包根目录） | 目标版本 |
| 问卷答案 | Glob `{记忆共享中心}/**/问卷答案*` （递归搜）或 `ls {记忆共享中心}/问卷答案汇总.md` | 有 = 已答过题 |
| CORE.md | Read `{记忆共享中心}/核心层/CORE.md` 前5行 | 有内容 = 核心层已初始化 |
| Skill 目录 | Bash `ls {记忆共享中心}/技能配置/` | 有子目录 = Skill已装 |

> **🚨 禁止行为**：
> - ❌ 不要"觉得""应该""大概"——必须执行真实命令
> - ❌ 不要只看记忆中心路径就下结论"未发现"——必须 `ls` 或 `Glob`
> - ❌ 问卷答案文件名可能是 `问卷答案汇总.md` 或 `问卷答案.md` ——两种都搜
> - ❌ 如果 Glob 没结果，再试 Bash `find {记忆共享中心} -name "*问卷*"` 兜底

### 1c. 输出校验结果表

将 1b 的**实际查询结果**整理为表格输出：

```
🏮 布洛陀已就位 — 系统身份校验

| 项目 | 值 |
|------|-----|
| 平台 | WorkBuddy |
| 记忆中心 | {实际查到的路径} |
| 当前状态 | 全新安装 / 已安装布洛陀X.X ({日期}) |
| **已安装版本** | **{从 manifest.md 读取的版本号} / 未发现（视为全新）** |
| **安装包版本** | **{从 version.md 读取的版本号}**  |
| 版本对比 | **全新安装 / 已最新（无需升级）/ 可升级: X.X→X.X / ⚠️ 降级: X.X→X.X（版本更低）** |
| 问卷答案 | {实际路径} / 未发现 |

✅ 平台确认：WorkBuddy
```

> 表格中每一行的值都来自 1b 的**实际查询结果**。如果某项查询失败/找不到，写"未发现"并标注你用了什么命令查的。

### 1d. 升级路径决策

根据版本对比结果决定后续路径：

| 对比结果 | 路径 |
|:---|:---|
| **全新安装**（未检测到已安装） | → 继续到步骤2（完整7步安装） |
| **已最新**（已安装版本 = 安装包版本） | → 输出"✅ 已安装最新版本 {版本号}，无需升级" → 结束 |
| **可升级**（已安装版本 < 安装包版本） | → 输出变更摘要 → 走 `references/upgrade/upgrade-plan.md` 升级流程 |
| **⚠️ 降级**（已安装版本 > 安装包版本） | → 警告"安装包版本({包版本})低于已安装版本({已装版本})，是否降级？" → 用户确认后走 `references/upgrade/upgrade-plan.md`（降级模式） |

**输出示例（升级场景）**：

```
📦 检测到已安装布洛陀 1.0（2026-06-01）
📦 安装包版本：1.3.1（2026-07-22）
📦 升级路径：1.0 → 1.3.1

🔍 变更摘要（1.0 → 1.3.1）：
  Skill更新：每日伙伴 v3.11.1→v3.12.0、系统日志 v3.4.2→v3.5.0
  系统模板：SOUL.md、用户基本规则（3文件）
  架构规范：Skill架构规范五个文件修复

是否开始升级？（Y/n）
```

### 1e. 写入检查点

> ⚠️ 如果记忆共享中心目录尚不存在（全新用户），则跳过检查点写入，继续步骤2。
