### 7c. 生成文件快照（manifest.md）

✅DO 在验证通过后生成 MD5 文件快照 —— 这是升级时三路比较的数据基础。

```bash
# 对记忆共享中心下所有关键文件计算 MD5
MANIFEST="{记忆共享中心}/.install/manifest.md"
VERSION=$(grep "^version:" version.md 2>/dev/null | sed 's/.*"\(.*\)".*/\1/' || echo "unknown")

echo "# 布洛陀文件快照" > "$MANIFEST"
echo "version: \"$VERSION\"" >> "$MANIFEST"
echo "created: \"$(date "+%Y-%m-%d %H:%M")\"" >> "$MANIFEST"
echo "" >> "$MANIFEST"
echo "| 文件 | MD5 |" >> "$MANIFEST"
echo "|------|-----|" >> "$MANIFEST"

# 遍历 conffiles 清单中的文件
for file_path in \
  "核心层/CORE.md" "认知层/IDENTITY.md" \
  "行为层/MEMORY.md" "情境层/动态状态快照.md" \
  "潜意识层/SHADOW.md" "自定义层/USER.md" \
  "记忆规则/用户基本规则-铁律版.md" \
  "记忆规则/用户基本规则-摘要版.md" \
  "记忆规则/用户基本规则-详解存档.md" \
  "README.md"; do
  full_path="{记忆共享中心}/$file_path"
  if [ -f "$full_path" ]; then
    md5=$(md5 -q "$full_path" 2>/dev/null)
    echo "| $file_path | $md5 |" >> "$MANIFEST"
  fi
done
```

📦 **产出物**：`{记忆共享中心}/.install/manifest.md`

🔌 **熔断器**：成功=文件写入后 Read 非空 | 失败=标注"⚠️ manifest快照写入失败，升级时将退化到完全覆盖模式" | 不阻塞安装完成

**升级用户场景**：升级完成后同样执行 manifest.md 重建（覆盖旧快照）。
