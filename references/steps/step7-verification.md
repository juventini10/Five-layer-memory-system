### 7b+. 检索/扫描类验收记录的状态头（E-1 根治 · 2026-10-22 上游反馈单V2）

> 病根实证：Win 用户机验收文件把「⚠️向量检索降级·候选0」当基线留存，文件面无任何
> 「本次语义层未启用」标记 ⇒ 一条从未跑通的链路因"有基线文件"被当作已验=假绿，比没验收更危险。
> 运行时显形（⚠️降级行+kb_degrade.jsonl）search_kb 早已在位——本规范补的是**记录面**：
> 降级态的输出可以存在，⛔不可以无标记地进基线。

凡把检索/扫描/走查结果落盘为**验收记录或基线**（如概念词召回基线、三面同源验收），
记录文件头部 ✅DO 带三行状态头，缺状态头的记录 ⛔不得作为基线引用：

```
# 状态: 语义层在位 | 降级
# 模型: <MODEL_EFFECTIVE 实值> ｜ 向量数: <kb_vectors 条数>
# 判据: 输出含「⚡语义#」标记=在位；无该标记=降级态记录，不得写入基线
```

- 「状态」行二选一，⛔不许留空或写"未知"——未知=当场跑 `search_kb.py --status` 实取，不凭印象；
- 「判据」必须是**输出里能看见的标记**（⚡语义#=search_kb 语义路命中行的现有形态），⛔"我以为加载了"不占判据位；
- 降级态确需留档（如排障现场）⇒ 状态头标「降级」+附降级原因行，与基线分目录/分标记，后续对账⛔混用。

### 7c. 生成文件快照（manifest.md）

✅DO 在验证通过后生成 MD5 文件快照 —— 这是升级时三路比较的数据基础。

```bash

MANIFEST="[记忆共享中心]/.install/manifest.md"
VERSION=$(grep "^version:" version.md 2>/dev/null | sed 's/.*"\(.*\)".*/\1/' || echo "unknown")

echo "# 布洛陀文件快照" > "$MANIFEST"
echo "version: \"$VERSION\"" >> "$MANIFEST"
echo "created: \"$(date "+%Y-%m-%d %H:%M")\"" >> "$MANIFEST"
echo "" >> "$MANIFEST"
echo "| 文件 | MD5 |" >> "$MANIFEST"
echo "|------|-----|" >> "$MANIFEST"

# 遍历 conffiles 清单（C20·2026-10-15：与 step5 真实落点对齐——旧清单三条 MC 路径
#   （认知层/IDENTITY、行为层/MEMORY、自定义层/USER）是搬迁移位前的老架构落点，且缺 SOUL.md；
#   配置根四件（IDENTITY/SOUL/USER/MEMORY）现在 [配置根]/ 下，真源=step5 5d 写入目标行）
CONFIG_ROOT="$(grep -m1 '^CONFIG_ROOT=' "[记忆共享中心]/.install/step3-done.md" | cut -d= -f2 | sed "s#^~#$HOME#")"
# P17 根治（2026-10-19）：CFG 件真实落点不再按 WB 扁平结构写死——按配置根反查本端
#   capability.yaml 的 system_file_paths 映射（与 step5 5d 同一权威源，⛔另抄清单=第三本账）。
#   qodercn 端 IDENTITY/SOUL/USER 实体=rules/core-*.md，扁平字面执行必报 3 缺件。
CFGNAME="$(basename "$CONFIG_ROOT")"
CAPFILE=""
for _c in adapters/*/capability.yaml; do
  [ -f "$_c" ] && grep -qE "^[[:space:]]*config_root:[[:space:]]*[^#]*[/.]$CFGNAME([[:space:]]|#|$)" "$_c" 2>/dev/null && CAPFILE="$_c" && break
done
[ -z "$CAPFILE" ] && echo "⚠️ 未反查到 capability（CFGNAME=$CFGNAME）——CFG 件按扁平回落，映射面未生效" >&2
syspath() { # 名 → 端内真实落点（F3 审查归正 2026-10-19：按 capability 值四形态分派，⛔一律拼配置根）
  _v=""
  if [ -n "$CAPFILE" ]; then
    _line="$(grep "^  $1:" "$CAPFILE" 2>/dev/null | head -1)"
    if [ -n "$_line" ]; then _v="$(printf '%s' "$_line" | sed 's/^[^:]*:[[:space:]]*//; s/"//g; s/[[:space:]]*#.*$//')"; fi
  fi
  case "$_v" in
    ""|null) printf '%s' "$1" ;;
    "~/"*)   printf '%s' "${_v/#\~/$HOME}" ;;
    platform://*|*::*|app/*) printf 'NONFILE:%s' "$_v" ;;
    /*)      printf '%s' "$_v" ;;
    *)       printf '%s/%s' "$CONFIG_ROOT" "$_v" ;;
  esac
}
for entry in \
  "MC|核心层/CORE.md" \
  "CFG|IDENTITY.md" "CFG|SOUL.md" "CFG|USER.md" "CFG|MEMORY.md" \
  "MC|情境层/动态状态快照.md" "MC|潜意识层/SHADOW.md" \
  "MC|记忆规则/用户基本规则-铁律版.md" \
  "MC|记忆规则/用户基本规则-摘要版.md" \
  "MC|记忆规则/用户基本规则-详解存档版.md"; do
  # F12 根治（2026-10-17）：旧清单含 "MC|README.md" 但无任何步骤创建 MC 根 README
  #   ⇒ 全新装机必然「缺件」。已移除（若要收录，先在 step3 3b 补复制动作）。
  scope="${entry%%|*}"; rel="${entry#*|}"
  case "$scope" in
    MC)  full_path="[记忆共享中心]/$rel" ;;
    CFG) full_path="$CONFIG_ROOT/$(syspath "$rel")" ;;
  esac
  case "$full_path" in NONFILE:*) echo "| $full_path | 非文件承载（capability 声明形态·MD5 不适用·预期态） |" >> "$MANIFEST"; continue ;; esac
  if [ -f "$full_path" ]; then
    md5=$(md5 -q "$full_path" 2>/dev/null)
    echo "| $full_path | $md5 |" >> "$MANIFEST"
  else
    # C20：缺件逐条显形——manifest 是升级比对证据链，静默跳过=快照漂移无人知（D9 病根）
    echo "| $full_path | ⚠️缺件（未落位·升级基线不完整·查该端五件制/step5 落点） |" >> "$MANIFEST"
    echo "⚠️ 清单缺件：$full_path"
  fi
done

# 版本锚点:单行版本号,供下游工具(如 Qoder系加强包)机检"装了哪版布洛陀"——比解析 manifest/README 更稳
```
