## 执行指令

### ⚠️ 禁止行为

| 禁止 | 原因 |
|:----|:-----|
| ❌ NEVER凭猜测设置路径 | 必须用 Bash `ls` 或 `find` 实际验证目录存在 |
| ❌ NEVER使用包含空格/特殊字符的路径不加处理 | 引用时必须加双引号——否则命令执行出错 |
| ❌ NEVER在目录创建未验证前说"路径已配置" | 目录不存在=后续步骤全部写错位 |

### 🔌 熔断器

路径配置过程中的异常处理：
- 成功条件：所有路径有效 + 全部目录已创建 + `step3-done.md` 已写入
- 中断处理：用户提供的路径无效 → 展示检测结果 → 让用户重新提供
- 重试机制：重试3次仍未通过 → 输出"路径配置失败，请检查目录读写权限"
- 降级处理：无降级——路径不对所有文件写错位

### 3a. 确认路径

全新安装默认路径：`[记忆共享中心]/`（可自定义）

```
你的记忆文件将存放在：[用户确认的路径]
这个目录称为"记忆共享中心"——所有AI工具共享同一份记忆。
```

### 3a-2. 确认日记仓库路径

```
你的日记/笔记存放在：[用户确认的路径，如 Obsidian vault 路径]
这个目录称为"日记仓库"——存放每日日记、周报、月报。
```

### 3a-3. 确认知识库路径

```
你的读书笔记和知识池存放在：[用户确认的路径]
这个目录称为"知识库"——存放读书精华摘要、永久卡片、核心启发库。
（可与日记仓库共用同一目录，也可独立设置）
```

> 💡 **成就系统日记路径说明**：
> 成就系统脚本 `scripts/path_utils.py` 中默认日记路径为 `[日记仓库]/1-每日计划/每日日记/`。
> 如果你的日记路径子目录与官方不同（例如 `01-日记/` 或 `每日日记/`），可修改 `path_utils.py` 第12行的 `DIARY_DIR` 一行。
> 路径统一由 `platform-paths.md` 定义——改不动路径时先查那里。

### 3c. 记录路径变量

安装过程中必须记录以下路径变量，**写入 `{记忆共享中心}/.install/step3-done.md` 文件头部**：

```
📦 步骤3/7 路径配置 ✅ {date命令返回日期}

路径变量（供后续步骤从文件读取）：
MEMORY_CENTER=[记忆共享中心]
DIARY_REPO=[日记仓库]
KNOWLEDGE_BASE=[知识库]
```

> ⚠️ **所有后续步骤从 `stepN-done.md` 文件读取路径变量，不靠AI上下文传递。**
> 如果重启对话，第一步Read `step3-done.md` 获取路径。
> 如果文件不存在，说明路径未配置完成，阻塞后续步骤。
| `[日记仓库]` | 日记/笔记存储目录 | 用户自定义 |
| `[知识库]` | 读书笔记/知识池目录 | 用户自定义（可同日记仓库） |
