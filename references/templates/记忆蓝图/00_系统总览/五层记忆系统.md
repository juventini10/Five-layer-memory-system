## 层间关系

```
L1 核心层（不变的身份）
  ↕ 约束
L2 认知层（怎么想）→ 被L1的价值观约束
  ↕ 指导
L3 行为层（怎么做）→ 被L2的思维方式指导
  ↕ 产出
L4 情境层（当前状态）→ 行为层的执行结果进入情境层
  ↕ 暴露
L5 潜意识层（言行偏差）→ 对照L4快照和L1底线，发现不一致
```

## 三大思维引擎

> **三大思维**不是五层之上的附加层，而是**整个记忆系统的推理引擎**——L1-L5是"存什么"，三大思维是"怎么想"。白皮书定义完整方法论，三明智Skill是执行流程。

### 三大思维定义

| 思维 | 核心定义 | 触发词 | 白皮书章节 |
|------|---------|--------|-----------|
| **第一性原理** | 从基本事实出发，拒绝类比推理。追问到锚点（主要矛盾）→识别本质→从锚点重建→跨域映射→回验 | 为什么/本质/底层逻辑 | 第2章 |
| **抽象建模** | 从具体经验中提取共同特征，形成类别和原理。提供"后退一步"的距离感，是批判性思维的前置能力 | 分类/归纳/总结/模式 | 第3章 |
| **批判性思维** | 对思考过程本身的分析、评估和改进。元认知能力，自我批判优先，实践检验为终极标准 | 靠谱吗/真的吗/验证/检验 | 第4章 |

### 三明智Skill执行流程

| 深度 | 判定条件 | 启用思维 | 流程 |
|------|---------|---------|------|
| **L1** | 触发词匹配（分析/分类/验证） | 单思维（最少2步） | 匹配对应思维→Step-Back后退一步→分类→拆解→输出 |
| **L2** | AI复杂度自评估（不能用一句话回答） | 双思维（至少3步） | 先抽象建模/第一性原理→批判验证→交叉验证→输出 |
| **L3** | 深度关键词（全面/深度/严谨/合理/评估） | 三思维+治理层4步 | 8步完整流程：3思维层(Step1-3)+G1苏格拉底+G2验证计划+G3认知偏差+G4完成验证+G5思考质量自检（v3.3新增双Agent验证架构+路径声明） |

**执行入口**：`技能配置/三明智/SKILL.md` → Step0路由器自动判定深度 → 走对应流程

### 思维引擎与存储架构关系

| 比喻 | 对应 | 说明 |
|------|------|------|
| **文件系统** | 五层L1-L5 | 持久化存储（身份→认知→行为→状态→偏差） |
| **OS内核** | 三大思维 | 思维引擎（怎么思考、怎么判断、怎么推理） |
| **可执行程序** | 9个Skill | 强制流程（触发后走几步+每步产出什么，有步骤锁） |
| **fstab挂载表** | 路由表 | 调度规则（定义什么场景读哪层，但无流程锁，是文档级指令） |

> **核心关系**：没有五层，三大思维没有东西可以推理；没有三大思维，五层只是一堆不会动的静态文件；没有Skill，三大思维只有定义没有强制流程。

## 数据流

### 冷启动流程（新会话）

```
新会话启动
  ↓
唤醒记忆系统触发（轻量1步~12K / 全量3步~60K 双模式）
  ↓
路径发现 → 版本门禁 → 分级加载核心文件（L1-L5+路由表+平台专属）
  ↓
完整性校验 → 输出刷新报告
  ↓
AI获得完整上下文，进入用户任务
```

### 事件触发流程（Skill执行）

```
用户输入 → 匹配触发词
  ↓
├─ 三明智触发 → 深度判定(L1/L2/L3) → 执行对应思维流程 → 产出签名
├─ 唤醒记忆系统触发 → 轻量/全量模式路由 → 加载核心文件 → 输出报告
├─ 每日伙伴触发(A-F) → 日记/规划/复盘/周报/月报/同步流程 → 产出喂L4+L5
├─ 读书助手触发 → 4阶段书籍处理 → 9模块笔记→Obsidian知识库
├─ 系统日志触发 → 5步写入+3层校验 → 写入当日日志
├─ 成长箱触发 → 错误记录/晋升检查/错误蒸馏/通知处理 → 写入成长箱文件
├─ 迁理之外触发 → 匹配哲学视角 → 辩证分析 → 综合结论
├─ Shall We Talk触发 → 读书笔记联动 → 深度对话 → 沉淀自定义层
└─ skill-lookup触发 → Skill库搜索 → 返回匹配结果+调用指南
  ↓
记忆琥珀备份（修改文件时自动）
```

### 定期流程（维护周期）

```
每天：日记/晚间复盘 → 每日伙伴 → 提取目标/情绪/睡眠 → 喂L4+L5
每周：周报 → 检查行为漂移 → 更新SHADOW
每月：月度校准 → 记忆蒸馏 → SHADOW审计 → 更新动态状态快照
升级：记忆琥珀备份 → 变更日志 → 校准本文件日期
```
