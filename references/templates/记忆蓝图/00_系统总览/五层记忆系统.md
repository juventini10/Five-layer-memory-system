## 顶层愿景锚点（布洛陀演进愿景）

> 本系统一切改造的方向标（权威源：`~/[记忆共享中心]/README.md` §演进愿景）。**五层记忆系统全部设计/升级必须服务此愿景——愿景不匹配的设计不做，愿景冲突的设计降级。**
> 📜 **设计哲学参考**：本架构卡是地图（系统是什么），根宪法见 `记忆蓝图/00_系统总览/五层记忆系统设计哲学/`（00宪法愿景/01通用规范/02实例/03进度看板）——系统为什么存在、如何进化，以根宪法为最高判据。

**系统愿景**：五层记忆系统从「人工精编的静态知识库 + 部分执行自动化」演进为**自主进化的活系统**——**全自动化 · 越用越好用 · 自主自动进化 · 越用越了解使用者**（LLM 版见 核心层/DSH宪法.md·2026-08-16）。

**机制杠杆（第一性原理）**：补齐当前缺失的「学习闭环」——每次交互自动留痕 → 自动蒸馏进 L1–L5 记忆与路由/索引 → 自动作用于未来行为，全程在守卫家族护栏下安全自主演化。

**愿景 → 五层映射**：

| 愿景支柱 | 五层记忆系统含义 |
|---------|-----------------|
| 全自动化 | 采集/蒸馏/反哺全程机制化（每日伙伴采集→概念抽取蒸馏→月报反哺） |
| 越用越好用 | 数据积累自动提升贴合度（知识池/灵感匹配/认知画像聚合） |
| 自主自动进化 | 学习闭环自我强化（残差驱动/碰撞消费/评级校准/版本门禁自愈） |
| 越用越了解使用者 | L4 情境 + 行为数据（正反向全记录）+ 言行一致性 → 认知画像 |

**子系统设计哲学**：各 Skill 宪法级设计哲学见 `记忆蓝图/02_设计理念/`（17 个文件夹·00宪法愿景/01通用规范/02实例×4/03进度看板 同构四层架构）——愿景匹配度三问（①强化学习闭环吗 ②减少人工吗 ③更懂你吗）是各子系统升级前的必过门槛。

## 层间关系

```
L1 核心层（不变的身份）
  ↕ 约束
L2 认知层（怎么想）→ 被L1的价值观约束
  ↕ 指导
L3 行为层（怎么做）→ 被L2的思维方式指导
  ↕ 产出
L4 情境层（当前状态）→ 行为层的执行结果进入情境层
  ↕ 暴露
L5 潜意识层（言行偏差）→ 对照L4快照和L1底线，发现不一致
```

## 三大思维引擎

> **三大思维**不是五层之上的附加层，而是**整个记忆系统的推理引擎**——L1-L5是"存什么"，三大思维是"怎么想"。白皮书定义完整方法论，三明智Skill是执行流程。

### 三大思维定义

| 思维 | 核心定义 | 触发词 | 白皮书章节 |
|------|---------|--------|-----------|
| **第一性原理** | 从基本事实出发，拒绝类比推理。追问到锚点（主要矛盾）→识别本质→从锚点重建→跨域映射→回验 | 为什么/本质/底层逻辑 | 第2章 |
| **抽象建模** | 从具体经验中提取共同特征，形成类别和原理。提供"后退一步"的距离感，是批判性思维的前置能力 | 分类/归纳/总结/模式 | 第3章 |
| **批判性思维** | 对思考过程本身的分析、评估和改进。元认知能力，自我批判优先，实践检验为终极标准 | 靠谱吗/真的吗/验证/检验 | 第4章 |

### 三明智Skill执行流程

| 深度 | 判定条件 | 启用思维 | 流程 |
|------|---------|---------|------|
| **L1** | 触发词匹配（分析/分类/验证） | 单思维（最少2步） | 匹配对应思维→Step-Back后退一步→分类→拆解→输出 |
| **L2** | AI复杂度自评估（不能用一句话回答） | 双思维（至少3步） | 先抽象建模/第一性原理→批判验证→交叉验证→输出 |
| **L3** | 深度关键词（全面/深度/严谨/合理/评估） | 三思维+治理层4步 | 8步完整流程：3思维层(Step1-3)+G1苏格拉底+G2验证计划+G3认知偏差+G4完成验证+G5思考质量自检（v3.3新增双Agent验证架构+路径声明） |

**执行入口**：`技能配置/三明智/SKILL.md` → Step0路由器自动判定深度 → 走对应流程

### 思维引擎与存储架构关系

| 比喻 | 对应 | 说明 |
|------|------|------|
| **文件系统** | 五层L1-L5 | 持久化存储（身份→认知→行为→状态→偏差） |
| **OS内核** | 三大思维 | 思维引擎（怎么思考、怎么判断、怎么推理） |
| **可执行程序** | 核心 Skill（包内 **10** 个·数据截止日 2026-10-03） | 强制流程（触发后走几步+每步产出什么，有步骤锁） |
| **fstab挂载表** | 路由表 | 调度规则（定义什么场景读哪层，但无流程锁，是文档级指令） |

> **核心关系**：没有五层，三大思维没有东西可以推理；没有三大思维，五层只是一堆不会动的静态文件；没有Skill，三大思维只有定义没有强制流程。
