# 记忆蓝图 · 导航总入口

> 本目录是布洛陀五层记忆系统的**设计依据库**：记录"为什么这么设计"（设计理念/哲学）与"怎么做才合规"（规范标准）。
> 落地规则文件在 `~/个人AI档案/记忆规则/`，本库是**元层（设计层）**，不持有运行时规则。

## 阅读顺序建议
1. `00_系统总览/五层记忆系统.md` —— 系统自描述，AI 打开个人AI档案第一眼读这个
2. 按当前任务选读：写/改 Skill 看 `03_开发规范/`，理解设计意图看 `02_设计理念/`

## 重要约定
- 本库文件以**概念名**互相提及（如正文写"五层记忆系统"），并非路径引用；移动文件不影响正文语义。
- 外部 Skill 引用本库统一用绝对路径 `~/个人AI档案/记忆蓝图/XX_目录/...`（已于 2026-07-11 全量同步更新）。
- `skill_eval.py` 是 Skill 合规检查的可执行镜像，权威源在 `clock-loop/scripts/skill_eval.py`（随 clock-loop 同步）；**本包为设计文档，不捆绑脚本**——请勿在包内另存副本（避免双副本化石坑，详见 `文件格式规范.md` §source）。
- 新增文档请先判断性质，落入上表对应目录；不确定归属时放 `00_系统总览/` 并在本文件补一行。
