## 1️⃣ 斯多葛 → 情绪与心态

**核心人物**：马可·奥勒留、爱比克泰德、塞内加

**核心理念**：
- 「你拥有控制你的思想的力量，而非外部事件。」— 马可·奥勒留
- 「烦恼不是来自事物本身，而是来自你对事物的看法。」— 爱比克泰德
- 「我们无法选择外部环境，但可以选择如何回应。」— 爱比克泰德
- 「你对事物的看法，决定了事物对你的意义。」
- 「不要为未来焦虑，未来要么不来，要么来了再面对。」— 塞内加
- 「命运引领愿意的人，拖拽不愿意的人。」— 塞内加
- 「有情绪是正常的，没有情绪不是人。但情绪来了之后怎么选，才是定义你的东西。」— 用户（2026-03-27）
- 「跟不经过大脑的人互怼，赢了也输了，因为你把自己拉到了他的维度。这不是忍让，是保护自己的能量不被浪费。」— 用户（2026-03-27）

**什么时候用**：
- 情绪失控、愤怒、焦虑
- 被人冒犯、遭遇不公
- 外部环境突然变化（计划被打乱、意外事件）
- 失眠、内耗、过度思考

**思考模板**：
> 这件事你能控制的部分是什么？不能控制的部分呢？把精力全放在你能控制的上面，剩下的，接受它。

## 2️⃣ 存在主义 → 人生选择与自我

**核心人物**：萨特、海德格尔、加缪、尼采、克尔凯郭尔

**核心理念**：
- 「存在先于本质。」— 你不是被定义的，你是通过选择定义自己的
- 「人是被抛入世界的，但必须为自己立法。」— 海德格尔
- 「他人即地狱。」— 萨特：过度在意他人目光，就是自我囚禁
- 「真正严肃的哲学问题只有一个，那就是自杀。」— 加缪：活着本身就是一个选择
- 「成为你自己。」— 尼采
- 「我们必须想象西西弗斯是快乐的。」— 加缪：意义是自己创造的

**什么时候用**：
- 面临人生方向选择（换工作、创业、去留）
- 自我怀疑、迷茫、找不到意义
- 过度在意别人看法
- 要不要坚持/放弃某个东西

**思考模板**：
> 这个选择 defines 你。不是选对了才成为什么样的人，而是你选了，才成为那样的人。所以问题不是「哪个选择更好」，而是「我想成为谁」。

---

## 3️⃣ 实用主义 → 工作方法与效率

**核心人物**：杜威、威廉·詹姆斯、查理·芒格、塔勒布

**核心理念**：
- 「有用即真理。」— 杜威：一个想法好不好，看它能不能解决问题
- 「不要等到万事俱备。」— 先做起来，在实践中调整
- 「反过来想，总是反过来想。」— 芒格：逆向思维是最快的捷径
- 「避免愚蠢比追求聪明更重要。」— 芒格
- 「脆弱的反面不是坚强，是反脆弱。」— 塔勒布：设计一个摔了也赚的系统
- 「如果你只有一把锤子，所有问题看起来都像钉子。」— 芒格：多元思维

**什么时候用**：
- 工作方法优化、效率提升
- 做决策（选A还是选B）
- 项目规划、风险评估
- 方案对比、取舍

**思考模板**：
> 这个方案能不能解决问题？如果不能，丢掉。如果能，先干起来再优化。别追求完美方案，追求有效方案。

## 4️⃣ 分析哲学 → 思考与表达能力

**核心人物**：维特根斯坦、罗素、卡尔纳普、奎因

**核心理念**：
- 「凡是能说的，都能说清楚；凡是不能说的，就必须沉默。」— 维特根斯坦
- 「语言的边界就是世界的边界。」— 维特根斯坦：你表达不清楚，是因为你想不清楚
- 「把复杂的事情说简单，才是真本事。」— 罗素
- 「很多哲学问题其实是语言问题。」— 把模糊的话拆成清晰的命题，问题就解决了一半
- 「定义你的术语。」— 很多争论源于对同一个词理解不同

**什么时候用**：
- 写文案、做内容、表达想法
- 情绪混乱、理不清头绪
- 和人沟通产生误解
- 需要把复杂事情讲明白

**思考模板**：
> 你刚才说的那句话，换个方式再说一遍，还能成立吗？如果不能，说明你还没想清楚。先把概念定义清楚，再讨论对错。

## 5️⃣ 唯物辩证法 → 看清规律与长期布局

**核心人物**：马克思、黑格尔、毛泽东、恩格斯

**核心理念**：
- 「事物都是对立统一的。」— 任何事都有两面性，坏事可能变成好事
- 「量变引起质变。」— 持续积累，到了临界点就会突破
- 「否定之否定。」— 发展不是直线，是螺旋上升的
- 「具体问题具体分析。」— 没有放之四海皆准的方法
- 「内因是变化的根据，外因是变化的条件。」— 别怪环境，先看自己
- 「主要矛盾和次要矛盾。」— 抓住重点，不要眉毛胡子一把抓

**什么时候用**：
- 制定长期计划、战略布局
- 遇到瓶颈、看不到进展
- 评估项目前景、趋势判断
- 复盘总结、找规律

**思考模板**：
> 这件事的「主要矛盾」是什么？你现在的精力是不是花在次要矛盾上了？量变积累到位了吗？别急，质变需要时间。

## 🔗 五大视角交叉应用

| 生活场景 | 推荐视角 | 原因 |
|---------|---------|------|
| 要不要辞职创业 | 存在主义 + 实用主义 | 先问"想成为谁"，再问"怎么落地" |
| 口播文案写不好 | 分析哲学 + 实用主义 | 先把话说清楚（分析），再看效果（实用） |
| 粉丝增长瓶颈 | 唯物辩证法 + 实用主义 | 找规律（辩证），试方案（实用） |
| 情绪低落/迷茫 | 斯多葛 + 存在主义 + 唯物辩证法 | 先稳住心态（斯多葛），再找意义（存在），最后看长期（辩证） |
| 被人冒犯/愤怒 | 斯多葛 | 你控制不了别人的嘴，只能控制自己的反应 |
| 和人产生冲突 | 分析哲学 | 先搞清楚"到底在吵什么"，多半是概念定义不同 |
| 项目规划 | 唯物辩证法 + 实用主义 | 抓主要矛盾（辩证），有效方案先干（实用） |
| 失眠/焦虑/内耗 | 斯多葛 | 未来还没来，担心没有用。回到当下你能控制的事 |
