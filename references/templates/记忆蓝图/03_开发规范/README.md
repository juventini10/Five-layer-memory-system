# 开发规范 — 总入口

> 定位：管辖所有 AI 文件的"怎么做才合规"质量体系。本文件是**路由入口**，不重复各规范内容，只告诉你"遇到 X 读哪本、规范间怎么互不踩"。

## 路由规则

当你被要求"读取开发规范，检查某个文件"时，先按以下规则判断读哪本：

| 文件类型 | 需读取的规范 |
|---------|-----------|
| `SKILL.md`（Skill 文件） | `Skill架构规范/`（入口 `Skill架构规范.md`）+ `指令编写规范.md` |
| 规则/配置文件（铁律版、摘要版、CORE、SHADOW、SOUL、IDENTITY、USER 等） | `指令编写规范.md` |
| 发布包文件（安装包、步骤文件、INSTALL.md、rollback.sh 等） | `发布包编写规范.md` + `指令编写规范.md` |
| 新建/改造任意 AI 文件（先过格式关） | `文件格式规范.md` |
| 分不清类型 | 先读本文件，再根据文件内容判断 |

## 规范清单（7 份正式规范）

| 规范 | 管什么 | 核心要点 |
|------|--------|----------|
| `Skill架构规范/`（目录，入口 `Skill架构规范.md`） | Skill 的结构/触发/安全/测试/行为契约 | 四层契约·安全十维·评估门禁·多 Skill 共存·行动可逆性分级 |
| `指令编写规范.md` | 所有 AI 文件的话术质量 | 禁令+正面双轨·因果链强制·注入防御·幻觉防护（内部版本 v4.2） |
| `发布包编写规范.md` | 发布包构建验证强制清单 | 入口分流·五道锁·熔断器·审计闭环·自动化冒烟 |
| `文件格式规范.md` | 任意 AI 新建/改造文件的格式骨架 | YAML 头字段集·首因高地·三段式·CHANGELOG 外置 |
| `版本命名规范.md` | 版本号/变更标记规则 | 语义化版本·升级来源标注 |
| `跨平台改造标准.md` | 跨平台（macOS/Win/Linux）改造约束 | 路径/编码/二进制兼容 |
| `跨系统协作规范.md` | 多系统/多工具协作接口约定 | 数据交换·边界·幂等 |

> 临时文件 `指令编写规范_合规体检.md` 已于 2026-07-11 移至 `自定义层/待完成工作/指令编写规范改造验证/`，属合规体检过程产物，非正式规范，不列入上述清单。

## 互引声明

- `Skill架构规范/` 的指令质量部分不再重复——引向 `指令编写规范.md`
- `指令编写规范.md` 的 Skill 结构部分不再重复——引向 `Skill架构规范/`
- `发布包编写规范.md` 的指令写法不再重复——引向 `指令编写规范.md`
