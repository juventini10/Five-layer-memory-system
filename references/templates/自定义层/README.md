# 自定义层

这个目录属于你。

五层记忆系统的 L1-L5 记录的是"你是谁"——你的价值观、思维模式、行为习惯、当前目标。
但有些东西不属于这些分类，却又很重要。

## 用它来做什么

### 存档未完成的工作

今天做不完的项目，写一个进度文件。明天告诉 WorkBuddy 去读取，接着干。

```
自定义层/
└── 布洛陀PPT.md

内容示例：
## 当前进度
- 封面页配色：✅ 完成
- Skill联动页：⏳ 数据表格已写好，待加动画效果
- 发表文案：❌ 未开始
## 下一步
1. 给联动表加上鼠标悬停高亮
2. 调整第三页的字体间距
```

### 跨对话续接工作

当前对话框上下文快满了，或者你想换个工具继续——
把进度写到自定义层，新对话里告诉 AI 去读取，接着干。

### 存放临时项目文件

一个项目的背景资料、调研笔记、待办列表——放这里而不是散落在各处。

### 记录你的"框架外"想法

五层记忆覆盖了"你是谁"，但覆盖不了"你今天突然想到的、不一定有用但不想忘的东西"。

## 使用原则

- 文件命名用中文，一看就知道是什么
- 想继续推进时，告诉 AI："去读 自定义层/XXX.md"
- 系统不会自动读这里的文件，也不会覆盖——完全由你管理
- 不要放密码和密钥

## 目录结构示例

```
自定义层/
├── 布洛陀PPT.md          ← 项目进度
├── 视频选题集.md          ← 创作素材
├── 2026-Q2复盘草稿.md     ← 临时文档
└── 项目A/
    ├── 调研笔记.md
    └── 待办清单.md
```
