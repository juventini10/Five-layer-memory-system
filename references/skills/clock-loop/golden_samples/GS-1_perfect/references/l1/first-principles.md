> **触发**：用户仅含"分析/本质/底层/为什么/原因/第一性原理/拆到不能拆/主要矛盾"等关键词，无"分类/验证"等双路由触发词
> **步骤**：4步 | **模板**：共用锚点两列（→ 见 `references/shared/anchor.md`）+ 共用结论块门禁锁（见SKILL.md §结论块模板）+共用签名（→ 见 `references/shared/signature.md`）
> **呈现层（2026-08-11 内嵌 · v3.14.0 精简）**：本文件各步骤内嵌呈现格式——中间推导（追问表/锚点表/本质表）⛔不渲染，仅结论块+签名渲染（2026-08-12 C-1 落地：头部声明对齐 v3.14.0 精简语义，旧"表格化/翻译行/结论置底"表述退役）。机制不变，呈现翻译变（你批准：呈现优化直接长在原版，废除独立呈现层模板）

## 开始前：路径声明（对话第一个输出）

在任何步骤执行前，以以下格式输出路径声明作为**对话第一条回复的首行**：

```
三明智 L1 路径：第一性原理
```

声明后进入Step1。

## Step2：识别本质

| 要素列举（不是本质） | 本质（要素间的关系和结构） |

| | |

**本质≠要素清单。** 本质是"这些要素之间是什么关系、什么结构导致了这个问题"。

🛡️ **验证标准**："本质"列是否揭示了要素间的关系结构（不是要素清单复述）

**呈现格式（v3.14.0 呈现精简：内部执行，⛔不渲染——本质表只在执行链内生成）**

## Step3：结论块+门禁锁

→ 渲染模板见 SKILL.md「结论块」段（内联模板唯一源）（结论块独立输出→门禁锁3问自检→通过后进入签名）

🔒 **结论位置锁（你批准·2026-08-11）**：结论块是**回复最后一项**（之后只有签名）——⛔ 结论不得出现在推理过程中间/开头。推理过程在上（可翻），结论在下（底部·离输入框最近）。

## Step4：签名

→ 见 `references/shared/signature.md`

格式：`[🧠 三明智 L1 (第一性原理) ✅ | 结论块浓缩版 | 日期]`

> 摘要✅DO是 Step3 结论块的浓缩版（不多不少），⛔DO NOT只写锚点——依据 SKILL.md §禁止行为 #5。
> 呈现注：签名后接署名（`—— 你的 {工具署名}`），签名是回复的最后一行内容（结论块之后仅剩签名+署名）。
