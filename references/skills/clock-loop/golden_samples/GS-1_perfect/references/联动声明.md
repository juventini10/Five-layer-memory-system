# 三明智 triwich — 与其他 Skill 的联动

> 本文件是 `[记忆共享中心]/记忆蓝图/02_设计理念/皮叔Skill联动设计哲学.md`（v1.2）的补充声明。依赖形态定义见该文件 §3.3，非数据关系（互补/互斥/复用）见 §3.4。
> 更新注：2026-08-04 旧《皮叔Skill联动哲学.md》已归档至 `[记忆共享中心]/归档/设计记录/`，本声明对齐对象为新哲学 v1.2。

| Skill | 方向 | 机制 | 说明 |
|-------|:---:|------|------|
| 唤醒记忆 | 读(上游) | 确认记忆已加载后再执行分析 | 依赖记忆系统提供用户偏好/情境 |
| 系统日志 | 写(下游) | 结果沉淀：签名输出+写入系统日志 | 每次分析结论落库 |
| clock-loop | 被固化引用 | 评估标准固化到 clock-loop/references/triwich-integration.md | clock-loop 用本Skill的尺子做质量评估 |
| 迁理之外 | 互补 | 逻辑↔哲学：触发词重叠时三明智主导逻辑层，需哲学视角回调迁理之外 | 三层互斥(逻辑↔哲学↔自我) |
| Shall We Talk | 互斥 | 管辖划分：SWT 管"自我认知探索"，三明智管"逻辑结构分析"。触发词若同时命中 → 按对象判：对象是**用户自身**归 SWT，对象是**外部问题/方案**归三明智 | 非数据联动，属管辖边界 |

**退出条件（与 SKILL.md §管辖权重叠 一致）**：用户说"好了""够了"→退出；连续 3 轮无新视角→自然退出。（来源：标准规范§7.1）

> ⚠️ 单侧声明：本表是 **triwich 侧**的声明。对端 Skill（Shall We Talk / 迁理之外）是否有对称声明**不在本文件保证范围内**——跨 Skill 一致性须由对端各自补齐，交接待办已记录于 triwich v3.11.0 评估报告候选台账 M11。
