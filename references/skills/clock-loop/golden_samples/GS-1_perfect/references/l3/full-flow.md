## 🔴 {ts} 格式规范（v3.0.5·定位键唯一性）

**`{ts}` = `YYYYMMDD_HHMMSS`（如 `20260809_185852`），由 Bash `date "+%Y%m%d_%H%M%S"` 实取，⛔DO NOT 自造格式或凭记忆填。**

- 历史反例（2026-08-09 实测）：`2026-08-08-19-56` / `20260808` / `20260808_1633` / `20260809_185852` 四种格式并存，其中 `20260808` 为纯日期粒度——同日复用会命中同一目录，幂等检查读到的可能是上一轮残留，Agent B 被静默跳过。
- ⛔DO NOT 用 `%Y%m%d`（纯日期）——时间粒度必须到分钟，否则同日多轮会话共享一个目录。
- 目录创建：`mkdir -p /tmp/triwich_l3_{ts}`（Linux/macOS）｜ `New-Item -ItemType Directory -Force $env:TEMP\triwich_l3_{ts}`（Windows）。

**交叉验证**：

### 签名反造假规则（v3.0更新）

签名出现 ✅ 时，摘要必须引用以下三者至少各一处：

| 来源 | 必须引用的证据 |
|------|--------------|
| G1 苏格拉底诘问 | 五问中至少一问的**具体答案**（不能写"已诘问"） |

签名造假 = 签了✅但摘要无证据引用 = 输出无效。

## Agent B 失败处理

| 场景 | 处理 |
|------|------|
| Agent B正常返回✅/❌ | 正常流程 |
| Agent B回传为空（但当前会话 `{ts}` 精确路径下 agent_b_review.md 存在且非空） | ⛔DO NOT重发、⛔DO NOT降级——先 Read 磁盘文件，视为完成，直接读取审查结论。**完成判定以磁盘文件为真相源，回传通道仅作通知**（v3.10.1 新增·2026-08-08 事故实证：443行报告完整落盘但回传空，主 agent 误判失败重发造成重复等待） |
| Agent B回传为空（且当前会话 `{ts}` 精确路径下文件不存在/为空） | 才可重发或按降级处理 |
| Agent B超时（>120s） | 降级为单Agent Step3自检。**签名一律标 ❌** + 输出缺失清单「Agent B 未执行（超时降级）」——⛔DO NOT签 `✅ ⚠️降级`：降级=步骤未走完，签名轴无第三值（v3.0.4·M1修复，依据 shared/signature.md「⚠️/部分✅/降级=视为❌」） |
| Agent B连续3次❌ | 提示用户"Agent B连续3次打回Agent A的结论——是否需要调整分析框架？" |
| Agent B无响应/崩溃 | 同超时处理 |

**🔍 异常留痕规则（v3.10.1 新增）**：任何 Agent B 异常（回传为空/超时/无响应/连续❌）处理完成后，✅DO 在系统日志记录实际处理路径（重发/读文件/降级+原因）——验证数据自动采集，供后续行为验证追溯（2026-08-08 设计：落实 G2-5 行为验证的观测点，不依赖人工盯对话）。
