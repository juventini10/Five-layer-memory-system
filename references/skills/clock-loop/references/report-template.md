## 一句话·温度话术库（v3.33.2新增·皮叔拍板·来源=知识池文案原则）

**六条写法纪律**（来源：爆款文案·感官占领"写感官不写形容词" / 南方周末写作课"场景式开头+短句力量+抽象阶梯" / 短视频爆款"15秒只打1个爆点" / 咸的玩笑"具体+有立场"）：
1. **写具体不写形容词**——"真跑过"胜过"很可靠"，"差5分"胜过"还有提升空间"
2. **一个类比胜过一句评价**——用画面/场景说话，不用抽象评价
3. **短句**——力量感，一句拆两句
4. **顶端给意义、底端给细节**——先结论后细节
5. **克制**——一句话只打一个点，打两个等于都没打
6. **温度来自立场**——像搭档说话、替你着想，⛔不玩梗/⛔不油腻/⛔不用客服腔

**话术库（按结果状态选，可微调但守住六条纪律）**：
- S级·实测通过：①「S级{分数}分，剩下的几分是"下次还能更好"——该冒的烟冒了，该跑的测试跑了，用吧。」②「这台不是纸糊的：文档挑不出毛病，真跑也跑得通。可以上桌。」
- S级·静态文档级（未实测）：①「S级{分数}分，但这是模拟考成绩——文档满分，实战卷还没动笔。上生产前，先真跑一次。」②「优等生一枚，考场还没进过。别急着吹，先遛一圈再说。」
- 未达·已停（A/B级）：①「{等级}级，不是不能打——是还有几颗螺丝没拧紧。差在哪，扣分项写得清清楚楚。」②「离S级就差一口气。想把这口气提上来，说一声，马上开工。」
- 卡死·建议重构：①「不是不够努力，是这条路本身到顶了。地基得重打——建议换个结构，从头来。」②「硬扛扛不过去，得先退一步重新画图纸。卡在哪、怎么改，建议里写好了。」
