### 🧠 思考检查点
```
🧠 思考检查点
├─ 数据完整:标准收集了任务类型+检查清单+审查标准+终止条件?
├─ 执行合规:没引入预设标准之外的要求?
├─ 钩子有效:当前Skill执行路径是否对任务有帮助?
├─ 安全合规:没把用户给的路径/信息硬编码到SKILL中?
└─ 预算合理:最大轮次设了上限,不会无限烧Token?
```

🔌 熔断器
├─ 成功条件：用户清晰选择了每项标准
├─ 失败处理：降级
└─ 降级方案：用户说"你看着办"→优先按JSON中该任务类型的预设标准执行；若无匹配→使用默认标准(平衡模式+3轮)。对模糊回答追问1次，仍模糊→默认标准
