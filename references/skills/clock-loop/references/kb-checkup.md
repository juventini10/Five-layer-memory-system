## 二、矛盾清单生命周期（辩证法审前置②·豁免状态住真相源）

矛盾清单每行schema含 `status` 字段（唯一取值集）：

```
status: 新发 | 已阅(n=累计呈报次数) | 已扬弃(处理:改卡|豁免:理由|转悬置区) | 已归档
```

- **折叠规则**：已阅n≥3的旧矛盾在体检报告中折叠为一行计数——原因是旧矛盾反复重现会淹没新矛盾，一人维护者的注意力是最先耗尽的资源
- **豁免即status取值**：豁免理由住矛盾清单本身，⛔DO NOT另建豁免表/白名单文件——原因是审计侧长出独立豁免表=第二真相=守卫三案结构重演（守卫编写规范原则1）
- 矛盾清单物理住所：`[记忆共享中心]/脚本中心/知识联邦引擎/矛盾清单.md`（kb_concept_lint.py 统计积压的唯一读取源）——**作者侧私有引擎·未随本安装包分发**（端用户走 `N/A（个人工具·未安装）`，跳过本体检段不影响其他检查）。

### 知识库体检路径（v3.11.0新增·Phase X-KB·循环 知识体检模式）

📦 产出物:知识库体检报告(机械段五检0 FAIL + 语义段"检测完成+已路由")

**触发识别**:阶段1 Poka-Yoke 预填检测到"知识体检/知识库Lint/概念层" → 任务类型=H.知识库体检 → 进入本路径(挂E骨架同构:机械段+语义段双层)。重档细则(谓词表+矛盾清单生命周期schema+消费指标)✅DO Read `references/kb-checkup.md`——原因是细则外置控SKILL.md行数,骨架只管路由与门禁。

**Phase X-KB·机械段（脚本确定性·clock-loop零直写）**
- Step B：调用知识库Lint重档(步序法·物理依赖)
  - ✅DO `python3 [记忆共享中心]/脚本中心/知识联邦引擎/scripts/kb_concept_lint.py --heavy`
    重档=轻档全项(孤儿/待重蒸/降级)+向量重建+积压统计,产出 `.kb_lint_last_run.json`。lint呈报不裁决——重蒸/改卡由生产脚本执行,⛔DO NOT由clock-loop直写概念卡——原因是生产/审计分离,审计者直写=既当运动员又当裁判(#S003结构)。
  - ⚠️外部引用权衡留痕(v3.30.0·§11.2 vs §2)：本路径引用 Skill 目录外绝对路径脚本——自用 Skill 依 §2 路径策略允许 `~/` 绝对外部路径，但换机/开源时须把脚本自包含进本 Skill（§11.2 开放引用原则），否则断链。
  - 防抖:脚本退出码3=知识联邦引擎log.md最新条目<60秒(时序协议)→等待60秒后重跑一次;仍为3→提示你"管道正在写入,稍后再试",本轮中止
- Step C：Read 脚本产出物(步序法·物理阻断)
  - ✅DO Read `[记忆共享中心]/脚本中心/知识联邦引擎/.kb_lint_last_run.json`
  - Read返回非空JSON → ✅解锁,进入语义段;返回空/文件缺失 → 🔴物理阻断,退回Step B补跑
  - 五检(孤儿/待重蒸/降级/积压/向量重建)判定:0 FAIL → 机械段达标;任一FAIL → 输出缺陷报告(卡ID+失效源+对应谓词)。"待重蒸"是标记非FAIL,不阻断——原因是mtime粗筛有已知假阳性,重蒸无损,假阳性代价=多蒸一次

- **达标标准**:机械段0 FAIL + 语义段"检测完成+已路由" + 消费指标门槛(矛盾积压>20→🔴FAIL阻断语义段绿灯,>10→⚠️警告,详见kb-checkup.md)。⛔DO NOT把矛盾清零当达标——原因是矛盾是碰撞燃料,清零=杀死知识进化信号
