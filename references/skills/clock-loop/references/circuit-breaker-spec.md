# 熔断器降级规范

> version: v1.1 | 日期: 2026-09-05 | 来源: SKILL.md（⛔本处不写源版本号·以 SKILL.md frontmatter 为唯一真相源＝#142·v1.0曾用"管道一行式"第四种标注格式已废）
>
> 本文件记录**阶段主干6个熔断器**的触发条件、降级方案和外显信号。
> **熔断器全集以全库 `grep -rn "🔌 熔断器"` 为唯一源（2026-09-05 A24实测：实体22处·本表仅覆盖阶段主干6个＝#176修法"总览表改指针"——v1.0自称"所有熔断器完整规范以此文件为准"实为覆盖率40%的假权威·路径内细则熔断器（kb-checkup/pkg-checkup/thinking-checkpoints/phase1.5等）在其所属细则文件内完整定义即可**。SKILL.md中各阶段内联熔断器为本文件的速查摘要。

## 熔断器总览

| # | 位置 | 熔断器名 | 触发条件 | 降级方案 |
|---|------|---------|---------|---------|
| 1 | 阶段0触发判定 | 触发判定 | 触发条件以 SKILL.md frontmatter description 为唯一源（⛔本处不枚举触发短语防漂移＝#142·v1.0曾写"不以循环/loop开头"漏4类触发短语滞后2个月＝#176②） | 不触发，正常对话 |
| 2 | 阶段1标准收集 | 标准收集模糊 | 用户回答模糊，追问1次仍模糊 | 使用默认标准（平衡模式+3轮） |
| 3 | 阶段1.5知识网络 | 文件加载失败 | patterns或weights文件加载返回空 | patterns→general_evaluation / weights→等分权重 |
| 4 | 阶段2自查循环 | 自查未达标 | 3次内部循环仍未达到85% | 跳子Agent审查，如实记录当前分数 |
| 5 | 阶段2审查环节 | 轮次用尽 | 达到最大轮次仍有未通过项 | 超限终止，交付当前版本+未通过项清单 |
| 6 | 阶段2子Agent | spawn失败 | 子Agent spawn失败或超时 | 降级为自检+自查清单核对 |

## 外显信号格式

所有熔断器触发降级时，必须输出外显信号：

```
⚠️ 熔断器触发:{熔断器名}({具体原因}) → 降级方案:{降级内容}
```

### 各熔断器外显信号

| # | 熔断器名 | 外显信号 |
|---|---------|---------|
| 1 | 触发判定 | 不触发时无输出（正常对话不需要信号） |
| 2 | 标准收集模糊 | `⚠️ 熔断器触发:标准收集模糊({原因}) → 降级方案:使用默认标准(平衡模式+3轮)` |
| 3 | 文件加载失败 | `⚠️ 熔断器触发:{patterns/weights}加载失败 → 降级方案:{general_evaluation/等分权重}` |
| 4 | 自查未达标 | `⚠️ 熔断器触发:自查3次未达标({当前分数}%) → 降级方案:跳子Agent审查,如实记录` |
| 5 | 轮次用尽 | `⚠️ 熔断器触发:轮次用尽({已用N轮}) → 降级方案:超限终止,交付当前版本+未通过项` |
| 6 | spawn失败 | `⚠️ 熔断器触发:子Agent spawn失败/超时 → 降级方案:自检替代,如实记录` |

## 降级链路图

```
用户输入
  │
  ├─ 非触发短语输入 → 熔断器1: 不触发,正常对话（触发判定以SKILL.md description为准·本图不枚举）
  │
  └─ 含"循环/loop" → 阶段1标准收集
       │
       ├─ 用户回答模糊 → 熔断器2: 默认标准(平衡模式+3轮)
       │
       └─ 标准收集完成 → 阶段1.5知识网络
            │
            ├─ patterns/weights加载失败 → 熔断器3: general_evaluation + 等分权重
            │
            └─ 加载成功 → 阶段2循环执行
                 │
                 ├─ 自查3次未达标 → 熔断器4: 跳子Agent审查
                 │
                 ├─ 子Agent spawn失败 → 熔断器6: 自检替代
                 │
                 ├─ 子Agent审查不通过 → 修正 → 重试
                 │    │
                 │    └─ 轮次用尽 → 熔断器5: 超限终止
                 │
                 └─ 子Agent审查通过 → 阶段3交付
```

## 更新规则

- 新增**阶段主干**熔断器时，必须同步更新本文件的总览表、外显信号表和降级链路图（v1.0此规则存在但9次新增全部未执行＝#176——治法不是更严的prose而是本文件不再自称全集·全集唯一源=`grep -rn "🔌 熔断器"`）
- SKILL.md中各阶段的熔断器块为速查摘要；本文件=阶段主干6个的完整规范（路径内细则熔断器归其所属细则文件·见头部scope声明）
- 本文件自带独立 version（v1.1起）·⛔不再"跟随SKILL.md主版本号"（独立可对账·防第四种格式漂移）
