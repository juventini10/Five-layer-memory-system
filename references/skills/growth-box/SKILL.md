### 0. 流程内步序强依赖（步序式防错）

- **锚点**：A1→A2→A2.5→A3 / B1→B2→B3→B3.5→B4 / C1→C2→C3→C3.5→C4→C5→C6 / E0→E1→E2→E3→E3.5→E4→E5→E6→E7→E7-b→E8→E9→E9.1→E9.2——流程内强依赖，流程间独立触发（串＝下方「总步口径」下的全部步骤节点，与分母同数：A4／B5／C7／E14）

### 1. 错误分类固定5级（定值式防错）

- **防什么**：AI自创错误分类标签，导致分类泛滥、无法统计聚合。
- **机制**：错误必须归入5个固定分类之一（流程/验证/身份认知/技术实现/其他），不可自创分类。5级 = 定值，少一级或多一级 = 阻断。
- **阻断条件**：错误类型不在5级范围内 → 阻断写入，要求用户/AI重新归类到合法分类。
- **对应步骤**：流程A步骤A1（判断错误类型）。

### 2. 晋升次数定值3次（定值式防错）

- **防什么**：AI自行调整晋升阈值（如2次就晋升或5次才提醒），导致阈值漂移、晋升机制失效。
- **机制**：错误必须重复出现3次才触发蒸馏晋升。3次 = 定值，不可由AI自行调整阈值。状态标注固定为 `pending(N/3)`，N<3不晋升，N≥3才进入晋升检查。
- **阻断条件**：N<3 的模式被输出为"待晋升" → 阻断，回退筛选；N≥3 但未提醒 → 回退步骤B2补全。
- **对应步骤**：流程B步骤B2（筛选pending模式）。

### 3. 错误归档格式Schema（接触式防错）

- **防什么**：错误归档字段缺失，导致错误记录无法追溯根因和修复方案。
- **机制**：错误归档必须包含固定字段——编号/名称、日期（Logged）、类型（5级之一）、优先级(Priority)、状态、来源AI、认知象限、**描述（Details·BIC三段式：事实/影响/后果·v1.14.4）**、根因、Rule/Why/How to apply（Body三段式）；完整14字段清单见步骤A2。字段缺失 = 脚本闸门阻断（v1.12.0·`scripts/growth_box_schema_check.py` exit 2=拒写回补，绕过留痕被复核逮出）。
- **阻断条件**：必填字段缺失或为空 → 阻断写入，回到步骤A2按模板补齐字段后再写入。
- **对应步骤**：流程A步骤A2（按格式写入）。

### 3.1 认知象限必填（接触式防错·四维认知轴 step③）

- **防什么**：错误条目缺「认知象限」字段，导致四象限设计哲学·认知轴第二象限（已知未知）无法在成长箱落地、统计断裂。
- **机制**：每条错误归档必须含 `认知象限` 字段，取值为 `已知未知（收集中）` 或 `已知已知（已解决）`。默认 `已知未知（收集中）`（记录时知道有错、在收集模式确认）；Status=resolved/promoted 时须标 `已知已知（已解决/已蒸馏）`（错误已澄清→晋升为已知已知）。
- **阻断条件**：认知象限字段缺失/为空/取值非法 → 与 Schema 其他字段同条件阻断写入，回到步骤A2按 `references/错误记录模板.md` 补齐后再写入。
- **对应步骤**：流程A步骤A2（按格式写入）+ 流程B步骤B4（晋升时同步将认知象限由"已知未知"改为"已知已知"）。

## 🔒 产出物级联锁（防跳步机制）

步序法（动作步序）——级联锁约束**流程内步序**，不约束流程间顺序：四个流程按意图独立触发、互不依赖（与铁律声明"4个流程数据源和执行逻辑完全不同"一致）。流程内强依赖：A1→A2→A2.5→A3 / B1→B2→B3→B3.5→B4 / C1→C2→C3→C3.5→C4→C5→C6 / E0→E1→E2→E3→E3.5→E4→E5→E6→E7→E7-b→E8→E9→E9.1→E9.2。上步产出物未完成不可执行下步，产出物锁缺失→退回上步重产→仍不可达→中止，不可自行跳步或降级执行。阻断条件=产出物空或文件不存在=回到步骤补全。

> **总步口径（v4.12.2 定·单一命令可复核）**：状态行 `{总步}` ＝对应 flow 文件内**标题以「步骤」开头**的 `####`／`#####` 小节数，复核命令 `grep -cE "^#{4,5} 步骤" references/flow-{字母}.md` → **A4／B5／C7／E14**。说明：①流程B 的「停滞类型判别」v4.12.2 起编号为 **B3.5**（对齐 C3.5 先例），使该口径与串一次对齐、⛔不留特例；②"重要度判定""兜底机制"这类说明性 `#####` 子节不计入分母（它们不是可路由节点）；③v4.10.1/v4.12.1 曾记 "E16"，系把说明性子节计入所致，本条为口径归真（⛔视为数值改动，实为定义补齐）。⛔DO NOT 凭手感写分母——分母不可复核＝骨架硬规则2「N 一致性可 grep」失去仪器。

| 机制 | 原理 |
|------|------|
| **步骤产出物锁** | 每步定义必须产出的具体产物，后续步骤依赖前序产物 |
| **上步校验锁** | 在蒸馏报告生成前、晋升确认前，先读取上一步的产出物文件。产出物缺失或不完整→回溯执行，补齐后再继续 |
| **报告完整性锁** | 蒸馏报告含必填字段清单（详见 references/蒸馏报告模板.md），缺字段=任务未完成 |

**执行规则**：每步开始前声明产出物→执行后确认产出物已生成→跳步=引用断裂=回溯执行。
