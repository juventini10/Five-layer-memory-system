# 晋升确认模板

> **用途**：成长箱Skill流程B（晋升检查）步骤B4的晋升确认格式模板
> **引用方式**：SKILL.md流程B步骤B4引用此模板

## 晋升确认格式

```markdown
## 晋升确认

**错误模式**：[编号] [模式名称]
**出现次数**：N次
**最新发生**：YYYY-MM-DD
**晋升目标**：[规则文件路径]
**晋升日期**：YYYY-MM-DD

### 精炼规则

[将错误模式提炼为可执行的规则，1-3条]

### 来源标注

[来源: 成长箱晋升 | 来源文件: {文件名} | 错误: {错误类型} | 晋升日期: {日期}]

### 晋升操作清单

- [ ] 写入规则文件：[路径]
- [ ] 更新记忆系统对应条目
- [ ] 成长箱原条目标记 `Status: promoted`
- [ ] INDEX.md状态更新为"已晋升"
```

## 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| 错误模式 | ✅ | 编号+模式名称 |
| 出现次数 | ✅ | 错误累计次数 |
| 最新发生 | ✅ | 最近一次发生日期 |
| 晋升目标 | ✅ | 要写入的规则文件路径 |
| 精炼规则 | ✅ | 从错误中提炼的可执行规则 |
| 来源标注 | ✅ | 标准格式：`[来源: 成长箱晋升 | ...]` |
| 晋升操作清单 | ✅ | 4项操作逐项确认 |

## 晋升路径对照

| 错误来源 | 晋升目标 |
|----------|---------|
| LEARNINGS.md（通用纠正） | `用户基本规则-铁律版.md` |
| `{tool}_errors.md`（工具专属） | `~/.{tool}/rules/` 或对应系统规则文件 |
| skill_errors.md | `技能配置/{skill}/SKILL.md` |
