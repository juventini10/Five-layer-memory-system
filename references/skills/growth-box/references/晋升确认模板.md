# 晋升确认模板

> **用途**：成长箱Skill流程B（晋升检查）步骤B4的晋升确认格式模板
> **引用方式**：SKILL.md流程B步骤B4引用此模板

## 晋升确认格式

```markdown
## 晋升确认

**错误模式**：[编号] [模式名称]
**出现次数**：N次
**最新发生**：YYYY-MM-DD
**晋升目标**：[规则文件路径]
**晋升日期**：YYYY-MM-DD

### 精炼规则

[将错误模式提炼为可执行的规则，1-3条]

### 来源标注

[来源: 成长箱晋升 | 来源文件: {文件名} | 错误: {错误类型} | 晋升日期: {日期}]

### 晋升操作清单

- [ ] 写入规则文件：[路径]
- [ ] 更新记忆系统对应条目
- [ ] 成长箱原条目标记 `Status: promoted`
- [ ] 同步认知象限：原条目 `认知象限` 由「已知未知（收集中）」改为「已知已知（已解决/已蒸馏）」（与 Poka-Yoke 3.1 / SKILL.md 步骤B4-5.5 一致）
- [ ] 标注TTL：`[TTL: 90d | 过期: {YYYY-MM-DD}]`（初始过期日=晋升日期+90天；与 SKILL.md 步骤B4-3 一致——v1.12.1 漏标同类缺陷二次复发，2026-09-01 补齐）
- [ ] 更新INDEX.md状态为"已晋升"
```

## 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| 错误模式 | ✅ | 编号+模式名称 |
| 出现次数 | ✅ | 错误累计次数 |
| 最新发生 | ✅ | 最近一次发生日期 |
| 晋升目标 | ✅ | 要写入的规则文件路径 |
| 精炼规则 | ✅ | 从错误中提炼的可执行规则 |
| 来源标注 | ✅ | 标准格式：`[来源: 成长箱晋升 | ...]` |
| 晋升操作清单 | ✅ | 6项操作逐项确认（含认知象限同步+TTL标注） |
