# 蒸馏报告模板

> **用途**：成长箱Skill流程C（错误蒸馏）步骤C4的蒸馏报告格式模板
> **引用方式**：SKILL.md流程C步骤C4引用此模板

## 蒸馏报告格式

```markdown
# 错误蒸馏报告

> **蒸馏日期**：YYYY-MM-DD
> **蒸馏范围**：[全月/指定日期范围]
> **蒸馏人**：[工具名]

## 📋 蒸馏概览

| 指标 | 值 |
|------|-----|
| 扫描文件数 | N |
| 错误总数 | N |
| 推荐晋升 | N |
| 推荐合并 | N |
| 建议保持 | N |
| 建议进知识层 | N |

## 🔍 步骤①：全月错误清单

| 编号 | 错误名称 | 日期 | 优先级 | 来源文件 | 状态 |
|------|---------|------|--------|---------|------|
| [编号] | [名称] | [日期] | [优先级] | [文件] | [状态] |

## ⭐ 步骤②：重要但未满3次

| 编号 | 错误名称 | 次数 | 未满原因 | 提前晋升理由 |
|------|---------|------|---------|-------------|
| [编号] | [名称] | N/3 | [原因] | [如critical说明] |

## 🔗 步骤③：跨系统同类合并

| 合并组 | 涉及错误 | 共同根因 | 合并建议 |
|--------|---------|---------|---------|
| [组名] | [错误列表] | [根因] | 晋升/合并到LEARNINGS |

## 📊 步骤④：决策表

| 编号 | 模式名称 | 次数 | 来源 | 建议 | 🧪 门禁痕（C3.5·六段） | 用户决策 |

| [编号] | [名称] | N/3 | [文件] | 晋升/合并/保持/进知识层 | `门禁=C3.5｜锚[成立:…;失效:…]｜8要素[1✅…8❌]｜自爆[…]｜结论[…]｜签名[…]`（六段一行·真源＝SKILL 门禁面；⛔旧形态「✅已核验」v4.12.3 退役——该列自 v4.11.0 起由 `schema_check --distill` 消费，填旧形态真行即 rc=2） | [用户确认] |

> **下次蒸馏**：[日期] 或 手动触发
```

## 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| 蒸馏日期 | ✅ | 执行蒸馏的日期 |
| 蒸馏范围 | ✅ | 全月或指定日期范围 |
| 扫描文件数 | ✅ | 读取的错误文件数量 |
| 错误总数 | ✅ | 扫描到的错误条目总数 |
| 推荐晋升/合并/保持/进知识层 | ✅ | 各类建议数量统计（枚举值须与 SKILL.md C4 决策表**同集合一致**（Δ=∅·Skill架构规范 §2.3.1 D7 镜像同步·v4.12.5 口径统一）） |
| 决策表 | ✅ | 必填，用户逐项确认 |
| 🧪 门禁痕 | ✅ | C3.5 结论复核的一行结构化落盘（真源＝SKILL.md E4 同名字段·六段语法），每行必带 `结论[…]｜签名[✅|❌]` 两段；⛔ 在本列手画四张表（零机械消费者格式必漂）。列名 v1.2 由「三思维复核」对齐而来，跨端引用旧名处需同步 |
| 蒸馏结论 | ✅ | 已晋升/已合并/保持观察/**已进知识层（含卡号+INDEX 已同步验证）**分类列出 |
