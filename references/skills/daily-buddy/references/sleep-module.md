## 四、日记评级联动规则（通用不变）
1. 睡眠时长达标率＜80%、作息偏差＞60分钟，当日不得评为A级及以上
2. 连续3天睡眠质量评级为「较差」，即使任务完成率100%，也不得评为A级
3. 从睡眠数据中提炼出可跨场景迁移的底层规律，满足S级顿悟标准，可直接评为S级

### S级睡眠顿悟判定规则（可反复评S级的唯一合规情况）

必须同时满足「三个新」要求：

| 要求 | 含义 |
|------|------|
| **新的底层规律** | 不是之前已经提炼过的认知，而是从睡眠数据里发现了全新的、脱离睡眠场景的通用底层逻辑 |
| **新的跨场景复用方向** | 能套用到至少2个和「睡眠管理」完全无关的新场景，且有明确的落地用法 |
| **新的可落地动作** | 能基于这个新规律，制定出和之前完全不同的行为调整计划 |

**绝对不能评S级的情况**：
- 同一个底层规律的重复验证（如：今天作息准，精力果然好）
- 同一个规律的换皮表述（如：把「稳定比完美重要」换成「睡眠不能突击补觉」）
- 单次事件的经验总结（如：今天熬夜了，第二天效率很低）
- 空泛的鸡汤口号（如：睡眠很重要，身体是革命的本钱）

**S级感悟必须包含的4个核心要素**：
1. **绑定数据触发源**：明确写清是从当天睡眠模块里哪条具体的睡眠数据里悟出来的
2. **提炼底层通用规律**：从具体睡眠数据里，抽象出完全脱离睡眠场景的、可跨场景复用的底层逻辑
3. **明确跨场景用法**：写出至少2个和睡眠管理完全无关的新场景，以及在这个场景里的具体落地用法
4. **给出第一步落地计划**：写出接下来要做的第一个具体动作，为后续月度校准留好验证依据

**2条落地铁律**：
1. **同规律终身一次S级原则**：同一个底层逻辑的顿悟，终身只能评一次S级
2. **月度校准强绑定原则**：所有睡眠相关的S级顿悟，月度校准时必须验证「有没有在跨场景里落地执行」
