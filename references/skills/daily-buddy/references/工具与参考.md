## 工具与脚本速查

| 场景 | 命令 / 脚本路径 | 作用 |
|------|----------------|------|
| 获取时间 | `date "+%Y-%m-%d %H:%M"` | 获取系统真实时间（禁用回忆） |
| 提取灵感句 | `create_skeleton.py`（优先读核心启发库，无个人库则回退随包 `daily_quotes_cache.json` 名言池） | 基于昨日日记关键词匹配金句，14天防重复 + 无匹配按日期轮换 |
| 成就系统 | 由每日伙伴Skill内置逻辑处理（工作流C步骤2强制执行） | 成就检测+成就更新 |
| 周报生成 | 工作流E + `references/weekly-review-sop.md` | 读取7天日记，生成周报（SOP驱动，无独立脚本） |
| 日记标题检查 | `python3 [记忆共享中心]/技能配置/daily-buddy/scripts/check_diary_titles.py` | 检查日记标题格式是否规范（辅助脚本，非硬依赖——不运行不影响工作流 A-F） |
| 周报·情境层联动验证 | `python3 [记忆共享中心]/技能配置/daily-buddy/scripts/test_context_sync.py` | 验证周报与情境层的数据一致性（测试工具，非硬依赖——仅在跨平台改造后运行回归验证） |

> **平台路径**：记忆归档路径和署名因平台不同，详见 `references/platform-paths.md`
