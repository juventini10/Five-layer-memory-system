## SHADOW.md联动规则

- **写入触发**：⚠️/❌结果自动写入SHADOW.md，🔴级（触及CORE底线或交叉验证矛盾）必须写入
- **累计对质**：同一偏差类型累计3次 → 触发温和对质（引用用户自己的原话，不带评判）
- **归档规则**：对质后30天无复发 → 移入SHADOW.md「已解决归档」区；归档后复发 → 移回活跃区，累计次数接续
- **CORE.md底线条款**：①不伤家人 ②不伤健康(宁可少赚) ③不利己损他 ④不违背良心 ⑤不做无正向反馈的事
- **SHADOW文件路径**：`~/个人AI档案/潜意识层/SHADOW.md`（六端共用）
- **认知象限字段（四象限设计哲学·无知矩阵）**：每条写入 SHADOW 的记录，必须在记录块中加入「认知象限」字段。
  - **取值**：已知已知 / 已知未知 / 未知已知 / 未知未知（定义见 SHADOW.md §认知象限字段规范）
  - **默认规则**：偏差记录默认「未知已知」；正向行为（用户主动纠正）填「已知已知」；已知缺口待探索填「已知未知」；未标注→按「未知已知」兜底
  - **🔒 写入前模板锁（设计端·防误）**：写入前✅DO读取下方「SHADOW记录写入模板」段，按字段顺序填。正面建模：一条合格记录 = 标题行 + 认知象限(第1字段) + 偏差类型 + 事实。⛔DO NOT跳过模板自由发挥——原因是模板把认知象限锁在第1字段位，跳过=字段可能漏标（历史48/49教训）。
  - **🔒 写入后字段锁（检查端·兜底）**：写入后立即检查本条新记录含①标题行三要素 ②偏差类型∈枚举 ③认知象限∈四态。缺任一→补全后重新写入，不进入下一步——原因是检查端是模板漏网后最后一道防线，放过=记录失去象限归属，月度晋升链断裂
  - **对质重定义**：对质动作 = 将「未知已知」晋升为「已知已知」的转化。对质成功后，在原记录追加「认知象限：未知已知 → 已知已知（对质第 N 次后晋升）」

## SHADOW记录写入模板

> 写入SHADOW.md时✅DO按此模板填写，⛔DO NOT自由发挥格式——原因是模板把「认知象限」锁在正文第1字段位，跳过模板=字段回到"想起才填"=历史48/49漏标重演。
> 字段取值定义**单一来源**：见 SHADOW.md §认知象限字段规范（本文件只引用指针，不复制定义）。

### 偏差记录模板

```
### {YYYY-MM-DD} {⚠️/🔴}{偏差简述} [{来源端}]
- **认知象限**：{未知已知/已知未知/已知已知}   ← 正文第1字段，不可省略
- **偏差类型**：{作息违背/消费冲动/时间浪费/搭建焦虑/其他}
- **事实**：{客观事实，数据说话}
- **归因**：{原因，或 _待记录_}
- **自查确认**：{✅/❌ 用户是否确认}
- **关联模式**：{关联到已有偏差模式}
- **连续计数**：{连续N天同向偏差}（如适用）
- **积极信号**：{正向行为}（如适用）
- **注意**：{观察要点/应对策略}（如适用）
```

### 正向行为记录模板

```
### {YYYY-MM-DD} ✅{正向简述} [{来源端}]
- **认知象限**：已知已知   ← 正向行为固定值，正文第1字段
- **偏差类型**：无（正向行为）
- **事实**：{客观事实}
- **关联模式**：{关联到已有模式的改善}
- **注意**：{是否持续观察}（如适用）
```

### 字段必填表

| 字段 | 必填 | 说明 |
|------|:----:|------|
| 标题行（日期+图标+简述+来源端） | ✅ | 三要素齐全 |
| **认知象限** | ✅ | **正文第1字段**，四态取值，不可省略 |
| 偏差类型 | ✅ | 固定枚举 |
| 事实 | ✅ | 客观描述 |
| 归因 | ✅偏差记录 | 原因或 _待记录_ |
| 自查确认 | ✅偏差记录 | 用户是否确认 |
| 关联模式 | ✅ | 关联已有模式 |
| 连续计数/积极信号/注意 | 🟡 | 有则填 |
