# 执行流程细节

本文件收录 SKILL.md 中按需加载的执行细节，避免主文件过长。

## Step2 动态补读（最伟大的我）

钩子方向确定后，根据钩子方向匹配最伟大的我目录，补读相关历史记录——不是全量加载，是按需读取：

```
钩子方向判断 →
├── 涉及重复行为/卡住模式 → 补读 回避模式/（最新3条）
├── 涉及情绪/关系动态 → 补读 认知发现/ 中相关主题的已有记录（按标签匹配）
├── 涉及成长/成就 → 补读 认知发现/ 中正面发现的记录
└── 不涉及任何已有记录 → 跳过，不浪费读取

补读后：将历史信息叠加到当前钩子的认知追问方向中
```

**作用**：让本轮对话继承历史认知沉淀，确保跨对话连续性，同时不浪费 Token 全量加载。
