## 12 维度速查

| 信号类型 | 匹配维度 | 触发特征 | 追问话术模板 |
|:---------|:---------|:---------|:------------|
| 确定性表述 | **维度1 中间信念** / 维度3 知识诅咒 | "一定""已经""解决了""本来就是" | "你说X，你确定这个前提成立吗？如果错了呢？" |
| 归因跳跃 | **维度1 中间信念** / 维度6 反事实 | 从结果直接到结论，无中间分析 | "从A到B中间跳过了什么？还有没有别的解释？" |
| 宣言vs行为矛盾 | **维度10 隐性矛盾** / 维度4 反思判断 | 目标vs数据系统性偏差 | "你说X，但你一直做Y——Y是不是其实更爽？" |
| 连续模式 | **维度11 二阶模式** / 维度8 锤子定律 | 同类事件≥3次重复 | "你连续几天都在做同类事——你注意到了吗？" |
| 成功后归因空白 | **维度5 反向D-K** | 做成了但没说为什么 | "换个人做，结果会一样吗？" |
| 内化知识 | **维度3 知识诅咒** / 维度7 历史终结 | "本来就是""正常的""都这样" | "三个月前你会怎么处理？差在哪？" |
| 终极性表述 | **维度7 历史终结** / 维度4 反思判断 | "最""永远""不会变" | "三个月后还这么看吗？" |
| 自我定义固化 | **维度12 确认偏差** / 维度1 中间信念 | "我一向就是""我就是这样的人" | "你是什么时候开始这么定义自己的？" |
| 构建者与被构建者的角色共存 | **维度10 隐性矛盾** | "我构建你执行，最终决策在我"但在过程中也被纠正方向 | "你说你是构建者——但被纠正方向的时候，你的身份变了吗？还是说构建者也可以被构建？" |
| 递归标准（自我突破型） | **维度1 中间信念** / 维度11 二阶模式 | "标准→突破→新标准→突破→新标准"——每次"再做一点"都生成临时新标准，原标准失效 | "你说'再改一个就好了'——这个'就好了'的终点，每次真的到了吗？还是一直在往前移？" |

> 反哺来源：2026-06-28对话。用户自述熬夜时"标准→突破→新标准→突破→新标准"的递归结构，每次"再修改一个就好了"都生成一个临时新标准，原标准（23:30）失效。

## 产出要求

Step 2.2 扫描后，候选钩子表每项必须标注 `[维度N]`：

```
✅ 示例：你说要X但一直做Y [维度10 隐性矛盾]
❌ 示例：你说要X但一直做Y（无标注）
```

**未标注维度编号的钩子 → 产出物锁不通过 → 不能进入 Step 3。**
