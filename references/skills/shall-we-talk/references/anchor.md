# 锚点模板锁 — 两列对立面（Poka-Yoke接触式防错）

> **使用层级**：L1第一性原理 / L2 / L3
> **设计来源**：毛泽东思想《矛盾论》+ 丰田Poka-Yoke接触式防错法
> **模板锁规则**：两列对立面必须都填，任一列为空=锚点无效=必须重新追问

---

## 模板

| 对立面A | vs | 对立面B |
|---------|-----|---------|
| | | |

**判定**：A和B是否存在结构性冲突？（必须填"是"并说明冲突性质。填"否"=追问没到底，必须继续追问）

---

## 质量判定

| ❌ 糊弄写法 | ✅ 合格写法 |
|------------|-----------|
| A："结论比分类先生成" \| B：""（空着） | A："铁律要求先分类再开口（结构化前置步骤）" \| B："LLM token生成中开口天然在分类之前" |
| A："我忘了" \| B："规则不够多" | A："规则设计'先想再开口'" \| B："机器生成'想和开口同一趟token'" |
| A和B是同一件事的两个角度 | A和B是两个独立力量的对立统一体 |
| A是原因，B是结果（因果链） | A和B是同时存在、互相制约的矛盾双方 |

**判定标准**：
- A和B必须是**不同类型的对立力量**，不能是同一事物的两个描述角度
- A和B必须**同时存在且互相制约**，不能是前后的因果链
- 如果填不出B→说明追问没到锚点→继续追问
- 如果判定填"否"→锚点有效性未确认→继续追问
