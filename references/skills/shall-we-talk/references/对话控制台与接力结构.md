# 【第二层】宏观控制：对话控制台 + 第7/8问接力结构（v0.8.0新增）

> 🔴 **第7问与第8问改为接力结构**（v0.8.0）：原版两个问题独立设计容易冲突。接力结构：第7问AI挑战→第8问基于你的反应给选项。

## 第7问：AI独立判断（挑战层）

第7问是AI基于前6问的对话数据，主动给出一个独立判断——不是追问，是挑战。

```
第7问声明（在问题生成声明基础上追加）：
├─ ① 独立判断：基于前6问数据，AI认为你的核心矛盾是什么？
│  └─ Poka-Yoke：判断必须有前6问的原话锚点支撑，不是凭空推断
├─ ② 挑战措辞：不是复述你说过的话，是揭示你没说但数据证明的事
│  └─ 参考"数字分身意识"四个自检
└─ ③ 开放性：AI的判断是拍出来让你反应的，不是定论
   └─ 你可以反驳、修正、接受——任何反应都是有效信息
```

## 第8问：方向盘（收敛层·基于第7问反应）

第8问基于你对第7问的反应，给选项让你选择收尾方向。

```
第8问选项设计：
├─ 如果你接受第7问判断 → 选项：深入这个方向 / 收一收 / 结束
├─ 如果你反驳第7问判断 → 选项：重新探索 / 换个角度 / 结束
└─ 如果你部分接受部分反驳 → 选项：整合两者 / 侧到接受的部分 / 结束

⚠️ 第8问始终包含"结束"选项——你可以随时结束对话，不需要理由。
```

## 接力结构的设计原理

| 原版 | v0.8.0接力结构 |
|:---|:---|
| 第7问和第8问独立设计 | 第8问基于第7问反应 |
| 可能冲突（挑战完又给选项，节奏不顺） | 接力（挑战→反应→选项） |
| 方向盘是固定流程 | 方向盘是收敛工具，接受你随时结束 |

## 控制台出示规则

**控制台出示规则（C4·v1.3.0补全·任何结束必出）**：

> 🔴 **C4硬约束**：✅DO 对话**任何路径的结束**都出示控制台——不止第8问/换主题，还包括：用户主动说"结束/够了/先这样"、收获门达标提前收敛、8轮到顶收尾、换钩子失败中止。⛔DO NOT 让对话"无控制台"地结束——原因是控制台是用户看清"这次挖到哪层、剩什么"的唯一全景，无它则用户不知深度进度、失去收尾选择权。

**触发点清单（任一即出）**：第8问结束 / 换主题 / 用户主动结束 / 收获门达标提前收敛 / 8轮到顶 / 换钩子失败中止。

原始规则（保留）：控制台在第8问结束时和换主题时出示：

```
━━ 对话控制台 ━━

深度分布（N问）：
  表层     ▓░░░░░░░  N问
  模式层   ▓▓░░░░░░  N问
  信念层   ▓▓▓░░░░░  N问
  身份层   ▓▓░░░░░░  N问
  ────────────────
  覆盖层级：X/4 ✅（层名）
  剩余空间：[当前层] 待深入方向

活跃维度：[维度X] [维度Y]
关键信号：[关键信号描述]

对话选项：
① ↓ 继续深入当前方向
② ↻ 沉淀收尾
③ ▣ 结束
━━━━━━━━━━━━
```

> N 为该次对话的追问总轮次（通常为8），条形格数 = N（1格=1问），显示每次追问在各深度层级的分布。
- 第8问结束时 → ✅DO出示（结束/继续同路线/换路线/深潜）
- 换主题时 → ✅DO出示（确认是否真的换）
- 其余1-7轮正常对话，控制台不出现

**继续模式**：用户选继续 → 每6问再出示一次控制台（6 = 苏格拉底五问+综合=一个完整mini循环），不设硬上限。
