# 对话信号词表（C7·模型无关结构资产）

> **加载时机**：Step3 追问中判断"该逼还是该跟随"（C6）、或复述检验判敷衍时 Read。
> **让弱模型照表匹配、不靠悟性。**

---

## 一、change talk / sustain talk（C6 逼vs跟随切换用）

| 类别 | 信号词 | 追问姿态 |
|:---|:---|:---|
| **动员型 change talk**（要改·收获门达标信号） | 我要/我打算/我准备/我会去/我决定 | 锚住它，进 Planning |
| **准备型 change talk** | 我想/我能/我应该/因为…所以该 | 苏格拉底逼：追 assumption 到根 |
| **sustain talk**（维持·触发 MI 跟随、勿逼） | 可是/但是/我做不到/一直都这样/没办法/就这样吧 | MI 跟随：反映+不硬怼，降一层或换钩子 |
| **assumption 确认语**（到根信号·参考非白名单） | 对/我从没想过/原来我是默认了/我一直以为/确实是这样 | 见下方⚠️反向用法 |

---

## 二、⚠️ 反向用法：敷衍负面清单（v3修正·抗假阳）

> **⛔DO NOT 把"对/确实/是的"当达标白名单**——原因是社交高频词，当达标信号→假阳爆炸（L3二审 Agent B 硬伤）。

> **✅反向用作"敷衍负面清单"**：当用户**仅**出现"对/嗯/是的/确实"等最小回应**且无自发展开** → 判疑似敷衍 → 不放行收获门，追一问要求展开。同一张表，方向反过来，抗假阳。

```
最小回应词（仅这些、无展开 → 疑似敷衍）：对 / 嗯 / 是的 / 确实 / 是这样 / 有道理
  ↓
追一问："能不能用你自己的话说说，这对你具体意味着什么？举个你自己的例子？"
  ├─ 能展开+举私人例 → 转真达标判定
  └─ 仍只最小回应 → 判未达标（负例集 P1-P3 敷衍型）
```
