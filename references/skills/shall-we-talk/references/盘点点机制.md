# 🔄 盘点点机制（v0.8.0新增·条件触发式深度校准）

> 🔴 **设计目的**：原8问锚定是线性的——一路挖到底，没有中途检查点。盘点点机制在第4问和第6问插入轻量检查，判断是否需要调整方向或提前收敛。

**与固定第5问检查点的区别**：不是固定在某一问检查，而是条件触发——只在需要时启动，避免打断流畅对话。

## 第4问轻扫描（可选触发）

```
第4问结束后，AI自检：
├─ 当前深度是否已达信念层（层3）？
│  ├─ 是 → Change Talk密集（用户出现改变意愿信号）→ 可提前收敛到第5-6问收尾
│  └─ 否 → 继续正常推进
├─ 当前线索是否已耗尽（连续2问在同一维度同一层）？
│  ├─ 是 → 第5问切换维度或升层
│  └─ 否 → 继续正常推进
└─ 扫描结果仅内部记录，不出现在问题声明中
```

## 第6问强制盘点点

```
第6问结束后，AI强制执行盘点点检查：
├─ Sustain Talk检查：用户是否连续2轮出现维持现状的信号（"但是/可是/其实/不过"+合理化表述）？
│  ├─ 是 → 触发方向调整：退一层或换钩子，不要硬撞
│  └─ 否 → 继续
├─ 深度校准：当前深度是否达到预期（至少层3信念层）？
│  ├─ 是 → 后两问（7-8）进入身份层/收敛阶段
│  └─ 否 → 第7问强制升层，不留在这个深度
└─ 盘点点结果仅内部记录，不出现在问题声明中
```

## 设计原理

| 发现 | 来源 |
|:---|:---|
| 8问锚定线性推进容易撞墙 | v2.2方案讨论 |
| Change Talk密集时可提前收敛 | 动机访谈（MI）理论 |
| Sustain Talk连续2轮是方向信号 | 动机访谈（MI）理论 |
| 盘点点是条件触发不是固定检查 | v2.2方案讨论 |

## 收敛与"至少8轮"基线的协调

如果盘点点判定可提前收敛（第4问触发或第6问深度已达标），剩余轮次转为收敛性对话（总结/确认），不要求再产生新深度追问。"至少8轮"是深度覆盖基线，深度达标后的轮次计入总数。

**⚠️ 盘点点不中断对话节奏**：盘点点是AI内部自检，不向用户出示。盘点点的结果只影响下一问的方向选择，不要让用户感知到"刚被检查了一下"。
