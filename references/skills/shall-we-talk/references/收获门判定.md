# 🚪 收获门判定细则（C2·Step3→Step4 之间的硬门）

> **加载时机**：Step3 追问推进中，判断"是否达标可收敛"时 Read 本文件。
> **达标判据锚定用户语言产出（非 AI 自评臆断）；判定由 AI 依硬规则执行，受表达能力天花板约束**（设计哲学§4.3 / 原则2 / 见§三诚实边界·§三点五V型）。

---

## 一、达标定义（觉察型 OR 动员型·任一即可）

```
🚪 收获门达标 = 用户自己产出以下任一，且触及"根"（底层假设，非表层应付）：
  ├─ 觉察型(看清)：说出进来时说不出的新洞察/重构视角/看清模式  ← ICF #10/#11
  └─ 动员型(要改)：说出改变承诺/行动意向(动员性 change talk)     ← MI DARN-CAT
❌ 未达标 → 不许进 Step4 沉淀
❌ AI 替背/AI 归纳 → 不算（必须用户自己产出+确认）
```

> **不强求 change talk**（理论纪要§七存疑点2解）：ICF 明述觉察/重构/看清是并列合法产出，行动只是其一（用 also 连接）。有的收获是"看清"而非"要改"。

---

## 二、到根校验：复述/扩展检验（⛔废弃 yes/no 确认）

```
⛔废弃：AI提炼假设 → "对吗？" → 用户说"对"
   原因(L3二审)：yes/no 是引导+封闭题，默许偏差+巴纳姆效应下，
   弱模型提模糊假设→用户更易点"对"→假达标率反升。

✅改用【复述/扩展检验】：
   AI 抛假设后，让用户"用自己的话说这对你意味着什么/举个你自己的例子"。
   ├─ 真到根者：能自发展开 + 举私人例证 → 达标
   └─ 礼貌敷衍者：只复读 AI 的话 / 空泛附和 → 判未达标
   判据从"说对"→"能否自发展开"（源 MI complex reflection + ICF 让客户自己说）
```

## 三、判定对照（配 references/负例集-通用规则.md 使用）

| 用户回应特征 | 判定 | 依据 |
|:---|:---:|:---|
| 自发展开 + 举私人例证 + 说出新洞察 | ✅达标(觉察型) | 负例集假阴 N 类 |
| 说出具体的、自己决定的行动意向 | ✅达标(动员型) | MI 动员性 change talk |
| 仅"对/嗯/确实"最小回应，零展开 | ❌不过 | 负例集假阳 P1-P3 敷衍型 |
| 逐字复读 AI 措辞，无个人化转译 | ❌不过 | 负例集假阳 P4-P5 复读型 |
| 空泛自我描述（放谁都成立），无锚点 | ❌不过 | 负例集假阳 P6-P7 巴纳姆型 |

> **诚实边界（§九#3）**：以上是硬规则判据，对"话痨假深/寡言真深"仍会误判（表达能力污染），属天花板区，负例集不覆盖。

## 三点五、V型判定档 + Layer1.5判官自律（v1.1·2026-07-24真机补）

### V型·反向假设有效触发（第三档·介于达标与误判）
AI 假设**前提方向错**（非用户真实状态），但该问题**逼用户做了真实自我确认**（隐性确定→显性确认）→ 算**轻觉察达标**，⛔DO NOT 判"纯误判/白问"。判据归"用户产出的真实反应"（如"愣一秒+确认"），非"AI前提对错"。区别于M型：M型=冤枉用户(伤害)，V型=前提错但问题有效(有价值)。来源：真机M2。

### Layer1.5判官自律（负面定性时必走）
当你要对用户做**负面定性**（敷衍/回避/低估/不想要/有矛盾）→ ⛔DO NOT自主定性，必转问句+标`[AI假设·待你否决]`，用户反驳即推翻；引用记忆负面标签前先核实原始依据；误判被否决后沉淀成戒律。📎 完整机制+判官戒律清单 → Read `Layer1.5判官自律.md`。
