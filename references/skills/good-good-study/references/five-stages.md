# 🚀 五阶段学习流程（锁定靶之后执行）

> **本文件是执行指令。** 锁定漏斗通过后进入本流程。
> 来源：05-运行时执行流程§四 + 01-学习方法论草案 + 02-外部理论夯实

---

## 整体结构

```
P1 领域分诊 → P2 地基速扫 → P3 断层线扫描 → P4 立场锻造 → P5 产出入库
```

**贯穿止损**：P1-P3 先出"领域地图"(问题+几派+张力候选)给你扫一眼确认方向 → 错就在此砍，别等P4深锻完才发现烧错方向。

---

## P1 领域分诊（极小token）

判断靶所在领域属于哪种类型：

| 类型 | 特征 | 后续处理 |
|------|------|---------|
| **繁杂域** | 有成熟理论、可分析、有标准答案倾向 | 走完整五步→锁**1个**主要矛盾 |
| **复杂域** | 无唯一解、涌现性、多学派（哲学/伦理/价值） | 不硬锁单一矛盾，走"有依据选边"→**强制steelman** |
| **混沌域** | 无秩序、先止血建秩序 | 不适合本引擎，告知你 |

## P2 地基速扫（≤全程token 10%）

> 理论背书：Ultralearning P1 元学习"10%画地图"

- 扫主流范式/公认地基，**只要骨架当坐标系**
- ⛔ 严禁深挖——地基是让后续争议可读的，不是学完整本教科书
- 产出：1段话的"这个领域的骨架是什么"

---

## P3 断层线扫描（中等token）

> 理论背书：库恩"反常"处=范式破裂点；MECE/issue tree

- 扫：未解难题 + 主要争议 + 学派分歧（信息熵最高处）
- 产出格式：

```
张力候选：
1. [张力A]（视角X vs 视角Y）
2. [张力B]（...）
...

结构性沉默（每视角最多1条，写不出则空）：
- 视角X 不提___：因为提了会削弱其___立论
- 视角Y 不提___：因为提了会削弱其___立论
```

**结构性沉默判定规则**：只有当"该视角如果提了此点会削弱自身立论"时才记录。"碰巧没提"或"与该视角不相关"不算。写不出=空，不凑。

**P1-P3 checkpoint**：把"领域地图"(P1类型+P2骨架+P3张力候选+结构性沉默)呈现给你 → 确认方向对 → 再进P4。

## P4 立场锻造（大token·核心产出阶段）

### 繁杂域路径
```
张力候选 → 按三判据锁定1个主要矛盾 → 依据链构建 → 立场成型
```

**主要矛盾三判据**（同时满足）：
- **上游性**：它是领域内其他多数分歧的源头
- **解释力**：理解它能连带解释一大片次级问题
- **张力性**：它是真实权衡（顾此失彼），不是能两全的伪问题

### 复杂域路径（哲学/伦理/价值）
```
张力候选 → 不硬锁单一矛盾 → 基于依据链选边 + 标让步条件
→ 强制写steelman（对立面最强版本）→ 再确认立场
```

- ⛔ 不套"锁死一个主要矛盾当真理"——那是不懂装懂
- 产物=**有依据、可证伪、标了让步条件的立场**，不是"正确答案摘要"

### 共通：依据链构建规则
- 权威A：文献/数据（标被引/出处）
- 推理B：基于现有信息的合理推理（**平权于权威，如实标等级即可**）
- 反例C：已知的反证/边界条件
- ⚠️ 未原文核验的标⚠️
