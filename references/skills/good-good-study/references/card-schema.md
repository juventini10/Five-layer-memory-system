## 一、Schema 字段定义

| 字段 | 必填 | 作用 | 防什么 |
|------|:---:|------|------|
| card_id | ✅ | 索引（格式：立场卡#SXXX / 技能卡#KXXX） | 孤岛卡 |
| 文件名 | ✅ | **MUST = `{card_id}-{主题}.md`（与 card_id 同格式·如 `立场卡#S005-讨好双因模型.md`）**——⛔DO NOT 用连字符代替 `#`（2026-08-06 S005 漂移实锤：`立场卡-S005-...` 曾违反） | 命名漂移=索引/引用失配 |
| topic | ✅ | 主题（一句话） | - |
| type | ✅ | 分类（反直觉/机制/方法/价值/...） | - |
| **主要矛盾** | ✅ | 五步法S3产物，本卡核心张力 | 无焦点=泛泛而谈 |
| **立场（结论）** | ✅ | 一句话可操作立场 | 无立场=白学 |

| **让步合法条件（信息性反证D）** | ✅ | 什么样的反证够格让我改 | 无边界=固执或墙头草 |
| **顶住红线（规范性压力）** | ✅ | 仅凭身份/情绪施压=不构成让步 | 无红线=讨好复发 |
| **推翻了我哪个旧认知** | ✅ | 进步真凭据 | 退化成收藏夹 |
| **碰撞后三件事** | 碰撞产出必填·其余省略 | 碰撞改变了什么具体行动（MUST 含「碰撞前的做法」对比列——行动前基线 vs 行动后；「可行动」判据的落地证据） | 洞见不落地=空转；缺基线=看不出碰撞改变了什么 |
| **碰撞来源** | 碰撞产出必填·其余省略 | 记录 [C-XXX × C-YYY] 概念对（D-F4·碰撞历史源真值） | 不记=概念层collision信息无法反查重建 |
| 领域分诊 | ✅ | Cynefin：繁杂/复杂/混沌 | 复杂域硬抓矛盾=误导 |
| **反方最强论证（steelman）** | 复杂域必填·繁杂域可省 | 对立面最硬版本 | 偏好包装成立场/稻草人 |
| 依据链每条标证据等级 | ✅ | 权威/推理/推测，自报家门 | 混淆事实与推测 |
| 精细加工标记 | ✅ | 证明本卡走过论据链（非灌输） | 假加工=弱立场 |
| 自测题×3 | ✅ | 检索辅助（B线留存主力；A线留存为质证/复用驱动，自测题降为辅助） | 写完即忘 |

| date | 碰撞产出必填 | 产出日期 `YYYY-MM-DD`（**lint 硬性 REQUIRED**；INDEX.md 日期列数据源；regen 缺则回退旧 INDEX 历史行） | 无日期=碰撞卡无时间锚点 / INDEX 缺列 / lint HARD 拦截 |

## 二、让步双判据（D5落地）

> 理论背书：Deutsch & Gerard⚠️——信息性影响 vs 规范性影响

- 让步**合法** ⟺ 信息性影响：对方给出更强证据 / 指出我推理漏洞（认输于事实）
- 让步**非法** ⟺ 规范性影响：只为减少冲突 / 被接纳 / 迫于身份（认输于脸色）= 讨好

---

## 三、证据平权原则

> ⛔DO NOT 把"无文献直接背书"错当成"质量可疑"——那是讨好绝对权威。

- 依据链里「权威A」和「推理B」是**平权的两类证据**
- 基于现有信息的合理推理 = 正当的一等依据
- **只需如实标注证据等级（权威/推理/推测），标了就理直气壮地用**
- 证据等级 ≠ 质量判定，两件事分开标

## 四、写入前强制自检（5项·任一不过=回到对应字段补齐）

- [ ] **证据平权自检**：逐条推理B问"我是不是因为它没文献就偷偷给它降权了"——降了=讨好权威，改正
- [ ] **让步双判据自检**：本卡的"让步合法条件"是否只允许信息性反证，没把规范性压力写进去
- [ ] **精细加工自检**：依据链是否真走过A+B+C，而非只堆了个结论
- [ ] **steelman自检**（复杂域）：是否把对立面最强版本写出来了，还是只驳了弱版
- [ ] **溯源自检**：依据链中引用的每一个权威来源，你是否亲自读过原文？AI残差/审查员声明/评估报告等 AI 中间产出是"关于来源的声称"而非来源本身——只有当你亲自读过一手原文时，才能列为权威来源。

### 溯源自检说明（2026-08-23 S816 v1.0 自查退回教训）

| 常见陷阱 | 错误示例 | 正确做法 |
|:---|:---|:---|
| 把 AI 残差当一手来源 | 残差#084 说"WB 不支持 Stop Hook" → 直接列为权威D | 去读 workbuddy.ai 官方文档，确认后再列 |
| 把审查员声明当事实 | "CHANGELOG 自述 XX 不支持"（无原文引用）| 找到 CHANGELOG 原文，截图/引用后再用 |
| 把旧快照当现状 | 2026-08-12 记录"不支持" → 2026-08-23 仍当论据 | 功能评测遇旧说法时，先核实最新版本 |

> 铁律：AI 中间产物（残差、评估报告、审查员声明、对话记录）是"某人声称 X 为真"的证据，不是"X 为真"的证据。只有当你亲自验证了 X 本身后，X 才能作为依据链中的权威来源。

## 五-b、完整参照件与机械闸（2026-10-01 新增·补 §五 空壳与真卡之间的鸿沟）

§五 是**空壳**——它能告诉你有哪些字段，却不能告诉你"一张填完整的卡长什么样"。
第一次写卡的人真正缺的是参照物与第二双眼睛，两件都在这：

| 要什么 | 去哪儿拿 | 命令 |
|:---|:---|:---|
| 完整形态参照<br>（含 steelman／<br>让步双判据／<br>三件事基线列） | `references/example-card-neutral.md`<br>中性主题·命名空间 `示例卡#X`<br>⛔不占你的取号序列<br>⛔不是任何人的真实立场 | 读即可<br>（复制改内容，<br>⛔别复制进卡库） |
| 字段级机械闸<br>（把「缺必填＝阻断」<br>从文档挪进 exit code） | `scripts/card_schema_check.py`<br>零依赖（端用户无 pyyaml） | 入库前：`python3 scripts/card_schema_check.py 你的卡.md`<br>存量体检：加 `--retro`（只报数不判红）<br>自证：`--self-test --mutant` |

> ⚠️ 闸的边界，如实声明：它**只判结构与命名**，不判语义质量——
> 「这条依据够不够格」「让步算不算信息性」仍须 AI 质证与你终审（§二 双判据的语义判断⛔不伪装成机械可判）。
> 两个字段判据按实盘校准过：`精细加工标记` 与 `碰撞模式标记` 等价（S10xx 碰撞卡批次用后者）；
> `领域分诊` 须落 Cynefin 三值——存量约四成老卡写的是自由文本，那些**用 `--retro` 看，别拿硬闸追溯**。

```

**质证记录（YYYY-MM-DD·你宣告：过）**：宣告内容
```

> 分身质证通过 = 你授权分身代理常规层审批。触发条件：事实层/风格层·高置信·未命中红区。

### 阶梯定义（事件→状态派生）

| 等级 | 含义 | 派生规则（脚本判定） |
|:---:|------|---------|
| L1 | AI已提炼 | 默认（无你质证事件） |
| L2 | 你已质证 | 卡内存在≥1个你质证事件（你锤+已修正 / 你宣告过） |
| L3 | 已应用 | 引用台账（`AI学习库/引用台账.md`）存在≥1条：你决策引用，或依据型引用且卡已L2 |
| L4 | 已内化 | 引用台账你决策引用+依据型合计≥3且无新反证 |

> A线留存 = 对话中被质证/复用驱动的 status 升级（用就活、不用就沉）——升级动作由脚本派生，非 AI 手写。
> 二期已上线（2026-08-17）：`scan_citation_candidates.py` 扫日志出候选 → 月报复核写入引用台账 → `derive_reading_status.py` 从台账派生 L3/L4。裸引用信号信噪比≈10%（残差#076），⛔不自动升级。
