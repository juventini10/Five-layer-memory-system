# 🎲 选题机制（A线专用·三池驱动+你仲裁）

> **本文件是A线选题的执行指令。** B线不走此流程（B线靠用户输入+逆向追问）。
> 来源：05-运行时执行流程§三 + D3决策 + 08-三库联邦设计§D-F8（碰撞候选=A线第二进料源）+ v0.11.0三池扩展（跨类型碰撞候选=A线第三进料源·蓝图索引卡↔立场卡）

---

## 一、核心原则

**选题不是AI的品味，是数据把它拽出来的——残差暴露盲区，碰撞候选暴露认知机会。**

- ⛔ AI不自己挑"我觉得有趣的"——那是用已知框架自选，撞不到盲区
- ✅ 从数据暴露真盲区/真机会 → 三池合并排序 → 你仲裁

---

## 二、选题流程

```
触发（你说"学X" 或 "好好学习" 或 "跑一轮学习"）
 ↓
① 扫数据源（三池·D-F8并列）
   池1·悬置区残差（未知未知/悬置区.md）——AI真正不知道的
   池2·碰撞候选队列（[记忆共享中心]/脚本中心/知识联邦引擎/collision_candidates.json 中 status=pending 项）——概念碰撞扫出的"值得深挖的认知机会"，与残差同类
> 🔻 **降级声明（v1.1.8 真值校正）**：知识联邦引擎及其脚本已以端用户最小集（min 16 件）随安装包分发，口径真源见 collision-consumption.md 腿F案段。仅当包内与本机该引擎目录**实际缺失**时，相关步骤才**跳过·不阻塞**。⛔不得把「随包」写成「不携带」（2026-10-12 clock-loop R1 实证=六处与实盘互斥）。
   池3·跨类型碰撞候选（蓝图索引卡↔立场卡·~/Local_Obsidian_Vault/2-知识库/09-AI学习库/跨类型碰撞候选-蓝图索引卡↔立场卡.md
       ·cross_type_collision_scan.py v1.0 扫描产出·消费流程见 collision-consumption.md §九·
       跨类型碰撞走简化版收口验证环·不进概念层投影）——用设计哲学/蓝图框架碰撞已沉淀立场，
       扫"原则与实践脱节"类认知机会（v0.11.0·D-F8并列）
   - 你当下真实困扰（SHADOW/近期日记/系统日志）作辅助排序信号
   - 你锤信号（2026-08-17 新增·三期反哺）：扫 AI学习库卡内质证事件（你锤/你宣告记录），
     统计你锤过的主题类型——你锤=深度质证=你在乎该主题，作为排序辅助信号
     （你锤过同类主题的候选优先，你锤频率最高的主题域优先）
   - 如你说了领域X → 筛与X相关的残差/候选
   - 池2候选文件不存在或无pending项 → 池2为空，仅走其余池（不阻断·呈现时说明）
   - 池3候选文件不存在或无可碰项 → 池3为空，仅走其余池（不阻断·呈现时说明）
 ↓
② 三池合并排序（按"与你/AI真实盲区接近度"·客观信号）
   → Top3 候选（每条附：来源池 + 存活时长/相似度 + 为什么值得攻 + 预估收益）
   格式示例：
   1. #029 · 讨好双因模型（残差池 · 1天前标注 · 直接威胁A线地基）
   2. C-003×C-011 · 双因叠加×生产性挣扎（碰撞池 · 跨域sim 0.52 · 可能产出学习动力学洞见）
   3. [BP-蓝图索引卡#012 × S074] · 焊闸哲学×闭环进化五通道（跨类型碰撞池 · 蓝图原则碰撞实践立场·格式同 collision-consumption.md §9.3）
   ⛔ 存活时长/相似度只是信息透明，不做自动加权——"重不重要"的判断留给你
 ↓
③ 呈现给你仲裁
   → 你选/否/换
   → **你全否Top3 = 等效"三池空"→ 走下方空池路径**
 ↓
④ 锁定靶（按来源池分叉）
   - 残差项 → 进锁定漏斗（如需收敛子域）或直接进五阶段
   - 碰撞候选项 → 强模型碰撞：Read 两概念的 source_cards 原卡 → 碰撞出洞见
     → 洞见卡入库（必带"碰撞来源"字段·D-F4）→ 跑 sync_collision_queue.py 自动对账回写
   - 跨类型碰撞候选项 → Read 蓝图索引卡（core_principles+summary+设计背景）+ 立场卡（主要矛盾+立场+依据链）
     → 碰撞出洞见 → 洞见卡入库（碰撞来源格式=[BP-蓝图索引卡名 × S-立场卡编号]·见 collision-consumption.md §9.3·soft warning不阻断）
     → 消费后在候选文件该条目下标注「已碰撞→SXXX」——⚠️此为手动标注·重扫会覆盖（对账脚本未建·§9.5已知债·消费后应及时消费不过夜）
     → 简化版收口验证环（跳过概念层投影步骤）
```

## 二.4、碰撞候选消费闭环（D-F4/D-F8）

- ✅ 洞见卡写回三库时**必填**「碰撞来源: [C-XXX × C-YYY]」——此字段=碰撞历史的源真值，概念层collision信息由此反查重建（D-F4）
- ✅ 产出入库后跑 `python3 sync_collision_queue.py` 自动对账（幂等·INDEX 权威→队列对齐 status→consumed + collided_to + synced_from=index）——⛔DO NOT 手工编辑 collision_candidates.json 回写 status（历史失真根因=手工回写靠自觉·2026-08-25 实证 781/1181 假 pending）
- ✅ 跨主体碰撞（AI概念×使用者自身概念）产出的洞见卡 source_owner 标"共创"——联邦最高价值碰撞（注：此"共创"是**立场卡侧**由碰撞父母归属机械算出，与2026-10-20概念卡侧二类制不冲突）
- **洞见卡入库前三判据验收（缺一退回重碰或放弃）**：①不可从任一单概念独立推出 ②产生新的可行动后果（碰撞后会做一件碰撞前不会做的事）③有反例暴露面（能说出什么情况下它是错的）——原因是强模型极擅长生成流畅但零新后果的类比文，无判据=作文入库=知识库注水 `[来源: 成长箱反哺 | 2026-07-27 | 洞见三判据]`
- 碰撞质量依赖模型强弱（D-F3诚实边界）——产物带依据链，移植的是结果不是过程

## 二.5、三池空的处理（空≠无任务）

> ⚠️ 三池空 = 自动检测没发现盲区/机会，**不等于没有盲区**（检测器本身有盲区）。

```
扫三池（悬置区+碰撞候选+跨类型碰撞候选）→ 全空（或Top3被你全否）
 ↓
升级问你："当前悬置区没有检测到学习方向。你觉得有什么是我需要学的吗？"
 ├─ 你给方向 → 进锁定漏斗 → 正常学
 ├─ 你说"没有" → 确认无任务，本轮结束（双重确认为空=合法终止，不硬学）
 └─ 你反问"你对Y了解吗？" → AI如实自评 → 有缺口则学 / 无缺口则确认
```

- ⛔ 不是AI自决"我需要学X"（那是D3禁止的后门）——是把决策权升级给你
- ⛔ 空的时候不伪造任务、不硬学

## 四、红线

- ⛔ AI不自选（D3铁律）——哪怕"顺手"觉得某个话题有趣
- ⛔ Top3每条必须有真实来源（残差编号 或 碰撞候选pair），不是凭空编的候选
- ⛔ 未经你仲裁不开学
- ⛔ 碰撞候选消费后不跑 sync 对账（或手工回写 status）——原因是静默消费=候选队列失真=下轮重复仲裁
