# 🎯 锁定漏斗（动手前必走·A/B线共用）

> **本文件是执行指令，不是设计解释。** AI读到这里=按步骤跑，不跳不改。
> 来源：05-运行时执行流程§二 + Zamani 2020(微软·被引321) + 主动学习信息论(Nguyen 2021 AAAI)

---

## 一、输入分流

| 类型 | 判定 | 处理 |
|------|------|------|
| **目标清晰** | 用户给了具体领域+目标，无歧义 | 跳过漏斗，直接进五阶段 |
| **模糊** | 范围过大/方向不明/多义 | 走下方漏斗 |

---

## 二、漏斗步骤（模糊输入时）

```
用户说"学X"（模糊）
 ↓
① 榨干推理（不问）
   扫：悬置区残差 / SHADOW / 价值观记忆 / 系统日志 / 近期对话
   → 推出"最可能缺的子域"（先用已有情报，不急着问）
 ↓
② 诊断模糊类型 + 算 VoI
   · 过宽(方向对但太大) → 推理劈小
   · 歧义(多个离散意思) → 标出离散选项
   · VoI = 残余不确定 × 猜错代价
     - VoI 低(猜错好改) → ③a
     - VoI 高(猜错烧大量token) → ③b
 ↓
③a【默认·主模式】陈述最可能的靶 → 你一句否决/微调（0问）
③b【兜底】按信息增益出问题，问到"边际增益 < 提问代价"就停
 ↓
锁定唯一靶 → 退出漏斗
```

---

## 三、B线特有追加：逆向追问

> B线所有入口都过确认，零例外。

A线锁定 = AI推理(扫残差) → 陈述猜测 → 你仲裁
B线锁定 = 在上方漏斗之后，**追加一步**：

```
AI确认靶后 → 逆向追问："你想解决的Y，X真的能解决吗？"
  → 匹配：真能 → 收敛X的子域 → 进五阶段
  → 不匹配：建议"解决Y可能需要的是Z，不是X"
```

**B线推荐模式**（用户问"我该学什么"）：
```
扫 SHADOW + 日记 + 系统日志 + 近期困扰
→ 推荐Top3方向（附理由）
→ 你选一个
→ 仍走逆向追问确认
→ 锁定靶
```

---

## 四、红线

- ⛔ **提问是推理的兜底，不是标准步骤**——默认"给带推理的猜测让你否决"，不默认发问
- ⛔ **停止规则是VoI，不是硬编码次数**——边际信息增益<代价即停
- ⛔ **不跳过逆向追问**（B线）——AI推荐的方向一样可能偏

---

## 五、熔断器

| 项 | 值 |
|---|---|
| 成功条件 | 靶已锁定（你确认或AI陈述未被否决） |
| 失败处理 | 重试（再推理/再提问） |
| 重试次数 | 2 |
| 降级方案 | 你直接给靶 |
