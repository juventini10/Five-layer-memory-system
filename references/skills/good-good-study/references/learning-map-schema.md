## 一、路径图 YAML Schema

```yaml
# metadata
title: "{学习主题}"
target_goal: "{终点目标}"            # UbD Stage 1: 学完能干嘛(可验证)
domain: "{领域/子域}"
estimated_duration: "{总时长}"
generated_date: "YYYY-MM-DD"
source_engine: "好好学习 B线"
status: "active | completed | abandoned"

# 节点序列(UbD Stage 3 × Bloom梯度)
nodes:
  - id: 1
    title: "{节点标题}"
    bloom_level: "Remember|Understand|Apply|Analyze|Evaluate|Create"
    what_to_learn: "{学什么·一句话}"
    completion_standard: "{完成标准·可验证}"  # UbD Stage 2
    resources: ["{推荐资源}"]                 # 深度层/快速层均须≥1条（v0.13.2收紧——原"快速层可空"×"出图必跑至exit 0"两条款并存=合法快速层图永远无法交付的死锁矛盾·Loop审查R4实跑实证后堵）
    estimated_time: "{预计时长}"
    status: "pending|in_progress|completed|skipped"
    depends_on: []                            # 前置依赖(节点id)
```

## 二、Bloom层级 × 完成标准动词约束

| Bloom层 | 完成标准动词 | ✘ 不可用 |
|---|---|---|
| Remember | 能列出/能识别/能回忆 | "知道了" |
| Understand | 能用自己话解释/能举例/能比较 | "理解了" |
| Apply | 能在新情境中使用/能解决 | "会用了" |
| Analyze | 能拆解/能对比/能找出关系 | "分析过了" |
| Evaluate | 能判断/能论证/能选边+给理由 | "有看法了" |
| Create | 能设计/能构建/能产出新东西 | "想到了" |

> ⛔ 完成标准必须用左列动词类，不可用右列模糊表达——原因：不可验证=伪完成。

## 三、B线4Phase完整流程

```
Phase 1 · 路径图 → Phase 2 · 过程辅导(可选) → Phase 3 · 即时验收(Agent B) → Phase 4 · 周期巡检
```

### Phase 1：路径图（必出）

**⚠️ 前置强制步骤：领域时效性探测（无分类·无例外）**
```
锁定靶后 → 必须先 WebSearch："{领域} 最新变化 2025 2026"
  → 发现重大变化 → 基于新信息出路径图
  → 没发现变化 → 确认现有知识仍有效 → 正常出图
```
- ⛔ 不做"快变/慢变"分类判断——联网成本≈5秒，教过时知识的代价=用户浪费数天。永远查。
- 实证教训（2026-07-25首测）：抖音算法2026年4月大改（收藏率>40%权重/7天慢推流），AI基于旧知识"前3秒定生死"出了过时路径图，被你当场纠正。在你的未知领域没人能纠正=更危险。

- 按上方schema产出
- 快速层=只出路径图（用户自学能力强只要方向）
- 深度层=路径图+后续Phase 2辅导

### Phase 2：过程辅导（可选·用户学的过程中）

4个经验证的辅导方法：

| 方法 | 做法 | 外部来源 |
|------|------|---------|
| ① 苏格拉底引导 | AI问→用户推（不直接解释） | Harvard RCT 2025⚠️ |
| ② 费曼检验 | 用户讲→AI挑漏洞 | Ultralearning P8 |
| ③ 主动回忆测试 | 学完AI出题考，错的隔天再考 | Karpicke⚠️ |
| ④ 生产性挣扎 | 用户卡住→AI给提示不给答案 | Harvard核心 |

> ⛔ AI**问问题不给答案**（Harvard RCT核心发现）。给答案=认知投降(ALEKS 2026: 成绩下降25%⚠️)。

### Phase 3：即时验收（Agent B独立判定·⚡解锁唯一入口）
- 学完一个节点 → 你说「验收第N关」→ spawn独立Agent B判"过/不过"
- ⛔ 不由辅导AI(Agent A)自判——原因：#S003(判官绕不开人/单一判官幻觉)
- Agent B判定依据：该节点的completion_standard
- **验收通过 → AI当场五处落盘（v0.8.4·缺一=验收未完成，不得宣告过关）**：
  ① 写验收记录文件 `07-主动学习/验收记录/LXXX-第N关-YYYYMMDD.md`（含判定/逐题/亮点/补练方向）
  ② 更新 progress.json（真值源·唯一写入时机）
  ③ 编辑 HTML 内 `const VERIFIED=[...]` 数组加入节点索引（v0.8.0防注水锁的写入时机·你刷新页面自动解锁+播庆祝）
  ④ 路径图 md 进度区勾选该节点
  ⑤ 宣告过关+${pts}⚡入账；达成就阈值触发学习成就+弹窗
  ⛔DO NOT 只写部分落盘就宣告过关——原因是完成态散在多处，漏写任一处=视图与真值分裂（实例：2026-07-31 L002第3关漏写VERIFIED，你发现页面未解锁——旧版本清单无③且④位旧文案"告知你回HTML点标记"与v0.8.0已移除按钮自相矛盾）
- 验收不过 → 指出缺口，⚡不入账，HTML不标记
- **验收结算框（v0.8.5·你定"终值要有温度"·峰终定律落地验收场景）**：五处落盘完成后，向你输出的最后一块必须是以下结算框（仿三明智结论块·框在最后=体验的终），⛔DO NOT 把它埋在工程信息中间——原因是终值被工程信息盖住=白设计（同迁理之外v3.4.0结算画面分层同构）：

```
╔════════════════════════════╗
  🎓 验收结算 · {路径名} 第{N}关

  【结果】✅ 通过 ＋{pts}⚡（累计 {x}/{max}）

  【你做对了什么】（≤两条·引考官原话/你的原话当证据，不空夸）
  · {本关最亮的具体表现，锤实的肯定}

  【带走一句】{本关核心认知的一句话提炼——你以后想起这关时该记得的那句}

  【下一步值得试】{补练方向转成邀请而非作业：具体、可选、带期待感}
╚════════════════════════════╝
```

  话术约束（温暖型·非讨好型）：✅肯定必须锤在具体表现上（引证据），⛔空夸（"你真棒"无证据=谄媚）；✅结尾落在"继续的动力"（下一步邀请/待解锅的钩子），⛔落在说教；验收不过时结算框照出（结果=🔄未通过），【你做对了什么】照写（不过关≠零收获），【下一步】指向缺口的最小补齐动作——让"不过"的终值也是可继续的而非沮丧的
- **讲评出厂三检（v0.8.2·你定"不能让答案出半点错误"·QD-014事故反哺）**：验收后向你输出参考答案/讲评类内容前——①**分级**：名词类事实（IP归属/人名/机构/数字/年份）逐个过"我验过还是我记得"，记得=⚠️ ②**核验**：⛔禁止跳过——全部名词类事实逐条WebSearch核验，查不实=降级⚠️或删（原因是"错得自信"会绕过自觉标注，唯有强制外查物理堵死）③**透明**：文末附事实断言清单+各自验证状态，把置信度亮给你。⛔标题禁用"标准答案"——不给内容穿免检马甲。原理：消灭的不是错误是"未标记的不确定性"——每个事实要么🟢验过要么⚠️标记，永不存在第三态
- **成就记日记（v0.7.0·你定）**：验收通过/成就解锁/等级晋升 → AI**当场**追加到当天日记（格式对齐daily-buddy即时记账："🎓 过关：{路径}第N关 +N⚡"/"🏆 解锁：{成就名}"）；当天日记不存在 → 记入progress.json的pending_diary字段，晚间复盘时由AI补记——⛔不静默丢弃
- **防注水物理锁（v0.8.0·你定·替代对账闸门为第一防线）**：完成状态存HTML文件内`const VERIFIED=[...]`数组，⛔无完成按钮——用户物理无法点击过关；Agent B验收通过后✅AI编辑该行写入节点索引+同步progress.json，你刷新页面自动播庆祝。浏览器不能改文件=账本只有AI的笔
- **防注水对账（v0.6.1·你定）**：HTML勾选=视图标记非真值；你发来的同步文本与progress.json验收记录不符 → 以验收记录为准——⚡只能被Agent B验收赢得，不能被点击领取（S006"宣告权外置"的产品化）

### Phase 4：周期巡检
- 触发词："好好学习 检查进度" / "学习进度" / "上次学到哪了"
- 读日记+路径图status → 生成进度报告
- 检查：有没有放弃/卡住/还记不记得

## 四.5、HTML交付模板（v0.5.0·皮叔拍板设计）

Phase 1路径图产出后，✅DO用 `references/learning-map-template.html` 生成交互版：
- **只替换**文件内 `const ROADMAP` 对象（数据来自本schema的YAML），引擎代码⛔不动
- **资源字段·可查证三层契约（v0.8.6·你定·替代v0.8.1中性化）**：⛔禁止"任一篇讲清X的科普介绍"/"X案例分析一篇"这类不指物的写法——"任一篇"是把筛选+核验成本全甩回用户（2026-08-05 L3评估定案：v0.8.1"不写平台名"被误扩为"不写具体出处"，AI在禁止补集里选最省力点）。资源字段✅DO满足三层契约、逐层可检：
  - **①可定位**：给出唯一标识（四选一即可）：ISBN / DOI / 官方域名+文档名 / 具名企业+案例名+出处。⛔DO NOT 只写"作者+书名"无标识符——无唯一标识=无法定位=退回"任一篇"级
  - **②已核验留痕**：ISBN 与书名+出版社+年份**必须来自同一条检索结果**（⛔DO NOT 凭记忆拼字段——记忆拼接正是 2026-08-05 实测 4 条书目 3 条错配的根因）；路径图 YAML/HTML 资源行✅DO附核验渠道：`（已核验：{YYYY-MM-DD}·{出版社官网/图书馆OPAC/ISBN库}）`，**无渠道=视为未核验=该条必须标⚠️**——⛔DO NOT 只写"已WebSearch核验"（意向性表述会名义执行实质失效）
  - **③可读适配**：中文资源优先；英文原版必须标 `【英文原版·N页】`；影印版必须标 `【影印版·英文】`——⛔DO NOT 把英文影印版当中文版推荐（2026-08-05 实测：《AI工程》东南大学社2025 ISBN 9787576620047 是英文影印版 509 页，非中译本）
- **资源类型按Bloom目标选（v0.8.6·你定·默认值+可覆盖）**：理论/概念节点(记住/理解/分析)→一手来源或权威著作（原著/教科书/官方指南）；实操节点(上手)→具体具名真实案例（企业名+案例名+出处）；创造节点(评判/创造)→用户自有资产优先。**⛔这是默认建议不是硬矩阵**——节点实情不匹配时✅DO覆盖，但覆盖必须写一句理由（如 Apply 节点配理论书：需先建底层认知）
- **逃生阀（v0.8.6·你定）**：确实找不到权威一手出处时✅DO写 `"暂无权威中文出处·建议直读X的原论文/官方文档"` 并标⚠️；⛔DO NOT 硬凑一本沾边的书充数——无此阀，严规则会逼出新的幻觉品种
- 保留项：⛔不出现具体平台名（维基/YouTube等墙内不可达资源=指路进死胡同），⛔不用操作指令式字眼（搜/百度/Google一下）——资源栏写"找什么"，不写"怎么找"；用户自有资产（自己的后台/系统内文件）可直接指名；**多项资源用" + "分隔逐件列出（你定：符号分件=人眼一秒清点要找几样，⛔不揉成长句）**；"词条"等载体词中性可用（各家百科都有词条）
- **核验机制复用（v0.8.6·你定）**：资源字段的核验直接复用 v0.8.2「讲评出厂三检」三步（分级→强制外查→尾注透明），⛔不另起炉灶造第二套核验机制——同一 skill 内两套核验标准=自相矛盾
- **出图必跑资源校验（v0.8.7·你定·执行保障层）**：Phase 1 路径图产出后、交付前，✅DO必须运行 `~/[记忆共享中心]/技能配置/good-good-study/scripts/verify_resources.py <路径图.md>`（校验：ISBN校验位/可定位标识/违规字眼/核验留痕四关）；**⛔校验未全过 = 图不交付，退回修正后再跑，直到 exit 0**——原因是 v0.8.6 三层契约写的是"规则"，本条款写的是"规则的执行保障"：规则不卡执行=上轮 L050"宣称验证过却 3/4 错"的教训重演（2026-08-05 L3 评估实测）。⛔DO NOT 跳过校验直接交付（即使时间紧）——校验跑一次≈1秒，出错的代价是你照着假书单去买
- bloom字段填**人话能力名**（记住/理解/上手/分析/评判/创造），⛔不显示英文Bloom层级名——大白话规范
- pts按Bloom梯度递增（记住1/理解2/上手3/分析4/评判5/创造6）
- 产出文件命名 `{LXXX}-{主题}.html` → 存 `07-主动学习/学习路径图/`（唯一物理家；`个人AI档案/学习地图`=软链替身入口——你定2026-07-27，原因是Obsidian界面不显示HTML，替身给你Finder快捷入口且零双本账）
- **进度同步三层（v0.6.0·防孤岛铁律）**：localStorage=交互缓存 → 你点「📋 同步进度」发文本给AI → AI更新 `07-主动学习/学习路径图/progress.json`（**真值源**）+ `成就系统/学习成就.md`（累计⚡·达阈值触发铜30/银80/金150/钻300+弹窗）+ 路径完成记日记。Phase 4巡检读progress.json。⛔localStorage不是真值——换设备/清缓存即失
- 配色（你定·对齐布洛陀手册DNA）：米黄底#f0ece4+克莱因蓝#002fa7+金#E8C840
- **主题定制成就（v0.7.0·你定）**：出图时✅DO随内容创作badges数组（每图4-8枚）——命名要求：好玩+贴题+人话（如咖啡图"第一滴金/味觉侦探"），⛔不用通用模板名凑数，**终局徽章(when:all)尤其⛔禁用"大满贯"——每张图的登顶时刻必须有专属名字（咖啡图"出师之杯"/写作图"付梓成书"这类），原因是终局千篇一律=跨图收集欲归零**；when取值start/node:i/count:n/half/all；关键关卡（最难/最有成就感的）必配专属徽章。⛔不单开成就设计流程——成就是出图创作的固定字段，边际成本≈零；未提供badges时模板自动降级通用款（引擎兜底）
- 设计基因（你定·2026-07-27）：Duolingo单列三态路径+WOW能力点+成就收集墙(灰剪影)+轻庆祝；靛蓝#4F46E5；游戏奖励循环=勾选→⚡飘字→进度跳→成就解锁→下关点亮
