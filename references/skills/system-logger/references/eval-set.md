# system-logger · 评估集（Eval Set）

> P0 评估集门禁（Skill标准规范 §6.1）。渐进披露：评测/自检时按需 Read，不常驻 SKILL.md 头部。
> 主文件：`../SKILL.md`

## 评估集（Eval Set）

### 应触发
| # | 触发场景 | 预期行为 |
|---|---------|---------|
| 1 | 实质性任务完成后（如修改了文件） | 自动触发日写入流程 |
| 2 | 用户说"写日志" | 触发日写入流程 |
| 3 | 用户说"系统月报" | 触发月度蒸馏流程 |
| 4 | 用户说"记入系统日志" | 触发日写入流程 |

### 不应触发
| # | 触发场景 | 预期行为 |
|---|---------|---------|
| 5 | 纯闲聊/问答 | 不触发——无实质产出 |
| 6 | 改typo/格式微调 | 不触发——非实质性任务 |
| 7 | 纯读取文件未做修改 | 不触发——无产出 |
| 8 | 用户说"月报"（无"系统"前缀） | 优先处理每日伙伴触发 |

### 运行时行为
| # | 测试场景 | 预期行为 |
|---|---------|---------|
| 9 | 日志文件不存在 | 创建新文件+写入头部骨架+追加条目 |
| 10 | 日志文件已存在 | 写前门禁（systemlog_gate_check.py exit 0）→ 经 append_log_entry.py 委托追加条目（脚本内部 cat >>·AI 手动 cat >> = 绕过违禁·2026-09-01 对齐 v3.10.5+ 脚本委托主路径） |
| 11 | date命令失败 | 脚本内部 date 失败→拒写报错（v3.10.5+ 主路径）；AI 手写场景（如有）时间字段留空+标注🟡降级（2026-09-01 对齐脚本承接语义） |
| 12 | 同一任务重复触发 | 跳过写入+标注"⚠️重复写入已跳过" |
| 13 | 三层校验未通过 | 回到步骤3补正 |
| 14 | 写前门禁检测到异常（h1重复/概览缺失/体积超限/工具名违规） | systemlog_gate_check.py exit 2/3/4/5/6 → 🔴拒写+报警，先治理（备份记忆琥珀→去重/重组→回验）再恢复写入 |
| 15 | 日志文件不存在（新建骨架格式） | 文件头 `# 系统日志 {YYYY-MM-DD}` + `## 今日概览`（无📋·与门禁 `^## 今日概览` pattern 一致）+概览表+组头追加 |
| 16 | 验证块输出（v3.13.0） | append_log_entry.py stdout 末尾验证块包含「🔖 流程完成令牌：{8位hash}」——sha256(time+random)前8位，脚本机械产出，AI不能伪造 |
| 17 | --verify-reply正例（v3.13.0） | 回复包含「🔖 流程完成令牌：{hash}」→ exit 0+「✅ 回复完整性：通过」 |
| 18 | --verify-reply负例（v3.13.0） | 回复不包含令牌（如AI自创总结表格跳过验证块relay）→ exit 1+完整诊断信息（可能原因+修复建议） |
| 19 | 回复不包含令牌（v3.13.0） | 完整性锁第5项「回复包含流程完成令牌」未通过→ 流程未完成→ 必须重新逐字relay验证块（含🔖令牌行） |
