# 激活状态文件模板

> **用途**：唤醒记忆系统 Skill 步骤8 的激活状态文件生成模板
> **引用方式**：步骤8生成ACTIVE_STATE.md时参考此模板

```markdown
# 激活状态文件（由唤醒记忆系统生成，新任务必读）

> **生成平台**：{{PLATFORM}} | **生成时间**：{{TIMESTAMP}} | **有效期**：至下次刷新前

## 路径索引（六端通用）
- 个人AI档案根目录：`~/个人AI档案/`
- 系统日志：`~/个人AI档案/工作日志/系统日志/`
- 三明智Skill：`~/个人AI档案/技能配置/triwich/SKILL.md`

## 已加载能力清单（六端通用）

### 1. 三大思维（已加载，可按路由规则触发）
- **抽象建模（Step-Back）**：用户说"分几类""对比一下""整体看看"时触发
  - 用法：分类声明3行+主观假设≥3行
  - 来源：三明智Skill v3.9.1（自动判断L1深度）
- **第一性原理**：用户说"为什么""本质""底层逻辑"时触发
  - 用法：追问链+锚点两列对立面+本质识别
  - 来源：三明智Skill v3.9.1（自动判断L1/L2深度）
- **批判验证**：用户说"靠谱吗""证据""风险"时触发
  - 用法：自我批判+8要素评估+自爆机制+实践检验
  - 来源：三明智Skill v3.9.1（自动判断L1/L2深度）
- **三明智L3**：用户说"全面的""深度""严谨""合理"时触发
  - 用法：完整流程（Step0→G5），必须执行完整
  - 来源：三明智Skill v3.9.1 · triwich

### 2. 产出签名规则（已加载，每条回复必须执行）
- 格式：`[前缀 归档对象 | 摘要 | 日期]`
- 前缀：🧠(记忆层) / 📝(系统日志) / 📋(文件变更) / 📓(日记) / 🚀(版本发布)
- 位置：回复末尾，署名之前
- 忘记加=系统故障，下条必须补上

### 3. 铁律/执规（已加载，每次执行必须自检）
- 铁律-001 先看清再动手
- 铁律-002 实事求是底线
- 铁律-008 意图分类+路由签名
- 执规-002 完成验证（做完必须复查）
- [完整列表来自用户基本规则-铁律版]

### 4. 用户基本规则摘要（已加载）
- 决策画像：先计划→先做、快速试错、边做边调
- 沟通偏好：直接指出问题、列表化、不给3个以上选项
- 红线：不做违背良心/伤害家人/只利己不利他/长期无正向反馈的事

## 使用方式
新任务启动时，先读取本文件确认已加载能力，然后：
1. 分析用户消息→匹配意图分类→触发对应路由
2. 执行对应思维流程→输出路由签名
3. 如有违反铁律→立即回溯

## 文件位置
- 本文件：`~/个人AI档案/ACTIVE_STATE.md`
- 三明智Skill：`~/个人AI档案/技能配置/triwich/SKILL.md`
```

**变量替换规则**：
- `{{PLATFORM}}`：步骤1识别的平台名
- `{{TIMESTAMP}}`：当前时间

**六端通用保证**：
- 文件位置统一：`~/个人AI档案/ACTIVE_STATE.md`（所有平台共享）
- 内容结构平台无关（能力清单+用法+路径变量）
- 各平台只需在各自的"新任务入口"加一行读取指令

**WorkBuddy平台额外操作**：
- 同步追加激活摘要到 `~/.workbuddy/MEMORY.md`
- 格式：`- 🧠 激活状态(YYYY-MM-DD)：三明智v3.9.1 loaded, L1/L2/L3路由就绪, 铁律X条+执规X条 loaded`
