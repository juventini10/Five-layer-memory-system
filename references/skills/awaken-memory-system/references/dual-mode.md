   - exit 0 且 all_pass=true → ✅ 补跑成功

   - exit ≠ 0 → ❌ 脚本执行失败（输出错误信息）

**输出确认块**：
```
🪞 自画像补跑结果（YYYY-MM）
├─ 脚本：distill_containers.py --generate --verify
├─ exit code：[0/非0]
├─ all_pass：[true/false]
├─ 自画像文件：[路径] [✅存在/❌缺失]
├─ 7段必含字段：[N/7已填充]
└─ 状态：[✅补跑成功/⚠️部分缺失/❌执行失败]
```

**失败处理**：
- 脚本执行失败 → 输出错误信息 + 建议"手动检查daily-buddy月报流程或手动生成自画像"
- 部分容器缺失 → 输出missing_files列表 + 建议"重新运行月报第6.5步五容器回流"
- 不阻塞后续操作（自画像补跑是增强功能，不是核心流程）

**诚实边界**：distill_containers.py生成的是五容器**骨架文件**（含必含字段标题），具体内容仍需AI在月报流程中填充。本触发只保证文件存在+字段结构完整，不保证内容质量——内容质量由月报第6.5步的AI蒸馏负责。
