# 结果块层级示例

> 模板定义唯一真源仍在 `SKILL.md §结论块模板`（v4.7.3 容量治理：教学性示例拷贝外置，渲染义务条款本体未动——L3"独立段头+禁软跳转"约束在 SKILL 原文保留）。

```

## L2 {思维1}&{思维2} 结果

**【第一层·深度追溯】**(折叠/文件通道·可跳过)

| 追溯项 | 内容 |
|:---|:---|
| [双思维产出物] | [思维1+思维2的锚点/8要素等·语义符号🟢🟡🔴🔵保留] |

**认知格（第一层子表）**（全层级·自适应呈现：有货的象限渲染成行、空格不渲染；有货格<2 整表不挂；行名直用四术语，⛔计数⛔比喻⛔教学句）

| 象限 | 本轮条目（条目本体+档位+指针） |
|:--|:--|
| {已知已知 / 已知未知 / 未知已知 / 未知未知·有货才写} | [条目本体·{推测级/佐证级}·指针] |


**【第二层·关键依据】**(≤3条·一句话·结论块内自证)

| # | 依据（含档位·指针） |
|:--|:---|
| 1 | [内容·实证级·复现手段（命令/测试/第三方复验）] |

| 3 | [内容·推测级]（无外部撑腰·无指针字段·参与总档封顶） |

**【第三层·结果+下一步】**(结果在交付终点·紧贴签名·离输入框最近)

| 项 | 内容 |
|:---|:---|
| 🎯 结果 | {✅/🟡/❌} {结论一句话} |
| 证据等级 | {推测级/佐证级/实证级}（总档取最弱承重柱·禁平均稀释） |
| 下一步·待你 | {默认推荐一句话}（默认推荐·不代执行；回「✓」即办／「跳过」即搁） |
| 下一步·系统 | {对系统的动作：FU号 或 任务卡名·动作；无则「无」} |

> **闸与呈现（v4.10.x）**：负担闸=待你行限价值层/不可逆/跨SSOT（只读实测执行者跑完）；单签名行=结论块后仅一行签名。
> 表情规则:项目标题只"🎯 结果"用表情;正文语义符号不干涉。**状态符号**:✅=结论成立|🟡=有条件成立|❌=结论不成立。**结论位置锁**:结论块=回复最后一项(你批准·2026-08-11)。
> **验证架构(v4.4.1·差异外显)**:单Agent 自检链--G1 苏格拉底诘问(五问自答)→ Step3 批判验证(8要素+自爆)→ 输出前自检(结论块门禁锁3问)。验证者=执行者自己,⛔无独立审查(对照 L3:Agent B 双Agent 独立盲审·Agent B 验证行)。
```

🔒 **门禁锁(签名前自主过一遍)**:1结论明确(✅/🟡/❌已选)2依据可追溯(结论块内自证)3签名摘要=结论块浓缩版。三问通过→签名;任一未过→退回补结论块。

签名格式:`[🧠 三明智 L2 ({思维1}+{思维2}) ✅ | 结论块浓缩版 | 日期]`

### L3:双Agent深度模式(完整,11步+1子目标+2检查点)

> 🔴 **L3呈现锁(v3.14.0 呈现精简改造·皮叔批准;v4.5.0 措辞更新)**:L3 对话呈现 = 启动简报块(3行) + 结论块(含 Agent B 独立验证行)+ 签名--⛔DO NOT 在对话内联转发 Agent A 推导/步骤叙述(用户只看结果,论证过程由文件通道留痕 + Agent B 盲审保障)。文件通道(/tmp)同时服务 Agent B 盲审隔离与推导留痕(Agent A 落盘 3 文件不变)。主agent 角色=orchestrator(启动 Agent A/B + 输出结论块 + 签名),无步骤叙述权限接口(见 full-flow.md 主agent角色锁)。⛔DO NOT在Skill执行链之外自造带Step编号的L3流程复述--编号与思维模块严格绑定,反贴即错(详见§禁止行为 #7)。

> 🔀 **跨平台声明（v4.10.7·检查⑩合规）**：示例中 `/tmp/triwich_l3_{ts}/` 为 macOS/Linux 口径；Windows 端等价替换为 `%TEMP%\triwich_l3_{ts}\`（运行时按 tempfile.gettempdir() 派生，非硬编码 `/tmp`，见 p0-step0.md §临时目录声明同源）。
执行前确认:本轮键文件 `steps/step0-determination-{ts}.md` 存在且标注L3(`{ts}` 与 `/tmp/triwich_l3_{ts}/` 同源同值,一轮一键)。

> **v3.0变更**:双Agent架构--Agent A(执行者)负责Step0→G1,Agent B(验证者)独立执行Step3。盲审设计+文件系统传递+Agent B独立WebSearch。

**Agent A(执行者)**:Step0→Step0.5→Step1→Step2→G1→写入文件  
**Agent B(验证者)**:读取文件→Step3(实事求是检查+8要素+自爆+实践检验+认识循环)→**结论块+门禁锁**→返回✅/❌+审查报告

**结论块(设计端防误·内联强制,禁止软跳转)**:L3 结论块必须独立成 `## L3 深度模式 结果` 段头(2026-08-11 换新:替换原 `## 🔒 L3 结论块`)、紧跟 Step4 之后签名之前,**强制渲染下表(不得压成散文 bullet--19:12 实跑曾因"同L1见上文"软跳转漏渲染,已定为设计缺陷)**:

#### Step 0.5:子目标拆解(v3.4新增·L3专属)

📦 **产出物**:子目标清单(✅DO写出来,不是AI脑子里想的)

🔌 **熔断器**:

- 成功条件:输出4个子问题 + 子问题3含≥3条隐含假设引用
- 失败处理:子问题数≠4 或 子问题3引用不完整 → 重新拆解
- 重试次数:1次
- 降级方案:不如期生成则对话输出子目标清单(不写文件)

仅L3深度模式触发。将用户的"全面评估/深度分析"指令拆解为4个子问题,确保覆盖三大思维维度。**子问题3直接引用Step0.5隐含假设扫描的3条假设作为输入**--不重复推断,直接读取本轮键文件 `step0-determination-{ts}.md` 中的隐含假设声明段。

🛡️ **自爆增强**:子问题3的3条假设风险等级全部为🟢 → 虽然Step0.5已触发自爆,但L3额外要求子问题3中至少报告1条"确认成立"的结论(不能只说不确定)。

🔒 **子目标锁(v4.2.0·成本匹配复杂度)**:Agent A 走**1轮**完整流程(Step1→Step2→G1),自然产出4个📦。⛔DO NOT 对每个子问题各走一遍完整流程--原因是1234本身就是Step1/Step2/Step0.5/G1的自然产出,对答案再走一遍=循环重复劳动(主线9"防过度设计")。  
**4个📦产出物(接触法·Fail-Closed·缺=退回)**:

|                                 子问题                                | 📦产出物(必填)               | 自然来源于                |
| :----------------------------------------------------------------: | ----------------------- | -------------------- |
|                                1核心矛盾                               | 【主要矛盾/锚点判定】             | Step2 第一性原理          |
|                                2模式结构                               | 【结构模式命名+MECE自检】         | Step1 抽象建模           |
|                                3隐性前提                               | 【假设验证结论(≥3条·引用Step0.5)】 | Step0.5 + Step3 对抗验证 |
|                                4综合结论                               | 【最终判断+建议+置信度】           | G1 诘问 + Agent B 交叉终判 |
| 🔒 **检查点**:4个📦任一空=退回补全。深度由📦(填不出=没做到)+Agent B(防敷衍)双保障,⛔不由"走几遍"保障。 |                         |                      |
