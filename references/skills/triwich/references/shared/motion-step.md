## 方法论定义

步序法（Motion-step method）是Poka-Yoke防误三法之一。核心原则：**上步未完成，不可执行下步**。通过物理步骤产出物锁（📦）和熔断器（🔌）阻断跳步。

## 执行模板

### 全局串行链

```
Step0（路径判定）
  └─ 产出 step0-determination-{ts}.md（本轮唯一键·v3.15.0）→ 🔌 熔断器检测缺失/键不匹配 → 中止
    └─ Step0.5（隐含假设扫描）
      └─ 产出 3假设 → 🔌 自爆检测全员🟢 → 强制重推
        └─ Step1（加载reference+首思维模块）
          └─ 📦 → 🔌 缺失 → 退回Step0
            └─ Step2（第二思维模块·L2/L3）
              └─ 📦 → 🔌 缺失 → 退回Step1
                └─ G1（苏格拉底诘问·L2/L3）
                  └─ 📦 → 🔌 缺失 → 退回Step2
                    └─ Step3（批判验证+Agent B盲审·L3）
                      └─ 📦 → 🔌 缺失 → 退回G1
                        └─ G2（验证计划·Agent B产出·L3）
                          └─ 📦 → 🔌 缺失 → 退回Step3
                            └─ Step4（输出前自检G4+G5·L3 → 结论块+门禁锁 → 签名；L2 侧 Step4=结论块+门禁锁 → 签名，无 G2/G4/G5）
```

### 步序中断规则

| 中断条件 | 动作 | 不可操作 |
|:---------|:-----|:--------|
| 📦 产出物空/不存在 | 退回上一步重产 | 不可跳过直接进下步 |
| 🔌 熔断器触发 | 中止全过程 | 不可自行补写文件后继续 |
| 🛡️ 自爆触发（8要素评估结论全员正面） | 强制复检≥2非正面 | 复检后仍全员正面→签名必须标❌（与 8element.md/SKILL.md 判断标准一致） |
| 🔒 门禁锁三问未通过 | 退回补充结论块 | 不可输出签名 |


## 步序法三原则

| 原则 | 说明 | 反例 |
|:--|:--|:--|
| 强依赖 | 步骤B的输入必须来自步骤A的明确产出 | 见Step0空→跳过直接写Step1 |
| 不可降级 | 缺失产物时中止，不降级执行 | "Step0文件缺失?那我凭记忆走L1" |
| 单一路径 | 一条路径走到头，不分叉不自选 | 碰到熔断器"算了走另一条路" |
