> **置信度标准（四级·v3.17.0 补悬置档）**：
> - 🟢高=≥2个独立来源且交叉验证一致（grep可验·列出具体来源）
> - 🟡中=1个来源或多源有分歧
> - 🔴低=无外部来源仅AI推理

> ✅DO 结论若证据不足以支持任一档，用🔵悬置——原因是"不知道就说不知道"是实事求是态度（§九态度元规则），强行下结论=编造=踩宪法级原则1。
> ⛔DO NOT 用🟢/🟡/🔴 替代🔵——原因是三档都预设"有结论"，悬置=承认"暂无结论"是独立状态，混用会让"证据不足"被误标为"低置信度结论"。

## 🛡️ 自爆机制

**🔒 检查点（v4.4.15 补·Fail-Closed）**：8 行「评估结论」列任一为空 / 仅填符号（✅/🟢/正常/没问题）而无论据 → **本步骤未完成，退回补全**。——原因是本模板此前是三明治唯一**无「缺=退回」条款**的产出物锁（同族 `references/shared/anchor.md` 两列对立面有「任一列为空=锚点无效=必须重新追问」），属**同族强度不一致的遗漏**而非设计；且 8 要素是 L1批判验证/L2/L3 三层共用的定值法基座，无检查点则"弹性 AI 缩减行数"这一原典要防的失效模式无闸（通用规范 宪法级原则 11「⛔DO NOT 只有'数量下限+检查点+AI自判'」）。
🔒 **落盘（v4.4.15）**：本表 ✅DO 静默追加写入本轮键文件（L1/L2）或文件通道（L3·`agent_a_output.md`），按 `### Step2：8要素评估` 分段；**⛔DO NOT 渲染到对话**（呈现层豁免不受影响）——判据唯一源见 `SKILL.md §防跳步机制 · 产出物静默落盘锁`。

**判据（唯一口径）**：看第2列「**评估结论**」的正负向，**与第3列置信度颜色无关**。
——原因是"绿灯"一词曾被同时用来指"结论正面"和"置信度🟢"，两套判据触发点不同；判据不确定=定值法防错失效。

```
8行「评估结论」全部为正面表述时，触发强制复检：
⚠️ 8要素全员正面 = 评估不充分。必须找出≥2个评估结论不是纯正面的要素，重新扫描。
```

**复检后仍全员正面** → 在评估结论末尾追加 `（⚠️ 复检后仍无实质性发现，可能超出当前知识范围）`，但签名必须标❌。

> **置信度全🟢 不触发自爆**，但属质量提示：全员🟢高置信度而无任何🟡/🔴，通常说明来源核验不充分（见下文§质量判定）。

## 质量判定

| ❌ 糊弄写法 | ✅ 合格写法 |
|------------|-----------|
| 8行全写"✅通过""正常""没问题" | ≥2行有具体风险/不一致/未知/待验证 |
| 每行只有置信度符号无论据 | 每行有一句话论据（"因为XXX所以评估为YYY"） |
| 全员🟢高置信度 | 至少有🟡或🔴标注 |
| 结论照搬Step2未引入新视角 | 有独立于Step2的发现 |
