> **触发**：用户仅含"分类/对比(无判断词)/整体看/模式"等关键词
> **步骤**：4步 | **模板**：共用签名（→ 见 `references/shared/signature.md`）+ 共用结论块门禁锁（见SKILL.md §结论块模板）
> **操作口诀**：十六字方针——去粗取精 → 去伪存真 → 由此及彼 → 由表及里（来源：毛泽东《实践论》1937，白皮书§1.2溯源）

## 抽象建模操作指引：十六字方针

> 来源：毛泽东思想调查研究方法论——《实践论》（1937）。已在白皮书§1.2溯源表中收录。

执行抽象建模时，用以下四步操作替代模糊的"请抽象"：

| 方针 | 白话 | 在抽象建模中的操作 |
|------|------|------------------|
| **去粗取精** | 扔掉不重要的 | 从一堆信息中筛出关键要素，忽略噪音和次要细节 |
| **去伪存真** | 别拿假当真的 | 区分表面现象和本质规律，剔除误导性信号 |
| **由此及彼** | 联想对比 | 从当前模式推演到同类问题，检验是否可迁移 |
| **由表及里** | 看到骨架 | 识别结构模式，不只看表面——提炼出可复用的类别和原理 |

此四步适用于所有深度层级（L1/L2/L3），是抽象建模的统一操作入口。执行完四步后，进入Step1（分类声明）填表。

---

## Step1：分类声明

| 字段 | 填写要求 | 实际内容 |
|------|---------|---------|
| 问题类型 | 这是一类什么问题（用抽象类别描述，不是具体场景） | |
| 抽象原理 | 这类问题的核心原理是什么 | |
| 参考框架 | 业界/学界的标准做法是什么 | |

🛡️ **验证标准**：
- "问题类型"必须是抽象类别（不是具体场景复述）
- "抽象原理"必须揭示核心机制（不是常识描述）
