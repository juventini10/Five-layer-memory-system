# L1-第一性原理（单层·轻量）

> **触发**：用户仅含"分析/本质/底层/为什么/原因"等关键词，无"分类/验证"等双路由触发词
> **步骤**：4步 | **模板**：共用锚点两列（→ 见 `references/shared/anchor.md`）+ 共用结论块门禁锁（见SKILL.md §结论块模板）+共用签名（→ 见 `references/shared/signature.md`）

---

## 开始前：路径声明（对话第一个输出）

在任何步骤执行前，以以下格式输出路径声明作为**对话第一条回复的开头**：

```
三明智 L1 路径：第一性原理
```

声明后进入Step1。

## Step1：追问到锚点

追问表格行数≥3（L1由AI判断最少追问层数，但锚点必须抓到主要矛盾）：

| 追问层级 | 问题 | 回答 |
|---------|------|------|
| 第1层 | 为什么？ | |
| 第2层 | 为什么？ | |
| 第3层 | 为什么？ | |
| ... | ... | |

**锚点（→ 见 `references/shared/anchor.md` 填入两列对立面模板）**：

| 对立面A | vs | 对立面B |
|---------|-----|---------|
| | | |

**判定**：A和B是否存在结构性冲突？

🔒 **检查点**：两列对立面任一为空=锚点无效=回溯重问。判定填"否"=追回重问。

---

## Step2：识别本质

| 要素列举（不是本质） | 本质（要素间的关系和结构） |
|---------------------|------------------------|
| | |

**本质≠要素清单。** 本质是"这些要素之间是什么关系、什么结构导致了这个问题"。

🛡️ **验证标准**："本质"列是否揭示了要素间的关系结构（不是要素清单复述）
