## Step2.5：决策类双轨分析（T2·v3.16.0 新增·owner=本Skill）

> **触发判定**：Step2 识别出对象若属**决策类**——一句话能转成"要不要/该不该/选A还是B/做不做"的问句——⛔DO NOT 直接进结论，强制先走双轨。

**为什么（因果链）**：纯逻辑拆解只能覆盖决策的"理性面"，但真实决策里"心里想但嘴上不说"的动机（情绪/冲动/安全感/沉没成本）往往才是真正的支配变量——只看理性轨=结论"逻辑上对但现实中做不到"=假分析。双轨让理性和心理两股力量并列，才抓得住决策的主要矛盾。

**双轨强制双列（⛔两列缺一=回到 Step2 补全）：**

| 轨 | 驱动力量 | 问句 | 这一轨的结论 |
|----|---------|------|------------|
| 🧠 **理性轨** | 逻辑/利弊/数据/代价 | 理智上，选什么最划算、为什么？ | |
| 💓 **心理轨** | 情绪/冲动/偏好/安全感/沉没成本 | 心里那关，它拽你往哪走、在怕什么？ | |

**判定规则**：双轨并行列出后，判定"心里那关"与"理智那关"是否同向。
- 同向 → 决策阻力小，主要矛盾在两者共同指向处 → 结论由此出。
- 反向 → **主要矛盾就在两轨的冲突点**——⛔DO NOT 只取理性轨结论，须把心理轨的顾虑显式写进结论的边界/保留条件（对齐 L1 结论块 🟡 有条件通过）。

🔒 **检查点**：双轨两列任一为空 → 回溯追问该轨再继续。决策类对象未走双轨直接出结论 = 假分析，退回重做。

**呈现格式（v3.14.0 呈现精简：内部执行，⛔不渲染——双轨表只在执行链内生成，供 Step3 结论块引用）**
