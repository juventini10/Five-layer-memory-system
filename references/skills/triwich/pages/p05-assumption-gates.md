# Step0.5 三闸页（隐含假设/顺序判定/深度四格）

> L1 轻活轮免四格（v4.7.2 S3a）；隐含假设与顺序判定按档位装载。
> **翻页回执格式（SKILL.md §生命周期装载表）**：读完本页后在本轮键文件落一行 `已读 pages/p05-assumption-gates.md @<8位指纹·取本页 frontmatter page_fingerprint 现行值>`——缺行=装载不可观测（工程控制论·能控⇔能观对偶），封口对账判红。

#### Step0.5:隐含假设扫描(v3.8新增)

📦 **产出物**:3条用户隐含假设,追加写入 `steps/step0-determination-{ts}.md`(`{ts}` = 本轮键,⛔不另铸新键、⛔不写固定名文件)

**定位**:所有层级(L1/L2/L3)在Step0判定后、加载路径前执行的通用步骤。不打断用户,AI自己完成。

**操作流程**:

AI根据Step0判定的任务类型和当前对话上下文,推断3条最可能的用户隐含假设。按以下模板写入本轮键文件 `step0-determination-{ts}.md`:

```
### 隐含假设声明
| # | 假设内容 | 来源依据 | 风险等级 | 验证状态 |
|:-:|:---------|:---------|:--------|:---------|
| H1 | | | 🔴高/🟡中/🟢低 | 未验证 |
| H2 | | | | |
| H3 | | | | |

**重要性自检**:如果这3条假设都是错的,结论是否会完全改变?
→ 是 / 否(如"否"→退回重推至少1条🔴高风险假设;**重推后仍"否"→签名标❌+输出缺失清单终止本轮**(终局出口·2026-08-30补C4·防无限循环/违规继续二选一困境))
```

| 字段   | 填写要求                                                                                                                                            |
| :--- | :---------------------------------------------------------------------------------------------------------------------------------------------- |
| 假设内容 | 一句话,用户觉得理所当然但AI需要知道的前提                                                                                                                          |
| 来源依据 | 从对话中哪句话/哪个上下文推断的(标注行或概括)                                                                                                                        |
| 风险等级 | **影响度语义**(全Skill唯一口径):🔴假设错了结论会变 / 🟡有影响但不致命 / 🟢影响不大。⛔DO NOT用"证据强度"语义(有无文献支撑)填此列--证据强弱写在「来源依据」列。原因是自爆判据是"全🟢→强制重推",影响度语义下=罚敷衍,证据强度语义下=罚有据,方向相反 |
| 验证状态 | 未验证 / 验证中 / 已验证(来自\___)                                                                                                                         |

🔌 **熔断器**:

- 成功条件:3条假设 × 4字段全部有值("重要性自检"已答"是")
- 失败处理:退回补全后重新写入
- 重试次数:1次
- 降级方案:推不出3条有效假设时允许写2条,但签名标❌并标注原因

🛡️ **自爆机制**:3条假设风险等级全部为🟢 → 强制重推至少2条🟡以上。重推后仍全员🟢 → 签名标❌ + 标注"Step0.5未能识别有效隐含假设"。不强制编造。

> **L3专属整合**:L3原有的"子目标拆解"Step0.5中的子问题3(隐性前提)直接引用此处的3条假设作为输入。见下文L3 Step0.5细则。

#### Step0.5 证据清单（v4.9.0新增·全档每轮·静默落盘）

📦 **产出物**：`### 证据清单` 段追加写入本轮键文件（与隐含假设扫描同键·⛔不另铸键），格式：

| # | 结论依赖的事实项 | 来源（指针/实测/无） |
|:-:|:--|:--|
| E1 | [] | [] |
| E2 | [] | [] |

- 填写纪律：①**全档每轮**（L1/L2/L3 同规格，档位体系不因层级打折）；②来源列✅DO给可查指针（文件:节名/卡号/日志行/复跑命令），拿不出=打「⚠️无来源」；③本段**静默落盘**，⛔不渲染到对话（呈现精简不受影响）。
- **缺料闸（具名·v4.9.0）**：**承重依据**（重要性自检=是，即该依据被推翻则结论变；含隐含假设 H🔴 且重要性自检=是）无来源 → 结论块🎯结果✅DO二选一：**条件式「补源X则…」** 或 **显式求源**；⛔泛化预警（"可能证据不足"类指不出具体缺项）= 门禁锁拒收。
- 档位口径（一行一档·总档封顶）唯一源=`SKILL.md §结论块模板` 证据档注记；⛔本页不另定档名。


#### Step0.5-b:思维顺序判定(v4.4.0新增·仅L2/L3·L1单路径不涉及)

📦 **产出物**:顺序判定行,追加写入本轮键文件 `steps/step0-determination-{ts}.md`(`{ts}` = 本轮键,⛔不另铸新键):

```
思维顺序: {思维A}→{思维B}→{批判验证恒末位}(判定: {保底/语境}·依据: {一句话})
```

**判定规则(三问·命中即判向·全部不命中→保底)**:

|  #  | 自问         | 判向第一性先      | 判向建模先    |
| :-: | ---------- | ----------- | -------- |
|  1  | 本质/规律已知可借? | 未知/惯例失效/要创新 | 有成熟模式可套  |
|  2  | 对象形态?      | 单一深问题       | 杂乱多对象无结构 |
|  3  | 认知预算匹配?    | 高影响决策值得深拆   | 常规分析     |

- **保底规则**:三问判不清→**建模先**(先分类建模→再拆解分析→后验证=历史默认)--保底保证"不判定不换序",防执行漂移。
- **双病症对照(判定校验锚·判定后自检)**:该第一性先却建模先=**拆错维度**(本质未知时分类轴拍脑袋);该建模先却第一性先=**大锤砸图钉**(常规问题耗尽认知预算·复杂自适应系统拆不尽)。换序须能说出在避免哪种病症--两个都答不上→回保底。
- **模块恒全走**:只换顺序不裁剪--三模块+G1 恒定全走,批判验证恒末位(对齐 L2 执行规则"标注重点不改变执行路径")。
- **声明外显(可审计锁)**:换序时路径声明✅DO展开执行顺序:`三明智 {L2/L3} 路径:{执行顺序串·→连接}(单Agent自检链)(标注重点:{思维1}+{思维2})`;保底时路径声明=现行格式+架构尾缀(`{思维1}+{思维2}`(单Agent自检链))不展开顺序串。**架构尾缀(v4.4.1·差异外显)**:L2 路径声明恒带 `(单Agent自检链)`--验证者=执行者自己(G1 五问自答→Step3 批判验证→门禁锁3问自检),与 L3 路径声明 `(双Agent)` 恒定对照,架构差异可审计。⛔DO NOT 顺序判定无产出物行--判定文件无顺序行=违反禁止行为#8。**顺序判定结果同步落简报块第2行深度声明(保底/换序标注)与键文件深度声明字段--第1行格式由本条管,第2行由§启动简报块管(v4.5.0)。**

> **哲学依据**:矛盾论·矛盾的特殊性--特殊矛盾构成特殊本质,本质决定分类轴(本质未知时先拆解,分类沿锚点展开);矛盾论·具体分析具体情况--固定顺序不看对象=八股调。来源:2026-09-16 你提出+WorkBuddy 双路取证(知识池 7 轮+外部方法论 2 轮)+triwich L1 批判验证过愿景闸。

### Step0.5-c:深度四格举证(v4.7.0新增·L1/L2/L3 降档闸·真源=任务卡2026-10-20 D节终裁)

📦 **产出物**:"深度举证行"追加写入本轮键文件（v4.7.2 S3a 收缩：仅**词表命中 L2/L3 且拟降档的轮**执行——降档动作不存在时⛔不填仪式行(纯 L1 轮/升档轮零举证义务)；触发判据与规则正文第一条同口径;与深度声明行同源——本段是"任务本质"的可核查操作化）:

```
深度举证: 先例={命中记录指针或"无"} | 词义={定义出处或"缺"} | 域数={N·列举} | 可逆={回滚路径一句话}; 判定={轻/重/默认重}; 依据:{一句话}
```

**规则(举证责任倒置——"轻"要证据,"重"无须举证)**:

- ✅DO 当词表/语义命中 L2/L3、执行者拟按更浅层级做(降档)时,须出示四项**外部证据**(每项须给可 grep/可读的指针,⛔DO NOT 用"我记得/应该有"的自报顶账——自报深度=两本账,且能报出来的都不叫未知未知):①同构先例——seal.log/decision-room/系统日志中存在同类问题**被验证过**的记录(指针=日期或FU号)②词义已定义——问题核心词在对话或文件里有操作定义(出处行)③域单一——对象跨域数≤1(列举即判)④可逆低成本——做错的回滚路径可一句话陈述。**四条全举得出→判"轻"放行**;任一举不出→**默认"重"**&#x6309;词表层级执行,⛔DO NOT 以"看起来简单"补足缺证(原因:误判代价不对称——多算=时间成本,少算=结论错误,默认永远偏向多算·S981"未测默认未知档"同构)。
- ⛔DO NOT 把举证行做成填空仪式——空话填进去门禁照样过,但事后 S4 对账(键文件无举证/扫描台账却出盘点结论=签名造假信号)会把"填了假证"和"没填"一起显形;本段把"无理由降档"降为"降档留痕",⛔不宣称杜绝跳过(纯AI环境诚实边界见 Skill架构规范 §1.1——绕过成本>遵守成本+绕过留痕)。
- **人工否决权(不对称·皮叔 2026-10-20 批准·任务卡④-b)**:✅DO 你明说"走深/全面/双Agent跑一遍"→立即执行,举证行不得构成降出L3的阻挡(升档无须举证——进深验证永远免费)。你主动要求降档(赶时间)且举证判"重"→可做,但结论块✅DO渲染「声明级·未验证深度」行,⛔DO NOT 与举证通过的结论同档呈现(原因:压档是偏好,举证是资格;偏好可改路径,不改变路径的资格·S527让步条款)。你未表态时,降档唯一通道=四格证据本身。
- ☑SHOULD 回访:本段判"轻"放行的轮次,按封口回访机制(FU)抽样对账——"判轻被推翻"反例数即本段真实考官(上线时同轮登记,见 CHANGELOG v4.7.0)。
