**设计哲学**:Poka-Yoke防错法——三法并用（来源：丰田 Shingo 原典）
- **接触法**：锚点两列对立面（任一列空=锚点无效=重新追问）／字段锁=证据档位+依据档列／格式校验=三层表格固定
  - 两列对立面单边或无效即退回重问；结论块软跳转=违规
  - 证据等级行/依据档位列缺=退回补全（必填字段锁）
- **定值法**：8要素固定数量锁（8行全评·缺=退回补全）／结论块三层表格固定结构
  - L3 四📦子目标产出物锁（任一空=退回）
  - 门禁锁固定项数（七项·不增不减·v4.10.1扩负担闸后口径·2026-10-22 R2计数归正；全树另有~22处「3问」引用（含判据本体/题面·R4实测计数），统一口径=立法级挂账→任务卡R3-4扩面复勘，本声明如实扩面）
- **步序法**：Step0→0.5→…强依赖＋签名二值化（未完成则不可签）

## 功能定位

三明智为分析评估类任务提供三层思维深度保障。本Skill做四件事:

> **检查点编号（唯一源=`references/l3/full-flow.md` §G系列编号说明）**：G1 苏格拉底诘问 / G2 验证计划 / G3=已被 Agent B Step3 批判验证替代（编号保留不重用）/ G4 完成验证 / G5 思考质量自检；G6/G7=格式与数字引用门禁（见 §铁律声明）。

1. **意图分类**--匹配触发词判定执行深度(L1/L2/L3)
2. **路径路由**--加载对应思维模块的reference文件
3. **执行约束**--锚点两列对立面+8要素自爆+签名二值化
4. **结果沉淀**--签名输出到对话+写入系统日志

## 签名规则(全局强制)

| 合法值 | 含义                                                      |
| :-: | ------------------------------------------------------- |
|  ✅  | 该层级全部步骤走完,产出物完整。Step0判定文件存在。结论块已输出且门禁锁三问通过。签名摘要=结论块浓缩版。 |
|  ❌  | 缺任何一步=不输出结论,只输出缺失清单                                     |

**⛔DO NOT输出暧昧的签名(如"基本完成""大致通过")。** 签名只接受✅或❌--原因是二值化消除灰区,灰区=AI自行判断宽松=质量滑坡。

**⛔DO NOT用 ⚠️ 标注把降级/超时混成 ✅。** 任何降级执行(如 L3 Agent B 超时后转单Agent自检)= 步骤未走完 = 签名 **❌** + 输出缺失清单,不得签 `✅ ⚠️降级`。签名轴与结论块内容轴的分离见上文§结论块「两轴分离声明」。
