# 布洛陀 · 对话标题自动命名（可选组件）

> 作用：新会话开始后，自动把对话标题改成 `YYMMDD | 类型 | 主题` 的格式，类型从「功能 / 设计 / 修复 / 优化 / 发布 / 探索 / 文档 / 研究」里自动判断。
> 这个组件**不在安装包里**，需要按下面的步骤自己装。

## 怎么用这份说明（一句话）

**把本文件直接发给你的 AI，说：「读取这个文件，按里面的步骤帮我装。」**

剩下的它来做——建脚本、注册钩子、跑验证。你只需要在最后看一眼标题栏有没有变。

> 本文档是**自包含**的（两个脚本的完整代码就在下面），不依赖任何安装包。
> 唯一的要求：你的 AI 得能读写本机文件（WorkBuddy / Qoder / Trae 这类桌面端都可以）。

---

## 一、它做什么

| 项 | 内容 |
|:---|:---|
| 标题格式 | `260921 \| 发布 \| 安装包说明` |
| 日期怎么来 | 北京时区，取会话实际创建时间 |
| 类型怎么定 | 按你的第一句话自动判断，判断不了就填「探索」 |
| 会不会覆盖手改的 | **不会**——你手动命名过的标题永远保留 |
| 出错会怎样 | 静默跳过，不影响你的对话 |

**第 1 段 · `session_title_utils.py`**

```python
#!/usr/bin/env python3
# version: v0.2
"""session_title_utils.py — 对话标题统一命名·公共原语（跨工具中立）

命名规则:
    标题格式 = YYMMDD | 类型 | 主题
    日期 = 北京时区实际创建日期（取会话 created_at）
    类型 ∈ {功能,设计,修复,优化,发布,探索,文档,研究}（关键词启发式，默认=探索）
    主题 = 首条 prompt 简洁概括

原语（本文件）:
    bj_date_from_ms(ms)  epoch ms → 北京时区 YYMMDD
    classify(prompt)     类型关键词启发式（顺序=优先级；保守窄词优先，默认=探索）
    extract_theme(prompt) 首行（跳过 @引用行）→ 去 markdown 符号 →
                          首个括号配平标点截断 → 限长 20
    make_title(prompt, created_ms) → "YYMMDD | 类型 | 主题"

如果你还有别的工具想接入同一套命名，直接 import 本文件调用，不要把实现
复制过去——复制之后两边各自演化，以后没法同步升级。
"""

import re
from datetime import datetime, timedelta, timezone

# 类型关键词启发式（顺序=优先级；保守窄词优先，默认=探索）
TYPE_RULES = [
    ("修复", ["bug", "报错", "修复", "排查", "异常", "崩溃", "错误", "失效", "复现", "回滚"]),
    ("发布", ["发布", "打包", "release", "安装包", "上线", "发版", "出包"]),
    ("文档", ["文档", "手册", "readme", "规范", "白皮书", "changelog", "说明"]),
    ("设计", ["设计", "ppt", "幻灯", "ui", "视觉", "样式", "风格", "配色", "原型", "页面"]),
    ("研究", ["研究", "调研", "评估", "对比", "选型", "分析", "体检", "审查", "audit", "为什么", "原理"]),
    ("优化", ["优化", "重构", "瘦身", "提速", "性能", "精简", "升级", "改进", "refactor"]),
    ("功能", ["开发", "实现", "新增", "构建", "搭建", "做一个", "写一个", "做个", "接入", "落地", "hook", "skill", "脚本", "引擎", "自动化", "工具"]),
]
DEFAULT_TYPE = "探索"
THEME_MAX = 20


def bj_date_from_ms(ms: int) -> str:
    """epoch ms → 北京时区 YYMMDD。ZoneInfo 不可用则回退固定 UTC+8。"""
    try:
        from zoneinfo import ZoneInfo
        tz = ZoneInfo("Asia/Shanghai")
    except Exception:
        tz = timezone(timedelta(hours=8))
    return datetime.fromtimestamp(ms / 1000, tz=tz).strftime("%y%m%d")


def classify(prompt: str) -> str:
    text = prompt.lower()
    for type_name, keywords in TYPE_RULES:
        if any(k.lower() in text for k in keywords):
            return type_name
    return DEFAULT_TYPE


def extract_theme(prompt: str) -> str:
    """取首个非空行 → 去 markdown 符号 → 在首个括号配平的标点处截断 → 限长。

    ⚠️ 下划线"_"不清洗——kb-index-guard 类主题名不可剥坏。
    ⚠️ 截断点须《》（）配平——《思考，快与慢》类书名号内标点不可切。
    ⚠️ v0.2 修：@开头的文件引用行（如 @"路径"）不作主题——
       跳到首个非引用行；全是引用行则剥掉 @ 和引号兜底。
    """
    lines = [l.strip() for l in prompt.splitlines() if l.strip()]
    if not lines:
        return "未命名"
    candidates = [l for l in lines if not l.startswith("@")]
    if candidates:
        line = candidates[0]
    else:
        line = lines[0].lstrip("@").strip().strip('"').strip() or "未命名"
    line = re.sub(r"^[#\s>*\-`]+", "", line).strip()
    line = re.sub(r"[`*#]", "", line).strip()
    theme = None
    for m in re.finditer(r"[，。？！：；、,?!\|\n]", line):
        seg = line[: m.start()]
        if seg.count("《") == seg.count("》") and seg.count("（") == seg.count("）"):
            theme = seg.strip()
            break
    if not theme or not theme.strip():
        theme = line.strip()
    return theme[:THEME_MAX] or "未命名"


def make_title(prompt: str, created_ms: int) -> str:
    return f"{bj_date_from_ms(created_ms)} | {classify(prompt)} | {extract_theme(prompt)}"


if __name__ == "__main__":
    import sys

    # 自测：--dry-run 模式打印标题，不写任何数据
    args = sys.argv[1:]
    if args and args[0] == "--dry-run":
        prompt = ""
        created_ms = int(datetime.now().timestamp() * 1000)
        i = 1
        while i < len(args):
            if args[i] == "--prompt":
                prompt = args[i + 1]
                i += 2
            elif args[i] == "--created-at-ms":
                created_ms = int(args[i + 1])
                i += 2
            else:
                i += 1
        print(make_title(prompt, created_ms))
```

**第 2 段 · `session_title_namer.py`**

```python
#!/usr/bin/env python3
# version: v0.4
"""session_title_namer.py — WorkBuddy 专属适配器：UserPromptSubmit 钩子新会话首轮自动命名对话标题。

命名规则:
    标题格式 = YYMMDD | 类型 | 主题
    日期 = 北京时区实际创建日期（取 sessions.created_at）
    类型 ∈ {功能,设计,修复,优化,发布,探索,文档,研究}（关键词启发式，默认=探索）
    主题 = 首条 prompt 简洁概括
    只动 custom_title（预留的用户自定义标题位）——title 列留给宿主自动起名，不动。
    已有 custom_title（手动命名过）→ 永不覆盖。

原语来源:
    classify / extract_theme / make_title / bj_date_from_ms 在
    ./session_title_utils.py（同目录）。
    本文件只保留 WorkBuddy 专属的 sqlite 落库逻辑（workbuddy.db sessions.custom_title）。

数据链路:
    WorkBuddy UserPromptSubmit 钩子 stdin JSON {session_id, prompt, ...}
    → 首次观察到该 session_id（状态文件判断）→ 写 sessions.custom_title
    → 状态文件 ~/.workbuddy/cache/title-namer/<session_id>.json 防重入

安全设计:
    - 任何异常 exit 0 静默降级——钩子绝不允许阻塞主流程（失败留痕 runtime.log）
    - UPDATE 带 `AND custom_title IS NULL` 守卫——不覆盖手动命名
    - sqlite busy_timeout=5000 + WAL 并发安全
    - 无 session_id / 会话不在库中 → 跳过不猜（fail-open to no-rename）

用法:
    echo '{"session_id":"<id>","prompt":"..."}' | python3 session_title_namer.py UserPromptSubmit   # 钩子模式
    python3 session_title_namer.py --dry-run --prompt "修复搜索超时问题" [--created-at-ms 1788952825816]  # 只看生成的标题不写库
    python3 session_title_namer.py --name-only --prompt "修复搜索超时问题" [--created-at-ms ...]   # 纯输出标题（供其他端适配器调用·不写 WB 库）
    python3 session_title_namer.py --set <session_id> --title "260909 | 功能 | 对话标题命名"        # 手动/历史改名通道（允许覆盖）
"""

import json
import sys
import sqlite3
from datetime import datetime
from pathlib import Path

from session_title_utils import make_title

DB_PATH = Path.home() / ".workbuddy" / "workbuddy.db"
STATE_DIR = Path.home() / ".workbuddy" / "cache" / "title-namer"
RUNTIME_LOG = STATE_DIR / "runtime.log"

# v0.2 修：模块级建目录——状态文件写入不能依赖 log() 顺带建目录的副作用，
# 否则目录不存在的新机器首跑会写状态失败、防重入晚一轮才生效。
try:
    STATE_DIR.mkdir(parents=True, exist_ok=True)
except Exception:
    pass  # 建不了目录时各写入点自带 try/except 兜底，钩子永不阻塞主流程


def log(msg: str) -> None:
    try:
        STATE_DIR.mkdir(parents=True, exist_ok=True)
        with open(RUNTIME_LOG, "a", encoding="utf-8") as f:
            f.write(f"{datetime.now().strftime('%Y-%m-%d %H:%M:%S')} {msg}\n")
    except Exception:
        pass


def _connect():
    """统一连接入口（v0.3 修）：显式设 WAL——非 WAL 数据库下，钩子进程写完
    后宿主应用可能还在读旧快照，标题要重启才显示。WAL 是幂等设置（已是
    WAL 则无操作）；设置失败静默降级，不影响写入本身。"""
    con = sqlite3.connect(str(DB_PATH), timeout=5)
    try:
        con.execute("PRAGMA busy_timeout=5000")
        try:
            con.execute("PRAGMA journal_mode=WAL")
        except Exception:
            pass
    except Exception:
        pass
    return con


def _to_ms(v) -> int:
    """会话创建时间的跨版本归一化（v0.4 修）：不同版本 WB 的 created_at
    可能是毫秒整数、秒级整数或 ISO 字符串——后两种会导致标题日期错乱或
    静默失败。统一转成毫秒；解析失败返回 0（上层回退当前时间）。"""
    try:
        if v is None:
            return 0
        if isinstance(v, (int, float)):
            n = float(v)
        else:
            s = str(v).strip()
            if not s:
                return 0
            try:
                n = float(s)
            except ValueError:
                from datetime import datetime as _dt
                n = _dt.fromisoformat(s.replace("Z", "+00:00")).timestamp() * 1000
        return int(n if n > 1e11 else n * 1000)  # 秒级(<1e11)→毫秒
    except Exception:
        return 0


def get_session(session_id: str):
    con = _connect()
    try:
        row = con.execute(
            "SELECT custom_title, created_at FROM sessions WHERE id=?", (session_id,)
        ).fetchone()
    finally:
        con.close()
    return row


def set_custom_title(session_id: str, title: str, force: bool = False) -> bool:
    """写 custom_title。force=False（钩子首轮自动命名）=带 `custom_title IS NULL` 守卫，
    永不覆盖手动命名；force=True（--set 手动/历史改名通道）=允许覆盖。"""
    con = _connect()
    try:
        sql = ("UPDATE sessions SET custom_title=? WHERE id=?" if force
               else "UPDATE sessions SET custom_title=? WHERE id=? AND custom_title IS NULL")
        cur = con.execute(sql, (title, session_id))
        con.commit()
        return cur.rowcount == 1
    finally:
        con.close()


def hook_mode() -> None:
    try:
        raw = sys.stdin.read()
        payload = json.loads(raw) if raw.strip().startswith("{") else {}
    except Exception:
        payload = {}
    session_id = str(payload.get("session_id", "")).strip()
    prompt = str(payload.get("prompt", "")).strip()
    if not session_id or not prompt:
        log(f"skip: no session_id/prompt (sid={session_id!r})")
        return

    state_file = STATE_DIR / f"{session_id}.json"
    if state_file.exists():
        return  # 已处理过，防重入

    try:
        row = get_session(session_id)
        if row is None:
            log(f"skip: session not in db sid={session_id}")
            state_file.write_text(json.dumps({"status": "not_in_db"}, ensure_ascii=False))
            return
        custom_title, created_ms = row
        if custom_title:
            log(f"skip: custom_title already set sid={session_id}")
            state_file.write_text(json.dumps({"status": "already_named"}, ensure_ascii=False))
            return
        title = make_title(prompt, _to_ms(created_ms) or int(datetime.now().timestamp() * 1000))
        if set_custom_title(session_id, title):
            state_file.write_text(
                json.dumps({"status": "named", "title": title}, ensure_ascii=False)
            )
            log(f"named sid={session_id} title={title!r}")
        else:
            # 并发窗口：custom_title 刚被别处写入 → 尊重现状
            state_file.write_text(json.dumps({"status": "lost_race"}, ensure_ascii=False))
            log(f"skip: lost race (custom_title set concurrently) sid={session_id}")
    except Exception as e:  # 钩子永不阻塞主流程
        log(f"error sid={session_id}: {type(e).__name__}: {e}")
    sys.exit(0)


def main() -> None:
    # v0.4 修：Windows 管道默认 GBK 编码，print 中文标题会报错。强制 UTF-8 输出。
    try:
        sys.stdout.reconfigure(encoding="utf-8", errors="replace")
        sys.stderr.reconfigure(encoding="utf-8", errors="replace")
    except Exception:
        pass
    args = sys.argv[1:]
    if args and args[0] == "--dry-run":
        prompt, created_ms = "", int(datetime.now().timestamp() * 1000)
        i = 1
        while i < len(args):
            if args[i] == "--prompt":
                prompt = args[i + 1]
                i += 2
            elif args[i] == "--created-at-ms":
                created_ms = _to_ms(args[i + 1])
                i += 2
            else:
                i += 1
        print(make_title(prompt, created_ms))
        return
    if args and args[0] == "--name-only":
        # 纯输出模式（供其他端适配器调用·不写 WB 库）：
        #   --prompt <首条消息> [--created-at-ms <epoch ms>] → stdout 打印 "YYMMDD | 类型 | 主题"
        prompt, created_ms = "", int(datetime.now().timestamp() * 1000)
        i = 1
        while i < len(args):
            if args[i] == "--prompt":
                prompt = args[i + 1]
                i += 2
            elif args[i] == "--created-at-ms":
                created_ms = _to_ms(args[i + 1])
                i += 2
            else:
                i += 1
        print(make_title(prompt, created_ms))
        return
    if args and args[0] == "--set":
        # 手动/历史改名通道：--set <session_id> --title "..."（允许覆盖已有标题）
        sid, title = args[1], ""
        i = 2
        while i < len(args):
            if args[i] == "--title":
                title = args[i + 1]
                i += 2
            else:
                i += 1
        ok = set_custom_title(sid, title, force=True)
        print(f"{'OK' if ok else 'SKIP(会话不存在)'}: {sid} -> {title!r}")
        log(f"manual-set sid={sid} ok={ok} title={title!r}")
        return
    hook_mode()


if __name__ == "__main__":
    main()
```

### 第 3 步：验证

新开一个对话，随便说一句话，然后看标题栏——应该会变成 `260921 | 探索 | 你说的主题` 这个样子。

没变的话，让 AI 看这个日志：`~/.workbuddy/cache/title-namer/runtime.log`

---

## 三、说明

- **只写标题，不动别的**：它只往 `workbuddy.db` 的 `sessions.custom_title` 字段写值，不碰你已有的命名。
- **一个会话只跑一次**：状态记在 `~/.workbuddy/cache/title-namer/` 下，同一个会话不会被反复改名。
- **不想要了怎么卸**：把 `settings.json` 里那条钩子删掉即可（也可以顺手删掉两个脚本文件）。

| 版本 | 日期 | 变更 |
|:---|:---|:---|
| v1.3 | 2026-09-21 | 对抗性终检补两防（脚本 v0.4）：①会话时间字段跨版本容错（秒级/字符串不再导致日期错乱或静默失败）②Windows 管道中文输出强制 UTF-8 |
| v1.2 | 2026-09-21 | 修「标题要重启才显示」：脚本显式设 WAL（脚本 v0.3）——非 WAL 数据库下钩子写完宿主可能读旧快照 |
| v1.1 | 2026-09-21 | 修两个脚本缺陷（见下）+ 注册命令加平台适配要求 + 注释清理 |
| v1.0 | 2026-09-21 | 首版 |

**v1.1 修了什么**（两个都是实际装出来的用户实测抓到的）：

1. **首跑目录缺陷**：脚本原来依赖日志函数"顺带"建缓存目录——在缓存目录还不存在的新机器上，第一次成功命名时写状态文件会失败（标题本身不受影响，但防重复机制晚一轮才生效）。现在脚本加载时就建好目录。
2. **引用行污染主题**：对话第一句话如果是文件引用（比如 `@"某个路径"`），自动生成的标题会变成一截路径。现在会跳过引用行取正文，全篇都是引用时剥掉引用符号兜底。
