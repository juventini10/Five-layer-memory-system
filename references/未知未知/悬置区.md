# 🌀 未知未知 · 悬置区（认知盲区轴·毛坯容器）

> 存储「当场无法归因」的异常信号毛坯。不存结论。
> 完整设计规范（触发定义/边界判定/状态机/时效窗/误标处理）见 `四象限设计哲学.md §2.7`。

### 条目格式

```
### 残差#{序号} · {YYYY-MM-DD}
- 触发: T1|T2|T3|T4|T5
- 归属: 用户盲区|AI盲区|双方共盲
- 来源: 对话|日记|复盘|探针
- 记录者: 用户|AI
- 状态: 悬置(未闭合)
- 毛坯描述: (仅冻现象，禁止归因)
- 显形: (转出目标 / 保留 / 升级课题 + 日期)
```
