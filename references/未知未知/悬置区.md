# 🌀 未知未知 · 悬置区（认知盲区轴·毛坯容器）

> **定位**：平行于「认知轴（SHADOW / 成长箱 / CORE）」与「时间轴（日记 / 周报 / 月报时间象限）」的**第三轴·盲区轴**入口。是认知升华流水线的入口：未知未知 → 显形 → 未知已知（SHADOW / 成长箱）→ 已知未知 → 已知已知（CORE / 日记）。
> **来源**：未知未知前置容器改造（设计草案 v0.1 + 四象限设计哲学.md §2.7）。
> **设计哲学冻结点（§2.7.8）**：本容器只存「尚未命名 / 未归因」的异常毛坯，**不存结论**。成功标准 = 显形率 / 平均盲区存活时长，**目标不是清零**——见 §2.7.6 涌现边界：信息全也消除不了未知未知。

## 一、数据契约（承重墙 · v0.1 · 冻结）

> ⚠️ 本段是自动化管道未来的读取规范。手工阶段0 即按此格式写，未来阶段1 / 2 的 Skill 钩子才能直接消费，**无需迁移**。改字段 = 历史条目失效，故冻结。

### 1.1 残差定义
> 残差 = 记录当下出现的、与既有认知框架（CORE / SHADOW / 成长箱 / 时间轴既有假设）不一致、且记录者在记录时**无法给出根因解释**的「未闭合信号」。
> （统计本义：残差 = 观测值 − 模型预测值；此处「模型」= 当前认知框架。复盘残差 = 现有记忆模型解释不了的观测。）

### 1.2 五类触发（任一成立即标「残差」）
| 码 | 触发 | 示例 |
|----|------|------|
| T1 | 预测失准 | 原以为 X，实际非 X，当场说不清为何偏 |
| T2 | 自相矛盾 | 同一议题先后陈述 / 行为冲突，当场无法归因 |
| T3 | 无法归因的成败 | 事成了或败了，机制不明 |
| T4 | 跨域孤儿 | 信号不属于任何现有轴 / 容器，强行归类会扭曲它 |
| T5 | 意识到的盲区 | 任一方意识到「这里有个我现在不知道的东西」，且无法立即命名 |

### 1.3 四条边界（是什么「不是」——消除主观判定）
- 不是**已知错误** → 去 **成长箱**
- 不是**已归因的知行偏差** → 去 **SHADOW 未知已知**
- 不是**已知未知**（列了缺口的）→ 去 **成长箱 pending**
- 不是**已诊断盲区** → 去 **月报盲区段**

> **关键纪律**：一条信号只要你当场能归因，它就**不是残差**，直接路由到上述对应容器。残差只容纳「当场确实归因不了」的。这条「能否归因」的判定，自动消除了主观判定缺陷。

### 1.4 归属标签（主体相对性 · 双主体创新落点）
- `用户盲区`：相对用户仍是未知未知
- `AI盲区`：相对 AI 仍是未知未知
- `双方共盲`：双方都尚未意识到

> 同一信号，用户能归因 → 对用户不是残差；AI 不能 → 对 AI 是残差。归属标记「相对谁仍是未知未知」——把用户「我和 AI 之间」的硬定义用活，也是文献全缺的那块。

### 1.5 显形状态机
```
悬置(未闭合)
  ├─[对话内即时显形(SWT锁六检查): 用户已确认清晰]──> 转出 最伟大的我/认知发现/ → 记显形台账(存活时长=0天)
  ├─[月报显形回看(第1.6步): 能归因]──> 转出 SHADOW(知行偏差)/成长箱(错误)/CORE(新认知) → 记显形台账
  └─[月报显形回看(第1.6步): 仍不能]──> 保留观察 | 升级为课题
```
> 显形频率：对话内即时 + **月报级**回看（月报SOP 第1.6步）；设计草案原议周报级为阶段1增强（经 L3 评估 Agent B 建议），见四象限设计哲学 §2.7。
>
> **对话内即时显形触发的条件**：T5标注后，在同一轮SWT对话中经过≥3轮追问，用户自己说出"对/是的/确实"确认了该信号的归因 → 即时跳出悬置区，不经过月报等待。存活时长=从T5标注到用户确认的小时间隔（不足1天按0天计）。

### 1.6 单条条目 schema（Markdown · 机器可读）
```
### 残差#{序号} · {YYYY-MM-DD}
- 触发: T1|T2|T3|T4|T5
- 归属: 用户盲区|AI盲区|双方共盲
- 来源: 对话|日记|复盘|探针(反方向的钟/S级评审/迁理之外/三明智)
- 记录者: 用户|AI
- 状态: 悬置(未闭合)
- 毛坯描述: (仅冻现象，禁止当时深加工/归因)
- 显形: (回看时填：转出目标 / 保留 / 升级课题 + 日期)
```

### 1.7 归因时效窗
> 一条残差在悬置状态停留超过 **3个月**（即经历3次月报显形回看仍未归因），触发以下处理：
> - **升级为课题**：从"被动等待归因"转为"主动研究"——给它一个研究编号，记录在显形台账.md
> - **标记为"深层盲区"**：状态从 `悬置(未闭合)` 改为 `悬置-深层(>3月未闭合)`
> - ⛔DO NOT：无限期保留而不升级——超过3个月的"悬置"如果不升级，就是在假装它还在被关注，实际已被遗忘
>
> 设计依据：L3评估Agent B提出的"归因时效窗"未决项。3个月=3次月报回看周期，给够显形机会但不过长。

### 1.8 误标处理
> 一条信号被标为残差后，若在显形回看时发现**其实当场就能归因**（误标），按以下处理：
> - **路由到正确容器**：按§1.3四条边界判断归属（成长箱/SHADOW/CORE）
> - **状态更新**：从 `悬置(未闭合)` 改为 `误标-已转出(目标容器+日期)`
> - **不删除原条目**：保留误标记录，用于未来分析"什么类型的信号容易被误标"（模式提炼）
> - ⛔DO NOT：直接删除误标条目——误标本身是信号，删除=丢失"什么容易误标"的模式数据
>
> 设计依据：L3评估Agent B提出的"误标处理"未决项。保留误标记录而非删除，是为了从错误中提炼"误标模式"。
