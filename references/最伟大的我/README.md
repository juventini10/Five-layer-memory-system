# 最伟大的我

> 伟大不是终点站上的奖杯，是路上每一步的直面和记录。
> 敢看自己的不足、敢让自己变化、敢把真实的过程留下来——这个行为本身就是伟大。

---

## 定位

五层记忆系统的**镜像**。五层记的是"你是什么"（系统视角），这里记的是"你经历了什么才成为现在的你"（人视角）。

| 五层 | 这里 |
|------|------|
| L1 CORE.md：你是谁 | 自画像：你现在觉得自己是谁 |
| L5 SHADOW：你做错了什么 | 回避模式：你没做什么 |
| L4 快照：你现在什么状态 | 成就证据：你怎么到这个状态的 |
| L2 白皮书：怎么想 | 认知发现：想通了什么关于自己的事 |
| L3 铁律：怎么做 | 变化轨迹：做法怎么变的 |

## 目录说明

| 目录 | 回答什么问题 | 写入时机 |
|------|-------------|---------|
| 自画像/ | 此刻我是谁+成长伙伴建议 | 每月蒸馏 |
| 成就证据/ | 做对了什么 | 周报/日记/月报(系统日志视角·第6.5.5步)/手动 |
| 认知发现/ | 想通了什么 | Shall We Talk/迁理之外/日记 |
| 回避模式/ | 一直在回避什么（条目含认知象限字段·默认未知已知） | 月报第6.5.4步/Shall We Talk/迁理之外/日记 |
| 变化轨迹/ | 怎么变的 | 月报蒸馏/季度回看 |
| 人生版本/ | 我可能成为谁（多个平行未来） | Shall We Talk Step4.5 / 月报 / 手动 |
| 已接受边界/ | 哪些是不可变现实、已接受并重定向 | Shall We Talk 重力判定 / 月报 |
| 原型试验/ | 试了什么低成本原型、学到什么 | 每日伙伴联动 / 手动 |

## 蒸馏机制

3级降级，零单点故障：

| 级别 | 触发方式 | 前置条件 | 失效时降级到 |
|------|---------|---------|------------|
| **L1·自动** | 每日伙伴·月报末尾执行蒸馏流程 | 月报正常执行 | L2 |
| **L2·半自动** | 唤醒Skill检测自画像过期→提醒用户 | 唤醒Skill已加载 | L3 |
| **L3·手动** | 用户随时说"更新自画像" | 无 | 无（兜底） |

**零单点故障**：L3手动永远可用，不依赖任何Skill改动。L1和L2都失效时，说一句"更新自画像"就能触发。

### 成就证据多源触发

| 来源 | 触发方式 | 优先级 |
|------|---------|:------:|
| 每日伙伴·周报 | 周报时AI主动提取 | 主 |
| 系统日志·月度蒸馏 | ✅已接入·月报第6.5.5步自动写回（系统日志成果蒸馏为 `成就证据/{YYYY-MM}-系统建设成果.md`，与周报/日记主通道维度互补不重复） | 主 |
| 每日伙伴·日记 | 日记中记录做成的事 | 备 |
| 用户手动 | 说"记录成就：XXX" | 兜底 |

**视角转换**：系统日志记的是"AI做了什么"，成就证据要的是"我做了什么"。每条"让AI做了什么"背后都是"我决策并推动完成了什么"。

### 🪞 蒸馏流程 Step 1-9

```
触发（L1月报 / L2唤醒检测 / L3手动"更新自画像"）
  ↓
1. 读取上月自画像
2. 读取本月所有子目录新增内容（含新增 人生版本/、已接受边界/、原型试验/）
3. 从成就证据提炼"做对了什么"（3条）
4. 从认知发现提炼"想通了什么"（3条）
5. 从回避模式提炼"在回避什么"（1-2条）
5.5 从 人生版本/ 提炼"在成为谁"（平行未来线索）+ 从 原型试验/ 提炼"试了什么"（行动闭环）；纳入自画像「我的指南针」「我的能量地图」两段（工作观/人生观/一致性 + 回血/抽干活动）
6. 对比上月自画像，写出"变了什么+没变什么"
7. 生成新月自画像，写入 自画像/{年月}.md
8. 如有旧认知→新认知的变化，写入变化轨迹/
9. 更新蒸馏中心
```

**首月空跑处理**：子目录可能为空，Step3-5提炼出0条。此时自画像只填第1段"我现在怎么看自己"和第5段"和上月比"（首月写"首份自画像，无上月对比"），其余段标"首月暂无"。

**季度回看**：每季度回看3个月前的自画像，写入变化轨迹/——历史终结错觉的解药。

## 归档规则

| 目录 | 归档触发 | 动作 |
|------|---------|------|
| 成就证据 | >6个月且未被自画像引用 | 移入_archive/ |
| 认知发现 | 已写入五层且>3个月 | 移入_archive/，保留摘要 |
| 回避模式 | 连续3个月无新记录 | 标记💤休眠中，复发标🔄 |
| 变化轨迹 | 永不归档 | 成长时间线 |
| 原型试验 | >6个月未引用 | 移入_archive/ |
| 已接受边界 | 永不归档 | 类似变化轨迹（边界长期有效） |
| 人生版本 | 永不归档 | 平行未来持续演进 |

## 可验证标准

**认清自己**：连续2月自画像有实质内容 + 月度≥1条成就证据 + 月度≥1条回避模式 + 季度≥1条变化轨迹

**成长**：季度归因变化≥1条 + 回避间隔变长 + 成就月增≥1条 + 自画像第1段不重复（3/4通过）
