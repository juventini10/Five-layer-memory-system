## 🎯 成就系统设计理念

**核心原则**：阅读和笔记是两条独立的成就线

| 成就类型 | 追踪什么 | 条件 |
|---------|---------|------|
| **📚 阅读成就** | 阅读数量 | 读完就算，不管写不写笔记 |
| **📝 笔记成就** | 笔记数量 | 必须写读书笔记才算 |

**为什么分离**：
- 鼓励广泛阅读（阅读成就）
- 鼓励深度思考（笔记成就）
- 两者都重要，但追踪方式不同

## 🔄 更新规则

### 每日更新
1. 完成番茄后 → 更新 `番茄成就.md`
2. 阅读后（读完就算） → 更新 `阅读成就.md`
3. 写读书笔记后 → 更新 `笔记成就.md`
4. 写日记后 → 更新 `通用打卡成就.md`
5. 记录睡眠/运动 → 更新 `健康成就.md` / `运动成就.md`
6. 发布内容 → 更新 `内容创作成就.md`
7. 完成技术任务后 → 记录到今日日记「今日工作」表格

### 每周更新
- 每周日检查所有成就进度
- 更新已达成成就的日期
- 调整下一个目标
